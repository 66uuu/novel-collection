# 弯道上又有一个人影

我跑到村口那条岔路上，脚步慢下来。
我慢下来，是因为我看见了前面的东西。
土路在前面拐了一个弯，弯过去就是村东头。就在那个弯的地方，站着一个人影。
我第一反应是，村里有人出来了。
我心里甚至有点感激。我想，有人就好。有人我就不怕了。
我拿手电照过去。
光打过去的时候，我看清了。
它站在路中间，正对着我。
它站得比刚才直。刚才它站着的时候，背有点驼，脖子往前伸。现在它把背挺起来了，头也抬起来了。两只前蹄还是贴在胸前，可是贴得更靠上，靠近脖子的地方。
那件褂子的下摆，现在不往外撑了。它顺着身体垂下去，垂到膝盖。
它把自己调整了一下。
它现在更像人了。
它脸上还是那个笑。
光打过去，它的两只眼睛是绿的，绿得亮得发白。它的嘴咧开，嘴边的东西还在，湿的，在手电光里亮。
它没有动。
它就那么站着，看着我。
我站在离它十几米的地方，脑子里转的是一个很奇怪的问题。
它是怎么过来的。
我跑了一千多米。我跑的时候，土路上没有别人。它刚才在林子里，我亲耳听见它的脚步声往深处走。
它不可能比我先到。
除非它根本没有走那条路。
我往路两边看。路左边是沟，沟那边是玉米地。路右边是一片荒着的地，长满草，草有半人高。
那些草是倒着的。
从林子那个方向，一直倒到路边，倒出一条线。像有什么东西从草上走过去，把草压平了。
草是湿的。我看见草叶上有水光。
那晚上没有下雨。
我蹲下去看了一眼。
草叶上的水不是露水。露水是凉的，是那种贴在叶子上的小珠子。这个不是。这个是黏的，抹在手指上，滑，还有味。
我把手指在裤子上擦了两下，擦不掉。
我站起来，又看了一眼那条倒下去的草。
那条线很直。
草是被压平的，没有断。压平的地方很宽，比一只羊宽，比一个人也宽。
我想不明白什么东西能把草压成这样。我后来也不想明白了。
