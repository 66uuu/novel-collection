## 二、参考封面提取的视觉语言

从两张《诡梦》封面提取并复现：

1. **构图**：竖版，主体居中，大标题压顶，底部中央作者名
2. **配色**：近乎单色的暗蓝灰黑，**唯一饱和色是血红**（脚印、裂天）
3. **母题**：中央必有「门 / 门槛 / 通道」——家是梦的起点，亦是尽头
4. **地面**：血红脚印 + 湿滑反光
5. **氛围**：雨雾、湿气、四角重度暗角、远处一点人造光（路灯）
6. **孤独感**：单个渺小背影（参考图 2 还加了半透明重影表示轮回）
7. **字体**：大字毛笔书法 + 小字副标语 + 「—— 作者 ——」

## 四、技术细节

- **生图**：ImageGen，1024×1536，quality=high，t2i 文生图（参考图只作风格证据提取，不作 i2i 输入，避免构图互相污染）
- **提示词**：`06_提示词存档/封面提示词-prompt-optimizer优化版.md`，走 prompt-optimizer 的 `image-general-optimize` 模板（3-6 句分层叙述）
- **去水印**：生图右下角带「AI生成」角标，用 numpy 掩膜填充去除（阈值 100 提亮字掩膜 → 膨胀 5 次 → 干净像素均值+方差重填 + 固定种子噪声）。验证标准：右下角区域最高亮度回落到背景水平（实测 8）
- **排版**：PIL + 华文行楷（STXINGKA.TTF）
  - 书名「我在梦境里轮回」130pt，血红 (158,24,25)，带 5px 高斯暗投影
  - 做旧：噪声蛀孔 5.5% 概率 × 0.25 透明度、边缘毛糙 4.5% × 0.55、9 条纵向干裂细痕
  - 副标语「三个梦，同一栋楼，同一个时刻」40pt，左右细线装饰
  - 作者「李焱 著」50pt，底部中央，左右细线（仿参考封面「—— 李焱 ——」）
  - 顶部压暗至 y=520、底部压暗 260px，保证文字可读

## 五、返工预案

| 现象 | 处理 |
|---|---|
| 红色不够饱和 | 把提示词 "saturated dried-blood red used only for" 改成 "vivid arterial red used boldly for" |
| 门内三层景象糊成一团 | 三段拆更短的分号句，每段只留一个主体名词 |
| 整体太亮、恐怖感不足 | 加 "the entire frame is swallowed by darkness except three points of light" |
| 出现多余人物 | negative 加 "crowd, groups of people, faces" |
| 重影不明显、轮回感弱 | "repeated three times" 改成 "repeated four times, each copy more transparent" |
| 想要 2D 手绘风而非写实 | 改用第一版提示词路线（`01_原图` 那张即 2D 成果） |
