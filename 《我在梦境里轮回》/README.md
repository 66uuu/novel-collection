## 这是什么

一部由**三个真实梦境**缝合而成的长篇小说。三个梦原本毫不相干——商业城、广西老宅、丧尸城——被放进同一个叙事框架后，发现它们是**同一栋楼的四重时空**，时间是同一个时刻（11:40），出口连着入口，一环扣一环。

主角顾南在梦里始终是清醒的：能思考，能判断，就是不知道那是梦。所以他砍了人，跑了命，也打翻过拦他的人。直到他把三个梦原原本本讲出来，才发现玻璃门上那行字是他自己写的：

> **讲出来，才能算数。**

## 技术与成本

- **正文拆分**：Node.js 按 `###第N章` 标记切分（`split(/(?=^###第…章$)/m)` 保留分隔符，每章天然带边界换行），拼接后与合并版逐字节一致；首轮误用旧版做源出过回归，已重拆 + 零修补校验修复
- **封面生图**：ImageGen 文生图，1024×1536，quality=high，共生成 3 张（v1 弃用、v2 迭代、v3 定稿）
- **封面提示词**：走 `prompt-optimizer` 技能的 `image-general-optimize` 模板（3-6 句分层叙述），先从两张《诡梦》参考封面提取视觉语言，再换成本书母题
- **去水印**：Python PIL + numpy 掩膜填充（生图自带「AI生成」角标，中值滤波无效，改用掩膜+均值方差重填）
- **排版**：PIL + 华文行楷（STXINGKA.TTF），书名 130pt 血红 + 噪声做旧破损，副标语 40pt，作者 50pt，顶底渐变压暗
- **质量门禁**：`story-short-write` 技能脚本，Node.js 运行
