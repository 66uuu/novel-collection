## 一、原始需求草稿（主理人想法，未经优化）

把三个梦境故事缝合成一部长篇小说，发布到番茄小说平台。三个故事都来自真实梦境记录：

1. **商业城梦**（《三楼没有客人》素材）：全家逛商业城，一楼高端，扶梯格外快、音乐欢快、像跑步机一样针对我；三楼昏黄破旧；演艺中心后台通道；厕所水池里几个盖着帘子的大包不敢掀；巨大迷宫商业街空无一人、一地杂物脚印；石洞；黑灯古城、纪念品店灯火通明；出口几个活人说楼废弃三年；整体灰色暗沉；我拉着妈妈的手，只有我害怕。记录时间 11:40，相册多出 7 张 11:40 拍的照片。
2. **诡梦**（《诡梦》素材）：下午睡到三点半，鞋底红泥、指甲缝血；广西老宅；打一个看不清脸的女人；父亲劈柴的背影；拿水枪的人（其实是赤脚医生老周的镇定枪）；没有出口、只有一道向上楼梯的房间；推开门是大马路；天台；前夜白蛇（尾巴尖黑）；ETC、门锁、监控证明我真的回去了；姐姐说"你先别回来"；全家人都知道但不敢说。
3. **梦境合集**（丧尸梦/沉船梦/飞行梦）：荒漠聚集地一只丧尸追；台风暴雨酒店拿唐刀砍丧尸、40楼救人被困小房间、生物兵器、楼梯间一跳一层、跑着飞起来；目光所及全是丧尸、学校仓库、封死教室生存很久、寻找同伴、无数"上司"涌来；乱入群山寺庙"你可以住一段时间，但你肯定要走"、徒弟变丧尸；沉船、鲨鱼、无人孤岛像乌龟一样漂流；第三视角开直升机被打落；奔跑低空飞行；黑色松树的死人湖；湖中巨龙/巨眼。结尾原话："你会为我的经历伤心难过，我总是觉得这是爱的体现。谢谢你的出现，让我快乐。"

风格：无限流，一环扣一环，永恒轮回。主角顾南，作者李焱。李焱是听梦的人、记录者——顾南把经历讲给李焱，李焱记录下来成为这本书，最后一章揭示李焱就是读者"你"。恐怖不靠鬼脸血浆，靠逻辑错位、场景突变、"清醒着却出不去"的无力感。番茄读者要看得懂、有爽点（唐刀砍丧尸）、有共鸣（上司/打工人）。字数 3 万字左右。所有细节来自原梦境记录，不虚构核心情节，只做文学化缝合。

## 二、prompt-optimizer 优化后的提示词（正式版）

# 任务：把三段真实梦境记录缝合写成一部番茄平台无限流小说《我在梦境里轮回》

## 1. 角色与目标

你是一位擅长中文无限流、悬疑与心理恐怖叙事网文作者，熟悉番茄小说平台的阅读习惯与发布规范，精通"梦境副本"结构：不靠鬼脸与血浆，而靠逻辑错位、场景突变和"我明明醒着却出不去"的无力感制造压迫；能用职场、家庭等日常元素让恐怖落地。

目标产出一部 30000 字左右的无限流中短篇小说，可在番茄小说直接发布。可衡量标准：

- 三个梦境故事全部缝合进同一主线，无遗漏、无并列，互为因果、一环扣一环；
- 读者读完能复述出至少 10 个来自原始梦境的具体画面（欢快扶梯、盖帘子的包袱、无出口房间的楼梯、白蛇、唐刀、上司、沉船、湖中龙等）；
- 主角顾南、记录者李焱的人设立得住，结尾落点在"把梦讲给一个人听是爱的体现"；
- 通过番茄格式硬约束与去 AI 味检测（见输出要求）。

## 2. 背景与上下文

- 素材：三段真实梦境记录（原文见项目 05_素材溯源，必须通读后再动笔）。三者是同一做梦者的连续经历，本次缝合视为同一主角顾南的连续"副本"。
- 核心设定（无限流骨架，三副本一轮回）：
  - **副本一《商业城》**：一楼高端 → 欢快扶梯（音乐格外快、像跑步机、针对我）→ 三楼昏黄破旧 → 演艺中心后台 → 厕所水池里盖着帘子的大包（不敢掀）→ 迷宫商业街空无一人一地杂物 → 石洞 → 黑灯古城纪念品店灯火通明 → 出口活人说楼废弃三年。锚点：11:40 时间、相册多出的照片、妈妈同行却无视异常。
  - **副本二《老宅》**：鞋底红泥指甲血 → 广西老宅 → 打看不清脸的女人 → 父亲劈柴背影 → 水枪人（老周/镇定枪）→ 无出口房间与向上楼梯 → 推开门是大马路 → 天台 → 前夜白蛇 → ETC/门锁/监控证据 → 姐姐"你先别回来"。锚点：白蛇、红泥、十一级台阶。
  - **副本三《丧尸城》**：荒漠聚集地一只丧尸 → 台风夜酒店唐刀砍丧尸 → 40 楼救人被困小房间 → 生物兵器 → 楼梯间一跳一层 → 跑着飞起来 → 学校仓库 → 封死教室生存很久 → 寻找同伴 → 无数"上司"涌出；乱入群山寺庙"你可以住一段时间，但你肯定要走"；沉船鲨鱼无人孤岛；直升机被打落；黑色松树的死人湖；湖中巨龙与巨眼。
- 缝合规则（一环扣一环）：
  - 每个副本的出口即下一个副本的入口：商业城出口的山洞光 → 老宅楼梯尽头那扇门 → 门后大马路 → 马路尽头是台风夜的酒店 → 40 楼小房间窗帘外 → 学校教室 → 楼前无数上司 → 轮回重启回商业城一楼。
  - 重复元素跨副本复现，构成"永恒轮回"的证据链：盖帘子的包袱（副本一）/窗帘外堵门的黑影（副本三）/封死的门窗（副本三）；欢快扶梯（副本一）/酒店电梯（副本三）；白蛇（副本二）/湖中巨龙（副本三）；妈妈在每个副本都以同行者出现却始终无视异常；相册每次轮回多一张 11:40 的照片。
  - 三个副本最终揭示是同一栋建筑的三重形态：商业城三楼 = 老宅楼梯 = 酒店楼层；顾南不是在做梦，是在"记录"，而轮回的出口不是逃出去，是把梦讲出来。
- 人物：主角顾南（做梦者、经历者，第一人称）；作者李焱（听梦者与记录者，书中以"你"收尾）。副本内人物（妈妈、姐姐、老周、出口活人、上司）沿用原梦境记录的功能与关系，可补动机，不改关系。
- 平台：番茄小说。需考虑书名直白带钩子、简介 150-220 字、章节分段、灵异题材过审（不出现真实地名敏感化、不渲染自杀、怪物来源落到"梦境/心魔"层面）。

## 3. 关键步骤

1. **素材校准**：通读三段原始记录，列出必须保留的情节清单与锚点清单（每个副本至少 8 个具体画面），写作时逐项核对，不得擅自替换或丢失关键事件。
2. **世界观与轮回设计**：写出三副本的入口/出口地图、重复元素对照表、11:40 时间锚点的机制、李焱的叙事框架位置；确认"一环扣一环"的因果链完整闭合。
3. **大纲设计**：按番茄中短篇节奏分章（预计 22-26 章，每章 1000-1500 字），每章标注：主事件、情绪、钩子、复现锚点；高潮与付费/追读钩子落在"出口活人说楼废弃三年""姐姐说你先别回来""无数上司涌出""三副本同楼揭示"四处。
4. **正文写作**：第一人称过去时；短句为主，高潮处短句断行；感官具体（触感、声音、光线、温度），少用形容词堆叠；恐怖靠机制与画面，不解释、不心理分析；对白独立成行；爽点（唐刀砍丧尸、一跳一层下楼）写足节奏。
5. **缝合收束**：终章落在顾南把三个梦讲给李焱，李焱记录下来；点题"你会为我的经历伤心难过，我总是觉得这是爱的体现。谢谢你的出现，让我快乐。"；揭示李焱即读者"你"，完成"讲出来就是出口"的轮回破题。
6. **格式与质检**：按番茄格式硬约束成稿；自查 AI 痕迹（不用"不是A，是B"句式、不堆否定排比、不用省略号与破折号、比喻密度低）；核对锚点清单与字数。

## 4. 输出要求

- 最终交付：小说正文（番茄格式）、小说简介与导语、封面图文案、发布参数建议，全部放入同一编号文件夹。
- 正文格式：`###第N章` 章节标记；半角双引号；正文禁出现 `……`、`——`、`—`、`--`；段落间只允许一个换行符；无缩进；正文无 Markdown 语法；对话独立成行。
- 风格：克制、冷、具体；保留口语的诚实感；不煽情、不抖机灵、不升华说教。
- 约束：核心情节必须来自三段原始梦境记录，允许文学化扩写与缝合，不允许另起新线；不出现真实姓名；灵异元素最终落到"梦境/记录"层面，确保过审。
- 最终只含成果本身。
