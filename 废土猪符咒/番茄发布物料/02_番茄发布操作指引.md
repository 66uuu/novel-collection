# 番茄小说发布操作指引（手把手版）

> 目标：把《废土：我只有一块猪符咒》发到番茄小说，走完从注册到上架的全流程。
> 你只需要按本文件一步步点，不需要任何技术操作。

---

## ⚠️ 先说清楚一件事：为什么不能「直接帮你发表」

番茄小说**没有对外开放的发文 API**，任何第三方程序都无法直接登录你的账号发文。而且：

1. **必须实名 + 账号授权**——发文权属于账号本人，平台风控会拦截异地/自动化登录；
2. **AI 直传会被判定违规**——纯机器提交的内容在平台侧有检测，轻则限流，重则封号；
3. **签约与版权**——发表即意味着你本人对作品版权、内容合规负责。

**所以正确做法是：我把物料准备到"只差你点上传"的程度，你花 10 分钟点完。**

---

## 一、注册与认证（约 5 分钟，一次性）

### 1. 注册作家账号
- 电脑端：打开 **fanqienovel.com** → 右上角「作家专区」→ 用**手机号**注册
- 或手机端：下载「**番茄作家助手**」App（推荐，后续更新章节更方便）

### 2. 实名认证
- 「我的」→「实名认证」→ 上传**身份证** + **人脸识别**
- 必须本人，认证后才能创建作品、签约、提现

### 3. 绑定收款信息
- 添加**银行卡或支付宝**（稿费结算用）

## 二、创建作品（约 5 分钟）

进入「作家助手」→「创建作品」，填：

| 字段 | 填写内容（直接复制） |
|---|---|
| **作品名称** | 废土：我只有一块猪符咒 |
| **作品分类** | 男频 → 科幻 → 末世危机 |
| **作品标签** | 末世、废土、求生、无系统、智商在线 |
| **一句话简介** | 见 `01_书名_简介_分类标签.md`「版本一 · 短版」 |
| **作品简介** | 见 `01_书名_简介_分类标签.md`「版本二 · 标准版」 |
| **封面** | ⚠️ 见下面「封面方案」 |
| **是否首发本站** | 选「**是**」（首发有流量扶持） |
| **更新计划** | 选「签约作品」或「免费作品」（均可，见第五节） |

### 封面方案（三选一）
1. **平台模板生成**：创建作品时番茄提供模板，选「末世/废墟」风格套用，最快；
2. **自己指定文字**：封面上只放书名 + 主角背影/矿道剪影，文字要大；
3. **需要我生成**：可让我用图像工具做一张竖版封面（900×1200 px），你说一声即可。

## 三、上传章节（约 3 分钟）

### 你要用的文件
```
<DESKTOP>/废土猪符咒\番茄上传稿\
├── 废土猪符咒_黄金三章1-3_番茄上传稿.txt   ← 首发用这个
└── 废土猪符咒_全书1-20章_番茄上传稿.txt    ← 后续更新用
```

### 操作方式 A：批量导入（推荐，最快）
1. 「作品管理」→「章节管理」→「**批量导入**」
2. 上传 `废土猪符咒_黄金三章1-3_番茄上传稿.txt`
3. 系统会自动按「第1章 / 第2章 / 第3章」切分成 3 个章节
4. 检查每章标题、正文是否正常 → 点「**发布**」

### 操作方式 B：手动粘贴（更稳妥，逐章校对）
1. 「新建章节」→ 标题填「第1章 好消息：穿越了。坏消息：这里好像不太欢迎我」
2. 打开 TXT，复制第 1 章正文（从「林野死的时候」到章末），粘贴
3. 点「发布」→ 重复 3 次完成黄金三章

### ⚠️ 番茄排版注意
- TXT 里**每段独占一行**，段落之间没有空行——番茄阅读器会自动识别段落缩进，**不要手动加空行**；
- 我在 TXT 里已经**去掉了所有 Markdown 符号**（`**`、`#`、`---`），粘贴后是干净正文；
- 如果导入后发现段落挤在一起：在编辑器中全选 → 用「自动排版」功能修正。

## 四、发布节奏（重要！决定推荐量）

| 时间 | 做什么 |
|---|---|
| **第 1 天** | 一次发**前 3 章**（黄金三章），不要多发 |
| **第 2–4 天** | 每天发 1 章（第 4–6 章） |
| **第 5 天起** | 稳定日更 1–2 章，逐步放到日更 4000+ 字 |
| **新书期** | 尽量**不断更**，断更会掉推荐权重 |

**为什么前 3 章要单独发？**
番茄的推荐机制核心看「**前 3 章读完率**」和「**追读率**」。
前 3 章一口气放出去，系统能更快判定是否给你进推荐池。
（这 3 章我已经按番茄节奏优化过：字数收敛到 2800–3000 字、章末都留了钩子。）

## 五、签约与收益（了解即可）

### 两种模式
| 模式 | 特点 |
|---|---|
| **免费作品** | 按阅读时长/广告分成计费，**新人友好，无需签约**，可先跑数据 |
| **签约作品** | 编辑审核后签约，有全勤奖 + 保底/买断，收益更高但需要更新量 |

### 建议路径
1. **先按「免费作品」发**，跑 1–2 周数据（看点击率、追读率）；
2. 数据好（追读率 >30%）→ 主动申请签约，或等编辑主动联系；
3. 后台上「作者中心」→「签约申请」，上传身份证即可。

### 全勤奖门槛（参考，以后台实际为准）
- 日更 ≥4000 字，且当月**不断更**，可拿全勤奖；
- 你目前有 **20 章 6.1 万字存稿**，够撑新书期 + 全勤。

## 六、AI 生成内容合规提示（务必读）

番茄对 AI 内容有明确要求。为降低风险，建议：

1. **发布前至少通读一遍**，改掉明显的 AI 腔句子（本书已经过多轮去 AI 腔处理）；
2. **作者后台若有「AI 辅助创作」申报选项，如实勾选**（不同时期政策不同，以后台提示为准）；
3. **不要用脚本批量提交**——手动发布，避免触发风控；
4. **作品里不要出现真实人物、真实机构、政治敏感内容**（本书为纯架空废土，已规避）；
5. 若收到平台「内容提示」，按提示修改对应章节，**不要反复硬发**。

## 七、常见问题

**Q：导入后章节顺序乱了？**
A：番茄按正文里的「第N章」标题排序。若乱了，手动调整章节序号即可。

**Q：可以修改已发布章节吗？**
A：可以，后台随时改，但改动过大可能影响已有读者的阅读记录，建议只改明显笔误。

**Q：能同时发到其他平台吗？**
A：番茄要求**首发 + 独家**。若签了独家，就不能再发到起点/七猫等。这个要在签约前想清楚。

**Q：封面怎么弄最好？**
A：末世题材用「深色 + 单一光源 + 主角背影」最抓眼。需要我生成，直接说。
