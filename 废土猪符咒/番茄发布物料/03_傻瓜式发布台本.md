# 番茄作家助手 · 傻瓜式发布台本

> 你已经下载了「番茄作家助手」（联想模拟器里的安卓 App）。
> 这份台本按「你看到什么 → 点什么 → 填什么」写，照着做，15 分钟能发完前 3 章。

---

## ⚠️ 开始之前，先想清楚两件事

**第一件：账号必须是你的。**
发文要手机号 + 短信验证码 + 实名认证。验证码发到你手机上，只有你能操作。

**第二件：建议优先用网页版，其次才用 App。**
- 🌐 **网页版**（推荐）：电脑浏览器打开 `fanqienovel.com` → 右上角「作家专区」→ 登录后发文。**复制粘贴长文本比安卓 App 顺得多**，不容易卡。
- 📱 **模拟器 App**（你已装的这个）：手机上发文的体验。优点是能随时更新；缺点是**粘贴几千字的长文可能卡顿或丢格式**。
- ⬇️ **最省事的选择**：如果只是想把稿子发出去，**用网页版**。模拟器 App 可以留着以后手机上改稿用。

下面两套流程都给。

---

# 方案 A：网页版发文（推荐，最快）

## 第 1 步 · 注册登录（约 3 分钟）
1. 电脑浏览器打开 **`fanqienovel.com`**
2. 右上角点 **「作家专区」**
3. 用**手机号**注册，收到**验证码**填进去
4. 进入「我的」→ **实名认证**：上传身份证正反面 + 人脸识别（本人操作）

## 第 2 步 · 创建作品（约 3 分钟）
点 **「创建作品」**，按下表填：

| 栏目 | 填什么 |
|---|---|
| 作品名称 | `废土：我只有一块猪符咒` |
| 作品分类 | `男频` → `科幻` → `末世危机`（若无此项，选「玄幻 → 末世」） |
| 作品标签 | `末世`、`废土`、`求生`、`无系统`、`智商在线` |
| 一句话简介 | 复制 `01_书名_简介_分类标签.md` 里的「版本一·短版」 |
| 作品简介 | 复制同文件里的「**版本二·标准版**」 |
| 是否首发本站 | 选 **是** |
| 封面 | 上传 `番茄发布物料/封面_废土我只有一块猪符咒_900x1200.jpg` |

> 封面文件名：`封面_废土我只有一块猪符咒_900x1200.jpg`（已按番茄 3:4 规格做好）

## 第 3 步 · 上传章节（约 5 分钟）

**方式一：批量导入（最快）**
1. 左侧「章节管理」→ 找 **「批量导入」/「导入txt」** 按钮
2. 上传 `番茄上传稿/废土猪符咒_黄金三章1-3_番茄上传稿.txt`
3. 系统自动切成 3 章 → 逐章核对标题 → 点 **「发布」**

**方式二：手动粘贴（最稳，推荐首章用）**
1. 点 **「新建章节」**
2. **章节标题**栏填：`第1章 好消息：穿越了。坏消息：这里好像不太欢迎我`
3. **正文**栏：打开 `番茄上传稿/分章粘贴版/第01章_....txt`，**Ctrl+A 全选 → Ctrl+C → 粘贴进去**
4. 检查分段是否正常 → 点 **「发布」**
5. 重复第 1 章的动作，发第 2、3 章

> 💡 分章粘贴版在 `番茄上传稿/分章粘贴版/`，每章一个文件，第 1 章到第 20 章都切好了。

## 第 4 步 · 发布节奏
- **第 1 天**：只发**前 3 章**（黄金三章，让系统判定推荐）
- **第 2–4 天**：每天 1 章（第 4、5、6 章）
- **第 5 天起**：日更 1–2 章

# 方案 B：模拟器 App 发文（你已装的）

## 第 1 步 · 打开 App
- 双击桌面 **「番茄作家助手」** → 模拟器启动 → App 打开
- 如果只看到模拟器桌面没看到 App：在模拟器里找 **「番茄作家助手」图标**双击进入

## 第 2 步 · 登录
- 用**手机号 + 验证码**登录（验证码在你手机上）
- 首次需要**实名认证**

## 第 3 步 · 创建作品
- 底部导航找 **「作品」** 或 **「我的」** → **「创建作品」**
- 名称/分类/简介/标签，同上表填写

## 第 4 步 · 发文
- 进入作品 → **「新建章节」** / **「写章节」**
- 标题填章名，正文**长按输入框 → 粘贴**
- ⚠️ **安卓 App 粘长文容易卡**：如果粘贴失败，改为**分段粘**（先粘前一半，再粘后一半）
- 点 **「发布」/「保存并发布」**

## 第 5 步 · 同样的节奏
第 1 天前 3 章，之后每天 1 章。

# 遇到问题怎么办

| 现象 | 处理 |
|---|---|
| 粘贴进去是一整坨没分段 | 用编辑器里的「**一键排版**」功能（一般叫「排版」或「格式化」） |
| 导入 TXT 后章节顺序乱 | 手动在章节管理里调序号 |
| 提示「内容需要审核」 | 正常流程，等审核通过即可，一般几分钟到几小时 |
| 提示内容异常 / 违规 | 逐段检查有没有敏感词，改掉再发；**不要反复硬发** |
| 模拟器卡死 | 关掉模拟器重启；或改走**网页版**（方案 A） |
