## 一、书名

番茄男频废土/末世类的书名规律：**「主标题 + 反差副标题」**，或**一句钩子式长书名**。
前 6 个字决定点击率，必须把「废土 + 金手指反差」塞进前 8 字。

| 方案 | 书名 | 说明 |
|---|---|---|
| **A（推荐·现用）** | 废土：我只有一块猪符咒 | 「废土」=品类词，「猪符咒」=反差金手指，一眼看懂又不土。搜索词覆盖好 |
| B | 末世：我的金手指是块猪符咒 | 更直白，「末世」搜索量比「废土」大 |
| C | 废土：开局一块猪符咒 | 番茄经典「开局」式命名，推荐机制友好 |
| D | 我在废土当搬运工 | 突出「普通人求生」路线，但金手指信息丢失 |
| E | 废土求生：我只有一块不能融合的猪符咒 | 信息量最大，但过长（13 字上限） |

**结论：保持方案 A。** 若上线 3 天点击率低于同类均值，可换 B 做 A/B 测试。

## 二、简介（三版，按平台字数限制选用）

### 版本一 · 短版（约 120 字，用于「一句话简介」栏）

```
林野加班猝死，醒来时手脚戴着铁链，编号戊-37。
他唯一的资产，是从 2026 年顺手带过来的一块石头——
刻着只歪头猪，能射出粉色镭射，用一次就冻掉半条命。
矿场在塌，上头在封口，镜子里站着另一个人。
他得先活下来，再算清楚一件事：
这块破石头，到底是怎么把他带到这儿的。
```

### 版本二 · 标准版（约 220 字，推荐主用）

```
穿越到废土，林野的第一个人生目标是：吃到两个馒头。

这里是断纪 198 年。地表是灰的，水在低处，人住在高处，
活命的规矩写在《渊政十二则》里——他一条都不懂。
他被踹醒的时候，编号叫戊-37，脚下是随时会塌的矿道，
身边躺着六十年前等人等到死的干尸。

他全部的底牌，是穿越时顺手带过来的一块石头。
六棱柱，刻着只歪头猪，能让他的眼睛射出粉色激光。
但这东西不是发电机，是换能器——威力有多大，取决于他的身体有多强；
用一次，冷一次，瞎一次，暴露一次。

矿场在往下塌，上头在往下填。
林野没打算硬刚。他打算先算一笔账。
```

### 版本三 · 长版（约 320 字，用于详情页 / 书架推荐位）

```
【签到无·系统无·金手指只有一个功能·主角靠算账续命】

林野，2026 年猝死在工位上的物流理货员。
醒来时，他被一条铁链拴在废土矿场的坑壁上，编号戊-37。

距离那场让世界崩塌的渊潮，已经过去 198 年。
没有国家，没有网络，没有电。活人在塔垸里种粮，
死人在旧道里站着等人，中间隔着一句没人敢念全的话。

他唯一的依仗，是一块跟着他灵魂穿过来的石头：猪符咒。
它能让他的眼睛变成激光枪——但威力上限，就是他自己的命。
身体越弱，威力越小；用得越狠，他越像一个被掏空的人。
别人的金手指是开挂，他的金手指是当着你的面，把你自己的血抽出来烧。

矿场要封，旧道要填，镜子里站着另一个"我"。
他不能打，不能逃，只能算——
算工时，算路线，算人心，算到所有人都不明白他为什么总能先走一步。

有人以为他深不可测。
其实他只是把上辈子理货的经验，用在了活命上。
```

**结论：主用版本二**，版本一填「一句话简介」，版本三放详情页宣传位。
