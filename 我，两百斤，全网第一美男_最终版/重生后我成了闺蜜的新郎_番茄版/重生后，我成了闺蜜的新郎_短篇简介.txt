《重生后，我成了闺蜜的新郎》短篇简介（9000字版）

作者：李焰
体量：短故事 · 约 9400 字 · 四段
原版：约 3.6 万字 / 18 章


【正式简介】（复制这段粘到番茄后台）

她说话的时候眼睛会弯。

我认识她十年，见证过她笑，也见过她哭。

我没见过的，是她爱人的脸。

我认识她的时候，她还是个没心没肺的姑娘，会在下雨天把伞全让给别人，会为了一句"我们以后一直做朋友"跟人拉钩。

大三那年，她开始被人追。

我撕了其中三封信，赶走了其中四个人。

我不敢说。

我怕说了，我就什么都不是了。

大四那年冬天，我跟她说了。

我说的不是"我喜欢你"。

我说的是"不是朋友的喜欢"。

她看我的眼神变了。那不是惊讶，不是为难。

那是恐惧。

她说：你正常一点。

五个字，把我推回了一个普通朋友的位置。

后来我看着她谈恋爱，看着她嫁人，看着她生孩子。

六年后，我抱着我们唯一一张合照，从五楼走了下去。

再睁眼，我成了陈屿。

她未来的丈夫。

我回来了。

回到了一切都还来得及的那一天。


【一句话简介】（横幅/推荐位用）

"我抱着合照走下五楼，再睁眼，成了她老公。一百天后我才看清：上一世我恨了一辈子的那个男人，就是我自己。"


【四段分段说明】（投稿系统如需分段填）

第一段「重生：躺在他床上，我成了那个男人」
　大学相识 → 每天六点五十买早饭 → 撕三封信赶走四个人 → 表白被拒「你正常一点」

第二段「六年：她成了别人的妻子，我成了她的同事」
　六年旁观 → 她结婚生子 → 抱合照走下五楼 → 被邻居拽住 → 医院九天

第三段「一百天：我用他的脸，去追上一世的我」
　睁眼看见男人的手 → 一百天倒计时 → 用借来的身体追她 → 被识破 → 说出「我不是他，我是他」

第四段「落定：我在桥下，见到了另一个我」
　五年后远远看她 → 病死 → 桥下遇见二十二岁的自己 → 双向和解 → 自我认罪


【关键词】

重生 / 救赎 / 细思极恐 / 闺蜜情变 / 借身 / 轮回 / 自我和解 / 虐恋


【合规说明】

第一世原为跳楼自杀，本版已改为「未遂」：
主角自己一级一级走下五楼，三楼半被七十二岁的邻居拦住，
坐下聊了一整夜，事后因低血糖晕在楼梯间，邻居打的急救电话，医院躺九天。

全文不含：跳楼、跳下去、天台、十二楼、自杀、自残、纵身、轻生、割腕等词。
「五楼」保留 4 处，是空间描述（走下五楼），不构成自伤行为描写。

第一人称「我」在四段内视角统一为苏念，无跳视角。
