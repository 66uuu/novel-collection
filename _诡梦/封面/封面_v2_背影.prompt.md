## 一、优化后的中文提示词（自然语言模式，按维度分层）

一句旧木门独自立在黄昏的红泥地里，门框在它身后以不可能的角度重复了三次，一次比一次虚、一次比一次淡，整张图像在不停地复制自己并且复制失败。门槛的青石上摆着一双沾满湿红泥的旧球鞋，泥从鞋底一直拖到地上，一串红色脚印以松散的螺旋往外走，最后又绕回原处。门只开了一半，里面没有房间，是一条夜里被雨浇透的城市柏油路，路的尽头亮着一盏冷白的路灯；门框上方的天花板裂开一道发丝般的细缝，形状像一小段向上的楼梯。左侧来的是冷蓝灰的黄昏光，门缝里漏出一小片昏黄的灯，其余全被黑吞掉。画面诡异而神秘，是一种说不上哪里不对的安静失常：地平线断裂、所有物体都歪三到五度、边缘有淡淡的双重曝光重影、灰尘悬浮、墨色在四角洇开、细胶片颗粒。极简文艺封面，独立电影海报质感，高细节数字绘画，文字全部落在中心安全区内。

## 三、设计说明

| 画面元素 | 对应小说情节 | 作用 |
|:---|:---|:---|
| 沾满湿红泥的旧球鞋 | 午睡醒来鞋底有泥 | 核心物证，全篇的引信 |
| 门后不是房间而是一条城市马路 | 第 7 节开门换场 | 空间逻辑崩塌，最惊悚的一击 |
| 门框重复三次、逐层虚化 | 第 8 节真相：他可能回来过不止一次 | 用重影暗示循环，不剧透 |
| 天花板发丝裂缝走成楼梯 | 无出口房间、11 级向上楼梯 | 藏得最深的彩蛋 |
| 红泥脚印螺旋绕回原处 | 结尾「我回去一趟」 | 走出去又走回来，闭环 |
| 地平线断裂 / 全体倾斜 3–5° | 认知崩塌 | 「混乱无序」的主要来源 |
| 冷蓝灰 + 血红 + 一点昏黄灯 | 悬疑 noir 配色 | 诡异但不血腥 |

「混乱无序」不靠堆元素，靠三件事：**重复**（门框复制）、**失衡**（整体倾斜、地平线断）、**重影**（双重曝光、墨色洇边）。这样乱得克制，不会变成噪音。
