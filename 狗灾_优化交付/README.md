## 二、这次做出来的东西

### 1. 框架 vs 正文，缺口已定位

你口述的框架共 21 个情节要点，现有桌面正文（12 章 17738 字）落地 17 个，**2 个有偏差、2 个缺失**：

- ❌ **缺失最严重**：框架里的「请先生布阵法引诱 → 备陷阱 → 道士拿桃木剑诛杀」**整条线一个字都没写**。这导致全片变成「所有人只能等死」，人类从未主动出击过一次。
- ❌ **缺失**：框架要求的「少量第三人称视角增强诡异感」，正文**一段都没有**，12 章全是「我」。
- ⚠️ 偏差：框架顺序是「二叔死 → 请先生 → 先生死」，正文写成了「先生先来 → 二叔死 → 先生死」，中间缺一个解释。
- ⚠️ 偏差：框架的 1–2 万字没问题（17738 字达标），但「开场必须吸引人」这条靠第一句「我家的狗在监控里站起来了」已经做到了。

### 2. 9 条逻辑漏洞，全部给了修法

| 编号 | 漏洞 | 严重度 | 修法 |
|---|---|---|---|
| L1 | 先生布阵/道士桃木剑整条线缺失 | 致命 | 拆成两个角色：第一位先生布场埋镇物（下陷阱），第二位道士带桃木剑赴死，爷爷最后空着手出门。三次主动出击三次失败，绝望层层加码，且完全符合原框架 |
| L2 | 三枚铜钱失效是空降反转 | 严重 | 在等待那一夜加一处小异常：半夜摸到铜钱**第一次是温的**，他当成捂热的错觉；再摸又凉了。结尾回收变"我早就摸到过" |
| L3 | 红布包只出现一次就消失 | 严重 | 绑死因果：红布包里就是三枚铜钱 → 爷爷锁进木匣 → 狗窝底下翻出 → 爷爷说"这是先生留下的最后一样东西" |
| L4 | 先生与二叔死亡顺序无解释 | 中 | 加一段主角推测（不给答案）："那天晚上它不是没有事，它那天是有事" |
| L5 | 警察两次出现后彻底消失 | 中 | 只加一句，越荒诞越好：主角拨 110 说"我村有人不见了"，对方问他是不是喝多了 |
| L6 | 第三人称视角缺失 | 中 | 强制加两段非第一人称：① 监控视角纯白描（约200字）② 河面打捞视角（约200字），越平越瘆人 |
| L7 | 二叔只是个死人，没有活人感 | 中 | 把"你爷爷那条狗，埋了没"从回忆提到现场演一次 |
| L8 | 监控时间线说不通 | 轻 | 补半句：爷爷的耳朵先察觉，监控后来才补上，因此错过了前几夜 |
| L9 | 三枚铜钱缺民俗锚点 | 轻 | 补一句：「三枚是三钱，天地人，一枚都不能少。少一枚，它就少一条道。」 |

成稿实测 **18320 字**，落在框架要的 1–2 万字区间内。

### 3. 过审部分不是"少写血腥"，是换一套写法

番茄查得严的是**过程描写**，松的是**结果陈述**。所以给的是 23 条替换对照 + 六种替代手法：

- 只写"少了什么"，不写"多了什么"
- 用器物的凌乱代替伤害的痕迹（二叔家全程 0 血腥：摆齐的鞋、吃到一半的面、三个未接来电、叠好的被子、地上"一层暗色，从门槛一直铺到墙根"）
- 用气味代替画面（"铁锈味"，不用"血腥味"）
- 用"没有"代替"有"（"全村能叫的狗都叫了，一只都没少。可我家院子里空荡荡的，只有风声。"）
- 用人物的错误反应制造诡异（王婶停下、慢慢转过来、睁着眼睛里面什么都没有、看了三秒、转回去继续走）
- 不给怪物感，只给人感（它的可怕是**在学人笑**、**回头看镜头**、**在等我认出它来**）

还给了**三条必须改的硬项**：
1. 第 06 章标题「二叔被剥了皮」→「二叔没在家」
2. 备选书名「它穿上了我二叔的皮」删掉或排最后
3. 作者按首句「这不是一个鬼故事」→「这不是一个关于怪物的故事」

写完后用第 4 节那几条 `grep` 命令**实际检索 txt 确认**，不是凭印象。
