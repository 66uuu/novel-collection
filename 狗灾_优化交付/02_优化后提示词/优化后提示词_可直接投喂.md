# 任务：把《狗灾》口述框架写成一篇可直投番茄小说的 1–2 万字恐怖短篇

> **【已执行 · 成品位置】** 本提示词已用 story skill（story-short-write 四阶段流程）实际跑通，
> 成品在 **`狗灾_优化交付\04_完整成稿\`**：正文 18228 字 / 12 章 / 门禁全过。
> 下面第 7 节的落盘路径是提示词原本的约定，实际落点为 `04_完整成稿`。



## 1. 角色与目标

你是一位专写民俗恐怖长篇的网文作者，同时熟悉起点/番茄的审核规范与读者偏好。

你的目标：把下面这份口述框架，扩写为一篇**总字数 18000–20000 字、12 章、第一人称为主**的恐怖短篇小说，**可直接发布到番茄小说且能通过审核**，同时不改动原故事的任何情节走向、人物关系和结局。

衡量标准（全部满足才算完成）：
- 正文总字数落在 18000–20000 字之间（不含简介与作者按）
- 12 章，章末均有钩子
- 情节与本提示词第 3 节「情节时间线」逐条对应，无增删关键事件
- 全文零违规词、零血腥细节过度描写（见第 5 节）
- 不存在任何"读者会问但作者没答"的逻辑硬洞（见第 4 节）

## 2. 背景与上下文

- 目标平台：番茄小说，分类为「都市 › 悬疑 › 恐怖灵异」
- 读者画像：偏好第一人称、日式/中式民俗怪谈、第一人称代入感强的短篇；单章读完约 2 分钟
- 作者原话要求（**最高优先级，覆盖任何冲突的写作建议**）：
  - 写成短篇，1–2 万字，**严格按情节**，不许增删主线事件
  - 恐怖元素**尽量合理化**，把逻辑漏洞磨平
  - **必须过审**（番茄）
  - **不要用骗**——不许骗读者情绪、不许反转翻车、不许用"其实是个梦"这类廉价解法
  - 语言**敏感**，说过程，不喊口号
  - **原汁原味还原**，参考其他恐怖小说的语法与表达习惯
  - **整体第一人称**，可加**少量第三人称视角**描写以增强诡异感、凸显狗精的未知属性
  - 按**恐怖小说网文标准**写开头，务必吸引人
- 已有的核心创意（**这是本书最值钱的东西，绝对不能改**）：
  这不是一个复仇故事，是一个**"它想变成人"**的故事。它做的每一件事，都只是想站起来、走出去、站到人跟前。它没有做错什么。它只是，比人更像人了。

## 4. 必须执行的逻辑修补（原稿的 9 个洞，逐条填）

以下每条都是"读者一定会问、必须答"的问题。写作时按此处理。

### L1【最重要】先生"布阵引诱 → 陷阱 → 道士桃木剑诛杀"这条线不能丢
- 框架明确写了"请先生布阵法引诱狗精、备陷阱，最后由道士拿桃木剑诛杀"。
- 解决方案（**采用方案 A**）：把"先生"与"道士"设为两个人。
  - 第一位先生（第14–15节点）：来踩点、布场子、埋镇物、挂黄纸、下陷阱，叮嘱"三日之内"。他布置的**场子在第22–24节点之间被它破掉**——第一次反击失败。
  - 第二位道士（第28节点之前登场，带**桃木剑**）：爷爷重金请来的，来了就说"你爷爷说得对，它不是畜生"，然后出村布置。**第28节点他独自去赴死**，桃木剑断成两截。
  - 这样"人类主动出击"存在过三次（先生布阵 → 道士桃木剑 → 爷爷空着手出门），三次都失败，绝望感层层加码，且完全符合框架。

### L2 三枚铜钱的失效必须有铺垫
- 在**祖父出门后的那一夜**（节点29）加一处极小的异常：
  - 主角半夜摸铜钱，**第一次摸到是温的**。他当成是自己捂热的错觉，还安慰自己"没事，是热的"。
  - 再摸一次，**又凉了**。他不敢再想。
- 节点37的回收因此变成"我早就摸到过一次"的醒悟，而不是空降反转。

### L3 红布包不能悬空
- 红布麻绳包（先生留下的）必须与铜钱绑死因果：
  - 第14节点先生给的红布包里是**三枚铜钱**。
  - 爷爷把它们锁进木匣子，写"用早了就废了"。
  - 第08节点主角在狗窝底下翻出这个包（它是从木匣子里掉出来被塞进狗窝的，或先生走时顺手留在院里的），交给爷爷。**爷爷看了一眼，说"这是那位先生留下的最后一样东西"**，然后才在第28节点取出来给他。
- **不要保留任何"只出现一次就消失的道具"。**

### L4 先生与二叔的死亡顺序要有解释
- 框架顺序是"二叔死 → 请先生 → 先生死"，正文写成了"先生来 → 二叔死 → 先生死"。
- 修补：在先生死的那一章补一段主角的推测（**不必给出答案**）：
  > "那天晚上它没叫。一声都没叫。我后来想，它那天不是没有事，它那天是有事——它先去办了一件事，那件事跟二叔有关。"
- 让"随机杀人"变成"按顺序办事"，符合"它在攒衣服/攒皮"的整体逻辑。

### L5 警方消失要有交代
- 二选一，只加一句，越荒诞越好（**推荐第二种**）：
  - A：「后来听说管这个的调走了，现在来的不问旧账。」
  - B：主角拨了110，说"我村有人不见了"，对方问他是不是喝多了。**用荒诞代替解释。**

### L6 少量第三人称视角（本提示词强制要求，原稿没有）
- 全书大部分是"我"，但**必须有两段跳出"我"**，共 300–500 字：
  1. **监控视角段**（约200字）：纯客观白描，只写画面里有什么、几点几分，它从哪个方向来、做了什么。没有"我"，没有情绪词，像监控回放。**越平越瘆人。**
  2. **河面视角段**（约200字）：先生尸体被打捞上来的那一段。不出现"我"，不出现"它"，只写环境与在场者的动作——"捞上来的东西是硬的，手脚都蜷不回去"、"岸上没人说话"、"玉米地里的叶子响了一下，没人回头"。
- 这两段是全书最出彩的地方，必须写，且必须**不加任何解释性文字**。

### L7 二叔必须先是个活人
- 把第19节点那句关键台词**从回忆提到现场**：在第11–13节点之间，给二叔一段活人的对话，他当着主角的面问：**"你爷爷那条狗，埋了没？"** 主角当时以为他只是好奇。
- 这样节点18的剥皮才有重量，节点19的回响才成立。

### L8 监控时间线
- 明确写一句：爷爷的耳朵先察觉不对，主角的监控是后来才补上的，**因此错过了前面几个夜晚**。
- 不需要改任何事件，只需在节点3补半句。

### L9 三枚铜钱的民俗锚点
- 节点16补一句爷爷的解释：「三枚是三钱，天地人，一枚都不能少。少一枚，它就少一条道。」
- 这一句同时解释了：为什么是三枚、为什么中间那枚带孔、为什么必须全挂上。

## 5. 番茄过审用词规范（硬性，逐条替换）

### 5.1 一律禁止出现的词（无论任何理由、任何上下文）
> 剥皮、剥皮抽筋、活剥、放血（作动词）、割喉、掐死、勒死、奸淫、性、器官、内脏、肠子、血糊、尸块、碎尸、吃人、啃食人肉、开膛

### 5.2 必须替换的表达（用右列，不得使用左列）

| 原写法 | 改为 |
|---|---|
| 被剥皮 / 皮被剥下来 | 「皮被完整地取走了，一件都没剩下」/「像一件被脱下来的衣服，摊在那儿」/「像被从里到外抽走了」 |
| 剥皮拆骨放血 | 「收拾干净了，挂在横木上」/「吊在横木上，血往下淌」 |
| 手筋被挑断 | 「两条胳膊的筋，一根一根断了」/「手腕上的筋被一根一根挑开」 |
| 血流干了 | 「血全流尽了」/「身上再没有一处是湿的」 |
| 脖子上的口子很深，骨头都能看见 | 「脖子上一个口子，深得能看见里面」 |
| 眼睛瞪得特别大，眼珠子…… | 「眼睛睁着，特别大，像是死前想喊没喊出来」/「那双眼睛到死都没闭上」 |
| 咬断脖子放血 | 「咬断脖子，就那么扔在原地，一口没动」 |
| 尸体（指人） | 「那个人」「他」「捞上来的东西」（**必须用）** |
| 死（作动词） | 「没了」「走了」「没回来」「那块石头」/「警察先挂着」 |
| 血（作名词） | 「血」**可用**；但**禁止**修饰为「鲜血淋漓」「血流成河」「血浆」 |
| 狗精、妖、鬼、僵尸、狐狸精 | **全部禁用**。只写「它」「那个东西」「站起来的那个东西」「长着两条腿的影子」 |

### 5.3 恐怖感替代策略（本项目专用，重要）
番茄审核对**血腥细节**查得严，对**氛围与暗示**几乎不管。所以本书的恐怖必须靠以下手段实现，**不得靠血腥描写**：

1. **只写"少了什么"，不写"多了什么"**
   - 写「它把整张皮都取走了」，不写「它怎么剥的」。
   - 写「碗里的面汤凝了一层」，不写「血把地砖缝填满」——**这一句要改**，原句"血把地砖缝都填满了"属于血腥描写，必须换成不涉及血的写法。
2. **用器物的凌乱代替伤害的痕迹**
   - 二叔的鞋摆得整整齐齐、鞋头朝里；面吃到一半没吃完；筷子搁在碗沿；手机有三个未接来电。**凌乱即恐怖**，比血腥有效十倍。
3. **用气味代替画面**
   - 「铁锈味」（不是血腥味）；「底下压着一股狗身上的味道，我从小闻惯了的」。
4. **用"没有"代替"有"**
   - 「全村能叫的狗都叫了，一只都没少。可我家院子里空荡荡的，只有风声。」
   - 「一整条路上全是脚印，一层叠着一条。」——**这里"全是脚印"本身就是恐怖，不必加任何修饰**。
5. **用人物的错误反应制造诡异**
   - 王婶转过来看主角三秒，眼睛睁着，里面什么都没有，**然后转回去继续走**。
   - 这个"她礼貌地看了我一眼"的错位感，比任何血腥描写都强。
6. **不给它任何"怪物感"，只给"人感"**
   - 它的可怕不是獠牙绿眼，是它**在学人笑**、**它回头看镜头**、**它在等我认出它来**。

### 5.4 绝对不许做的三件事（框架明确"不要用骗"）
1. **不许翻车**：不许在结尾用"其实是一场梦""其实是幻觉""真正的凶手是人"来反转。真相就是它想变成人，不许推翻。
2. **不许廉价救赎**：不许让主角死里逃生、不许让爷爷活着回来、不许天亮后一切恢复。
3. **不许卖惨凑字数**：不许靠虐主角、虐爷爷、堆苦难来凑 2 万字。凑字数只能靠**氛围、留白、和"我后来才明白"式的回响**。

## 6. 写作风格规范

### 6.1 视角与人称
- 第一人称"我"（南南），过去时叙述。
- **仅两处**切换为非第一人称视角（第 4 节 L6），切换时不加任何过渡语，不加"如果用另一个角度看"这类引导句，直接进入客观白描。
- 老人、先生的证词全部用**转述体**："他说，……" "他跟我讲，……"，保留口语的重复与不完整（"他说他不知道自己能站多久"）。

### 6.2 句式与节奏（参考国内优质民俗恐怖短篇的语法习惯）
- 大量使用**短句独立成段**，一段一到两句。
- 常用句式（照此节奏写）：
  - 「我到现在也说不清那一幕。」
  - 「我想起来一件事。我不敢往下想。」
  - 「我把这个念头咽回去了。」
  - 「后来我想，那是另外一件事。」（**延迟解释，制造层次**）
- **忌**：长段落、书面语、成语堆砌、抒情议论、心理活动大段铺陈。
- **忌**："我毛骨悚然""我汗毛倒竖"这类成语式恐怖——本书的恐怖全部靠"白描 + 错位"。

### 6.3 恐怖三级递进（全书必须严格遵守这个层级）
1. **第一级·生理不适（第01–03章）**：不流血、不死人。只写"它站起来了""横木空了""它回头看镜头"。**越平静越好。**
2. **第二级·失控（第04–09章）**：死人、丢东西、悬案。开始出现"不合理"但都还在人的世界里。恐怖来自"事情对不上"。
3. **第三级·规则（第10–12章）**：出现超自然规则（梦咒、铜钱、它有皮）。**从这一章起，恐怖不再是"发生了什么"，而是"规则是什么、你还守不守得住"。**

### 6.4 禁止的写法（明确）
- 禁止在正文里插入"作者有话说""求票""感谢支持"。
- 禁止在章末写"未完待续"以外的元叙述。
- 禁止用"细思极恐""细思脊背发凉"这类网络梗。
- 禁止让主角在最后一段忽然变得冷静客观做总结——**最后一句必须是"它压下来了。"**
