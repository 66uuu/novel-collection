## 1. 一律禁止出现的词（零容忍）

以下词汇**无论出现在任何上下文、任何时态、任何引号内，一律不许写**：

```
剥皮      剥皮抽筋   活剥      放血（作动词）
割喉      掐死      勒死      奸淫
性        器官      内脏      肠子
血糊      尸块      碎尸      吃人     啃食人肉
开膛      狗精      妖        鬼
僵尸      狐狸精    鲜血淋漓  血流成河
血浆      腐肉      尸油
```

**注意"鬼"字**：本书主题极易顺手写成"跟鬼一样"。**禁用"鬼"**，改用"跟人不一样""那个东西"。

## 3. 恐怖感替代策略（比换词更重要）

审核对血腥细节严，对**氛围与暗示**几乎不管。本书的恐怖必须靠以下手段实现：

### 3.1 只写"少了什么"，绝不写"多了什么"
- ✅「它把整张皮都取走了」
- ❌「它怎么把皮剥下来的」

### 3.2 用器物的凌乱代替伤害的痕迹
二叔家的场景全部靠这几样东西撑起来，**一句血腥描写都不要**：
- 门口一双鞋，摆得整整齐齐，鞋头朝里
- 前堂一碗没吃完的面，筷子搁在碗沿，面汤凝了一层
- 桌上手机亮着，三个未接来电，都是当天早上的
- 床上被子叠得整整齐齐
- **地上一层暗色，从门槛一直铺到墙根**

### 3.3 用气味代替画面
- 「铁锈味。底下还压着一股别的，说不出来。」
- 「血腥味很重。但底下压着另一股味，是狗身上的味道。我从小闻惯了的。」

### 3.4 用"没有"代替"有"
- 「全村能叫的狗都叫了，一只都没少。可我家院子里空荡荡的，只有风声。」
- 「一整条路上全是脚印，一层叠着一条。赤脚，五个趾头，人的脚。」

### 3.5 用人物的错误反应制造诡异
王婶这一段是全书错位感的顶点，**一个字都不要改**：
> 王婶停住了，站在那里。她没有回头，就站在路中间，背对着我。
> 我等了一会儿。
> 然后她的头，慢慢地，往这边转了过来。
> 我看见她的脸。她的眼睛是睁着的，可是里面什么都没有。她看着我，看了大概三秒钟。
> 然后她又把脸转回去了，继续往前走。

"她礼貌地看了我一眼"——这个错位比任何血腥描写都强。

### 3.6 不给"怪物感"，只给"人感"
它的可怕不是獠牙绿眼，是它**在学人笑**、**回头看镜头**、**在等我认出它来**、**穿着一件一件攒的衣服**。

**作者按里的核心句必须保留：**
> 这不是一个鬼故事。（⚠️ 注意：此处"鬼"字需改）
>
> 改为：**这不是一个关于怪物。这是一个关于"它想变成人"的故事。**

## 4. 写完后的实际检索命令（Windows / Bash）

在正文 txt 所在目录执行，**逐条确认返回 0 处**：

```bash
cd "<DESKTOP>/狗灾_优化交付/04_完整成稿"

echo "=== 1. 一级禁用词 ==="
grep -o -n -E "剥皮|活剥|放血|割喉|掐死|勒死|奸淫|器官|内脏|肠子|血糊|尸块|碎尸|吃人|开膛|狗精|僵尸|狐狸精|鲜血淋漓|血流成河|血浆|腐肉" 狗灾.txt | wc -l

echo "=== 2. 敏感单字（鬼/妖/性/尸）逐个查 ==="
for w in 鬼 妖 性 尸; do printf "%s: " "$w"; grep -o "$w" 狗灾.txt | wc -l; done

echo "=== 3. 血腥修饰词 ==="
grep -o -n -E "血糊|血淋淋|血浆|血肉|骨茬|断肢" 狗灾.txt | wc -l

echo "=== 4. 元叙述检查（应为 0） ==="
grep -o -n -E "作者有话说|求票|求订阅|细思极恐|未完待续|，本文" 狗灾.txt | wc -l

echo "=== 5. 正文字数（不含书名简介区） ==="
sed -n '/第01章/,$p' 狗灾.txt | wc -m
```

**验收标准：**
- 第 1 项 = 0
- 第 2 项中「鬼」「妖」「尸」= 0；「性」= 0（正常中文里极少出现，若有须人工确认）
- 第 3 项 = 0
- 第 4 项 = 0（"未完待续"若要保留，仅限 txt 末尾、正文外）
- 第 5 项落在 18000–20000 区间

## 5. 审核风险自评（诚实披露）

| 项目 | 风险等级 | 说明 |
|---|---|---|
| 剥皮意象 | **中** | 本书核心恐怖意象，无法回避。已全部改为"被完整地取走了""像被脱下来的衣服"这类**暗示性表述**，不写过程、不写工具、不写痛感描写。番茄对"过程描写"查得严，对"结果陈述"较松。 |
| 掐脖子致死的血 | **中** | 脖子上的口子已改为"深得能看见里面"，不写深度数值、不写伤口形状。 |
| 三层人皮意象 | **中** | 用"像一件被脱下来的衣服"处理，不使用"皮"字与人体部位的组合。 |
| "它不是人"设定 | **低** | 本书写的是动物成精但**不写妖术、不写法术**，只写"站起来的狗"。 |
| 章节名"二叔被剥了皮" | **高** | ⚠️ **必须改**。建议改为「二叔没在家」/「二叔的鞋」/「屋里少了一个人」。 |
| 书名"它穿上了我二叔的皮" | **高** | ⚠️ **不建议用作主书名或副标题**。保留在备选里但排在最后，或直接删除。 |
| 结尾主角疑似被害 | **低** | 框架指定戛然而止，停在"它压下来了"，不写受害过程。 |
| police / 悬案描写 | **低** | 只写"先挂着""不问旧账"，不影射任何具体单位与人名，无涉政风险。 |

**三条必须改的硬项：**
1. 第 06 章标题「二叔被剥了皮」→「二叔没在家」
2. 备选书名 3「它穿上了我二叔的皮」删除或降到最后
3. 作者按第一句「这不是一个鬼故事」→「这不是一个关于怪物的故事。这是一个关于"它想变成人"的故事。」

## 6. 封面图过审要点

- ✅ 可用：夜色村道、远处高瘦深色人形轮廓、赤脚、一串脚印朝远处去、大字书名压构图
- ❌ 禁用：人脸特写、任何皮剥落画面、血、内脏、尸体、人与动物拼接感、真实动物照片改造成人形的图
- 推荐：一张**背影远景**，人形轮廓只到剪影程度，看不出五官，画面 70% 是黑，书名用白色大字压在下方三分之一处
- 尺寸 1080×1440（番茄封面推荐比例 3:4）
