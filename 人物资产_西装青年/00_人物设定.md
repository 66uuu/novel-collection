## 五、怎么用

**出单张图**

```bat
cd /d "<DESKTOP>/AI生成视频\11_本地工具接入指南\bridge"
python nr_bridge.py t2i --prompt "1boy, male focus, pale skin, ash brown layered hair, long bangs, black three piece suit, <动作/场景>, 3d render, cg, semi realistic" --width 512 --height 768 --steps 30
```

**保脸换场景**：用 `build_t2i_ref()`，`ref_weight` 取 0.45–0.55，并且**不要再在提示词里写长相和服装**（会跟参考图打架，导致换脸）。

**出视频**：首帧用 `01`/`03`/`04` 任意一张，`build_i2v` 的 prompt 只写「动作 + 声景 + 配乐 + 镜头」，同样不写长相服装。

## 六、这次调出来的经验（踩过的坑）

| 现象 | 原因 | 解法 |
|---|---|---|
| 画成女性 | SD1.5 人像模型对 `blond` 强偏向 | 必须写 `1boy, male focus`，反向词加 `1girl, female, long hair, makeup` |
| 一个人画成两张（双联画） | 用了 512×896 这种瘦长尺寸 | 改回 **512×768**；反向词加 `split screen, multiple views, two people` |
| 裁到膝盖、没有鞋 | 只写 `full body` 不够 | 必须加 `head to toe, feet visible, wide shot` |
| 侧身永远是 3/4 正面 | IPAdapter 把构图拉回参考图 | 侧身权重压到 **0.14**，并写 `ear visible, nose silhouette` |
| 背面变正面 | 同上 | 背面改用**面部**参考图 + 权重 **0.20**，人脸不出镜时文字描述足够 |
| 黑西装漂成灰色 | 提示词里 `suit` 太笼统 | 写 `black suit jacket, black trousers`，反向词加 `grey suit, white suit` |
| 画面里冒出柜子/桌椅 | 模型自己加道具 | 反向词加 `furniture, cabinet, table, chair` |

## 八、已知限制

- 本机只有 SD1.5（512×768），**做不到真正的 90° 正侧脸全身**，`05` 是 3/4 侧身。
- 角色一致性靠 IPAdapter，不是 LoRA。跨镜头换机位仍会有 10–20% 的相貌漂移，
  正式出片前建议用 `drift_check.py` 抽检。
- 想要真正锁脸，需要训一个角色 LoRA（15–30 张同角色图）。
