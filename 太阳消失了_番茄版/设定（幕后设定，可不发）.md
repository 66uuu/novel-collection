# 《太阳消失了》设定与逻辑核查

## 一、核心设定

| 项 | 内容 |
|---|---|
| 事件 | 太阳在本地时间 08:40:00 从宇宙中消失（不是熄灭，不是被遮挡，是"位置上什么都没有了"） |
| 伴生事件 | 同一瞬间，三家引力波台收到一个持续 0.3 秒的信号 |
| 时间锚点 | 08:40 —— 太阳消失的那一秒，也是顾南睁眼的那一秒 |
| 循环长度 | 08:40 → 约 11:00（缺氧死亡），约 140 分钟 |
| 循环机制 | 顾南的意识被"想活下去"这个念头锚定在这 140 分钟里，死亡即回到 08:40 |
| 记忆机制 | 循环对所有人都生效；所有人的记忆每天被洗一遍，只有顾南洗不掉（他"记性太好"） |
| 留痕机制 | 一切物质痕迹都会重置。墙上的字、手背的伤、手机备忘录、截图，全部消失。只有记忆能带过去 |
| 出口条件 | 不带任何目的地放弃 —— 不是"拿命换出口"，是"什么都不想要了" |

## 二、逻辑漏洞与修补（全部已写进正文）

| # | 漏洞 | 修补 | 落在哪一章 |
|---|---|---|---|
| 1 | 太阳消失两小时内就缺氧，物理上不成立 | **把"不成立"本身变成恐怖点**。沈砚在新闻里明说：按已知物理这个过程要几百万年，"现在只用了两个小时，我算过三遍"。结论是"我们熟悉的规则从八点四十开始不管用了" | 第4章 |
| 2 | 为什么只有顾南记得？ | **用开篇第一句"我记性太好"回收**。循环对所有人生效，别人的记忆每天被洗干净，所以每天都是第一次；他记性太好，这一天在他脑子里抹不干净 | 第1章埋，第11章收 |
| 3 | 为什么循环从 08:40 开始？ | 双重锚定：08:40 既是太阳消失的物理时刻，也是他睁眼的时刻。他是在那一秒唯一睁眼（抬头）的人 | 第1、11章 |
| 4 | 前面自杀多次都没用，为什么最后跳楼就出去了？ | **区分"想出去"和"算了"**。第9章埋：他每一次死之前心里都在喊"让我出去"，那是拿命换票，还是"想要"；第11章收：最后一次他什么都没想，只是累了 | 第9章埋，第11章收 |
| 5 | 世界会重置，那他写在墙上的字为什么能留到下一轮？ | **改成留不住**。墙上的字第二天是白的，手背的伤长好了，备忘录空了，截图没了。他因此确认：能带过去的只有脑子。这一改反而更狠 | 第8章 |
| 6 | 他躲在屋里为什么还是死？ | 缺氧是全球性的，躲进盒子只是换个地方死。第9章补了氧气罐、封死地下室两次尝试，明确"空气在往外跑，谁都拦不住" | 第6、9章 |
| 7 | 别人看不见黑，为什么还能正常生活（出汗、说天蓝）？ | 认知被整体改写，只有他被踢出共识。加了两处硬证据：他拍的黑色照片，老陈看了说"天亮堂"；背书包的小孩说天是蓝的 | 第3章 |
| 8 | 停电停网了怎么还能刷手机？ | 两小时内电网有惯性，信号逐步衰减。第5章明写"有人在打电话，打不通，举着手机到处走，找信号" | 第5章 |
| 9 | 结尾是"真醒"还是"又一个梦"？ | 刻意留白。用 0.3 秒引力波信号的新闻推送做钩子——那件事也许真发生过，也许只是巧合。不给答案 | 第4章埋，第12章收 |
| 10 | 为什么他循环这么多次，精神还没彻底崩？ | 给出缓冲：他靠"记住每一个人"活着（第10章），靠每天买一杯豆浆维持住自己还是个人 | 第10章 |
| 11 | 日出时间与原始素材不符 | 原始素材写"六点多就该天亮"，正文与天气 App 统一改为 06:04 | 第2、3章 |

## 四、审核风险自查

- 无血腥描写：死亡过程只写生理感受（发麻、发黑、气短），不写伤口、不写尸体细节
- 自杀情节：全部为"循环内无效死亡"，且明确服务于"挣脱循环"的主题；结尾落在求生与珍惜日常，导向正向
- 无宗教、无迷信；"天体物理研究所"为虚构机构
- 无政治敏感内容
- 无未成年人受害情节（背书包的小孩仅作为认知错位的对照组出现）
