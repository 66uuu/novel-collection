## 发布步骤（番茄小说）

1. 打开番茄作家助手 → 新建作品 → 短篇 → 频道选"惊悚/灵异"，标签勾 #无限流 #空间循环 #中式恐怖 #细思极恐
2. 上传 `03_封面/封面_无限鬼屋_番茄上传600x800.png` 作为封面
3. 书名填"无限鬼屋"，一句话介绍照抄简介包里的"一句话卖点"
4. 正文从 `01_正文/无限鬼屋_番茄发布版.txt` 复制（简介单独贴进简介栏，正文从"第一章"开始贴）
5. 发布方式二选一：整篇一次发（推荐）；或按 6 章分天发，每章尾自带钩子
