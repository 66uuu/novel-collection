# 第四百四十二章 在上界，符咒变成了什么

林述把十二符咒亮出来。

在上界，它们不一样了。

不是发光。

是"响"。

十二个声音。

牛的声音，是闷的。

兔的声音，是轻的。

龙的声音，是长的。

一个一个，像在点名。

"它们在说话。"旺财说。

"对。"

"说什么。"

"说它们是谁。"林述说。

"谁。"

"它们是圣主的一部分。"林述说。

"但在这儿，"林述说，"它们不是圣主。"

"它们是我。"

"为什么。"

"因为这层是'上面'。"林述说。

"上面认的不是谁造的。"

"上面认的是'谁在用'。"

"上辈子，"林述说，"公司资产都登记在公司名下。"

"但一台电脑，谁天天用，就是谁的。"

"别人碰一下，你都心疼。"

"这个道理，"林述说，"上面也认。"

"所以十二符咒，在这儿，是我的。"

"不是圣主的。"

"它们一亮，"林述说，"圣主就感觉到了。"

"感觉什么。"

"感觉它身上，"林述说，"少了十二块。"

"少的地方，"他说，"是空的。"

"空的地方，会疼。"
