# 第二百六十一章 门外的盟友

林述的队伍，凑齐了。

老符纹人，管账。

三个野符，能打，但没什么脑子。

还有一个，是"叛逃的符宗"。

符宗，持九符，能立域。放在门外，是顶尖战力。

"你为什么叛逃。"林述问。

"圣主要合并世界。"符宗说，"合并了，我娘就变成影了。"

"你娘在门那边。"

"对。"符宗说，"我娘是门那边的。"

林述看了他很久。

"行。"他说，"你跟我干。"

"你不怕我反水。"

"不怕。"林述说，"你要反水，早反了。"

他把地图摊开。

"十二个点。"他说，"我们一个个去。守符者那边，能谈就谈。谈不成，就抢圣主的。"

"上辈子带项目组，"他补了一句，"也是这么东拼西凑。人不多，能用就行。"

*（第二百六十一章 完）*
