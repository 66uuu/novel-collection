# 第四十七章 情报生意，我做起来了

林述的情报生意，是从一张A4纸开始的。

他打印了二十份，贴在咒术师常去的几个据点：便利店后门、任务大厅角落、某家拉面馆的墙。

内容是手写的：

【情报贩子。
- 咒灵温床位置（已核实）
- 诅咒师活动区域
- 上层未公开的'禁区'名单
一份一个价。先付定金，验货后补款。不看身份，不问用途。】

下面留了个一次性邮箱。

第一天，没人理。

第三天，邮箱炸了。

"你这写的什么。"旺财说。

"用户需求。"林述一条条看，"有人要温床位置，省得自己找。有人要诅咒师动向，保命。有人想知道'禁区'在哪，别误闯。"

"这些你哪来的。"

"西装漏的、旺财闻的、图书馆翻的、我自己跑出来的。"林述说，"信息这东西，我这儿攒了一堆，别人正缺。"

他把价格定得不高。一份温床情报，五千日元。一条诅咒师动向，两万。

一周后，他账上多了十五万。

"这不比接委托赚钱。"他跟旺财算，"接一单委托，四小时，一万二。卖一条情报，两小时整理，两万。时薪翻三倍。"

"你这算盘打得真响。"

"社畜的核心竞争力。"

生意做起来，麻烦也跟着来。有人开始查"情报贩子"是谁。有人想白嫖。有人想砸场子。

林述早想到。他从不露面，只走邮箱。交货用死信箱，收钱用一次性账户。

"你这套，"旺财说，"跟谍报一样。"

"上班学的。"林述说，"前公司做项目的，都知道怎么留一手。"

他把今天的收入记本子：

【情报生意：本周净入十五万。客户七家。无身份暴露。】
【风险：有人在查我。暂时安全。】

他合上本子。这世界认实力，但他找到了另一个词——稀缺。

他掌握的信息，别人没有。这就够了。

*（第四十七章 完）*
