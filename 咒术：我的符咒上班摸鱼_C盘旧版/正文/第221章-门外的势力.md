# 第二百二十一章 门外的势力

林述花了一个月，摸清门外格局。

【门外势力】
【1. 圣主：被锁在中央。信众遍布。】
【2. 信众（符纹人）：靠借圣主符力活着。人数最多。】
【3. 持符者：自己持有符的人。少，强，不受圣主控制。】
【4. 影：符力凝结的怪物。中立，危险。】
【5. 中立区：少数不信圣主、也不持符的地方。弱小。】

"持符者，"林述说，"是我的同类。"

"但你不受圣主控制。"旺财说。

"对。"林述说，"因为我的符，是我融的，不是借的。"

"那其他持符者呢。"

"不知道。"林述说，"有的可能跟我一样，有的可能是圣主的'代理人'。"

他记本子：

【关键：找持符者。他们是我在门外唯一的潜在盟友。】
【风险：持符者里，有圣主的人。】

"旺财。"

"嗯。"

"门外第一件事：找人。"

*（第二百二十一章 完）*
