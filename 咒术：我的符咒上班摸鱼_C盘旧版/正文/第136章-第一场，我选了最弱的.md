# 第一百三十六章 第一场，我选了最弱的

回游第一场，林述挑了个最弱的对手。

一个二级咒术师，术式是"加速"，除了快，没什么本事。

"你挑他干嘛。"旺财问。

"试规则。"林述说，"第一场，我不为赢，为摸清回游的运行。"

他上去，牛符咒一拳。对方加速躲开，绕到他背后。

林述没追。他站在原地，等。

对方冲过来。林述开兔符咒，反手一肘。

对方倒了。

"就这么简单。"旺财说。

"对。"林述说，"二级的加速，快不过我兔符咒。"

但他没高兴。

因为他注意到，刚才打斗的时候，头顶的天，闪过一道光。

有人在看。

"暴露了。"林述说。

"什么。"

"回游是公开的。"林述说，"每一场，都有人看。我用了牛、兔，暴露了底牌。"

他皱眉。

规则战里，暴露底牌，就是最大的失误。

*（第一百三十六章 完）*
