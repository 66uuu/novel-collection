# 第九十五章 时间跳到十二年后

十二年。

林述站在高专的天台上，看着东京。

十二年前，他刚穿越，住杉并区的破公寓，在便利店搬货。

现在，他三十二岁。二级咒术师，牛兔两个符咒，一本记了十二年的账。

东京变了。高专变了。五条悟成了最强的象征，夏油杰的名字，成了禁忌。

而林述，还在这里。

"十二年了。"旺财说。

"嗯。"

"你头发白了几根。"

"用你管。"

林述摸了摸鬓角。确实有几根白的。十二年，不短。

他想起ch19那张时间表。十二年后那行，他画了个大圈，写"我的全部后手，从这天兑现"。

现在，这一天快到了。

"涩谷，"他说，"快了。"

"你怎么知道。"

"我记得。"林述说，"原著里，就是这段时间。"

他从怀里摸出本子。这本子，换了七本。第一本早写满了，锁在铁盒里。

现在这本，第一页写着一行字：

【倒计时：涩谷。】

下面是一串数字，一天一天划掉。

"你划了十二年。"旺财说。

"对。"

"累不累。"

"累。"林述说，"但值得。"

他合上本子，看天。

十二年前，他是个什么都不懂的社畜。

十二年后，他是个准备好了一切，只等那一天的咒术师。

"旺财。"

"嗯。"

"谢谢你陪了我十二年。"

"少肉麻。"旺财说，"罐头还没结呢。"

林述笑。

十二年了。游戏，要进入下一阶段了。

*（第九十五章 完）*
