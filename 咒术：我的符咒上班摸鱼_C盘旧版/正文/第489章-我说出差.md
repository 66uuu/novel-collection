# 第四百八十九章 我说，出差

"老师，出差累吗。"阿石问。

"累。"

"多累。"

"累到想哭。"林述说。

"那你哭了吗。"

"没有。"

"为什么。"

"因为没时间。"林述说。

"上辈子，"他说，"我加班到凌晨，特别想哭。"

"但哭要时间。"

"哭一次，得二十分钟。"

"二十分钟，够我改两个bug。"

"所以我就没哭。"

"后来攒着。"

"攒到项目上线那天，我一个人在楼梯间哭了半个小时。"

"哭完，洗把脸，回去开会。"

"开会的时候，谁也没看出来。"

阿石看着他。

"大人真辛苦。"

"对。"林述说。

"上辈子我当大人的时候，"林述说，"也觉得辛苦。"

"我以为是我一个人的问题。"

"后来发现，所有大人都这样。"

"只是没人说。"

"大家都装着没事。"

"装着装着，"林述说，"就真的习惯了。"

"习惯了，就不觉得苦了。"

"但不觉得苦，"他说，"不代表不苦。"

"只是麻木了。"
