# 第四百六十七章 关门要很久

门关得很慢。

慢到林述在那儿坐了很久。

"要多久。"旺财说。

"不知道。"

"那你坐着干嘛。"

"我得按着。"林述说。

"门不是自己关吗。"

"自己关，"林述说，"但它会反悔。"

"门会反悔？"

"会。"林述说。

"上辈子，"林述说，"我删过一个大文件。"

"删了，进度条走了一半。"

"停住了。"

"为什么。"

"因为有程序在用。"

"我得先把程序关了。"

"程序关了，进度条才走完。"

"所以我现在按着，"林述说，"是在等'程序'关掉。"

"什么程序。"

"圣主的'想'。"林述说。

"它不想被关。"

"它一直在使劲。"

"我按着，"林述说，"它使不上劲。"

"等它不使劲了，"他说，"门就关上了。"

"那要等多久。"

"等到它明白，"林述说，"使劲也没用。"

"人什么时候会停止挣扎。"

"当他发现，"林述说，"挣扎改不了结果。"

"上辈子我被裁过。"

"通知下来那天，我闹过。"

"闹了一个月。"

"一个月后我明白，"林述说，"闹，改不了名单。"

"改了名单，也改不了公司要走。"

"想明白那天，我就不闹了。"

"不闹了，我反而睡了个好觉。"
