# 第二百六十三章 旺财说了句人话

那天晚上，林述在算账。

算的是，抢完十二个点，得多少灵，得死多少人。

他算着算着，手停了。

"打不过。"他说，"怎么算，都打不过。"

旺财趴在旁边。

"我知道。"它说。

"你知道还跟着我。"

"对。"

林述低头看它。

"你图什么。"

旺财沉默了一会儿。

然后它说了一句，不像它的话。

"你别死。"

林述愣住。

"你死了，"旺财说，"我没地方去。"

棚里很安静。外面有风声，有影的低鸣。

林述低下头，眼眶有点热。

这狗，跟着他，从咒术世界，跟到门外。嘴上天天骂他，算计他，偷吃他的符核。

现在说了这么一句。

"我尽量。"林述说。

"你说尽量，"旺财说，"就是没把握。"

"对。"林述说，"但我会尽力。"

*（第二百六十三章 完）*
