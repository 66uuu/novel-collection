# 第一百零一章 涩谷，十万人

涩谷，十万人。

黑色的"帐"罩下来，把整个涩谷站和周边街区扣在里面。普通人在里面，出不去，也不知道发生了什么。

只有咒术师知道：这是陷阱。

林述站在人潮里，看着头顶那层黑。

"羂索。"他念出这个名字，"把十万人当饵，逼五条悟进来。"

"你怎么知道。"旺财问。

"我记得。"林述说，"这一章，我看了很多遍。"

他往涩谷站走。人群里，有尖叫，有推挤，有哭声。

"你打算怎么办。"旺财问。

"先干活。"林述说，"后手，一个一个放。"

他掏出手机。十七条线人的消息，一条条弹进来。

【东口：灰原到位。】
【西口：七海到位。】
【地下：情报网到位。】
【咒具：八件已分发。】

林述深吸一口气。

十二年了。

他等的这一天，来了。

"旺财。"

"嗯。"

"今天，我不当主角。"林述说，"我当那个，把主角们串起来的人。"

他钻进人群，往涩谷站深处走。

身后，十万人被困。头顶，黑帐压城。

前方，是一场注定要死很多人的仗。

而林述，带着他十二年的准备，走了进去。

*（第一百零一章 完）*
