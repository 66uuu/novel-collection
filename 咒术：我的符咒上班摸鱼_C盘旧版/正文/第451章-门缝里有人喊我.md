# 第四百五十一章 门缝里有人喊我

按到第二十一天，林述听见了声音。

不是圣主的。

是从缝里，传上来的。

很轻。

"林述。"

林述手一抖。

"谁。"

"我。"

是旺财的声音。

"你怎么在下面。"

"我没在下面。"旺财说。

"那你在哪儿。"

"我在你旁边。"

林述转头。

旺财就坐在他旁边。

"那你刚才喊我干嘛。"

"我没喊。"

林述愣了。

"那喊我的是谁。"

"缝里那个。"旺财说。

"缝里那个，不是我。"

"是'另一个'。"

"另一个什么。"

"另一个你。"旺财说。

"上辈子，"林述说，"我做过一个梦。"

"梦见另一个我。"

"他在一个格子间里。"

"敲着键盘。"

"我隔着屏幕看他。"

"他也看我。"

"他张嘴，说了句话。"

"什么话。"

"他说，'你替我把班上完了吗'。"

"我说，'没有'。"

"他说，'那你快点'。"

"我快下班了。"
