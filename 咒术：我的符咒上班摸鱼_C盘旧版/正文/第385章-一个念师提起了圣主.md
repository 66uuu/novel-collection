# 第三百八十五章 一个念师提起了圣主

来找林述打听消息的人里，有一个不一样。

他不问谁强谁弱。

他问一句：

"你知道'圣主'吗。"

林述手上一顿。

"听过。"他说。

"在哪儿听的。"

"忘了。"

"你撒谎。"那人说。

"对。"林述说。

"我不问你从哪儿听的了。"那人说。

"我问你，"他说，"你身上的东西，是不是圣主的。"

林述没答。

"你不用答。"那人说。

"我从你进门就闻到了。"

"闻。"

"念师闻念。"那人说。

"你身上的念，是'旧'的。"

"旧念不是自己修出来的。"

"是从别处来的。"

"能给你旧念的，"那人说，"只有一种东西。"

"圣主。"

林述看着他。

"你找圣主干嘛。"

"我不找。"那人说。

"我躲。"

"躲它干嘛。"

"因为圣主，"那人说，"不是神。"

"它是件东西。"

"一件有主人的东西。"
