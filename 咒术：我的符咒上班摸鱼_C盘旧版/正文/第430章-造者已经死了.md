# 第四百三十章 造者已经死了

林述在表上，找到了造者的名字。

"造者：造锁。状态：已完成。"

后面还有一行。

"离职时间：——"

"离职时间，是空的。"林述说。

"空的是什么意思。"

"意思是他没离职。"林述说。

"那他还活着。"

"不。"林述说。

"表上还有一行。"

"什么行。"

"'最后活动：三百年前。'"

旺财愣住。

"三百年。"

"对。"

"三百年没动。"

"对。"

"那不就是死了。"

"表不认。"林述说。

"为什么。"

"因为表没收到'死亡证明'。"林述说。

"上辈子，"他说，"我们公司有个老员工。"

"退休十年了。"

"但系统里，他还在职。"

"为什么。"

"因为没人给他办离职。"林述说。

"办离职要走流程。"

"流程要他自己签。"

"他退休了，签不了。"

"所以他一直在系统里。"

"一直是'在职'。"

"一直占着一个编制。"

"那个编制，"林述说，"十年没人敢动。"
