# 第二百七十八章 我在门外，当了个符师

林述去登记处，办了正式符籍。

登记的人，还是那个。这次它看见林述，笔停了一下。

"符师。"它说，"不是符徒了。"

"对。"

"作保人。"

"符宗。"林述说。

登记的人低头，看了一眼符宗递来的符牌。

"持十二符的符师。"它写下这行字，"第一次见。"

"外面的人，都是这么说的。"

登记的人把符牌递给林述。

"你以前是'待核'。"它说。

"对。"

"现在呢。"

"现在，"林述说，"我是正式的。"

他拿着符牌出来，翻过来看。背面写着两个字。

符师。

"上辈子，"林述说，"入职要背调。这辈子入符籍，也要。"

*（第二百七十八章 完）*
