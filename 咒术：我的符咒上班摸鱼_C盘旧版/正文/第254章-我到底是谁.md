# 第二百五十四章 我到底是谁

林述在棚里，坐了三天。

他不知道自己是谁了。

是林述？是一个加班猝死的社畜？还是圣主的一部分，借着他的身体活着？

"你在想什么。"旺财问。

"想我是不是我。"

"你不是你是谁。"

"我可能，"林述说，"是圣主的一块。它借我活着，等我攒够力量，它就回来。"

旺财沉默了一会儿。

"你会骂人吗。"它问。

"会。"

"你会摸鱼吗。"

"会。"

"你会算加班费吗。"

"会。"

"圣主会吗。"

林述愣住。

"圣主不会。"旺财说，"圣主只会'合并世界'。它不会为了五块钱的加班费，跟人吵半个钟头。"

林述笑了。

"你骂人的时候，"旺财说，"那种缺德的劲儿，圣主学不来。"

林述低下头，眼眶有点热。

"对。"他说，"我是谁不重要。我是不是'我'，才重要。"

他站起来。

"我还是那个，为了加班费跟人吵架的社畜。"

*（第二百五十四章 完）*
