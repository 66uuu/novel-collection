# 第二百七十九章 旺财在门外

旺财在门外，混得比林述好。

它咬影，赚符核。符核能换灵。它攒了一堆。

"你攒这么多灵干什么。"林述问。

"存着。"旺财说，"万一你没活了，我养你。"

"你养我。"

"对。"旺财说，"你上辈子，是不是也想过，有只狗养你。"

林述没说话。他确实想过。

旺财还收了几个"小弟"。

不是狗，是几只小的符兽。土黄的，跟它一个色。

"它们哪来的。"

"门外生的。"旺财说，"没主的符力，凝成的。我看着像同类，就收了。"

"你收小弟干什么。"

"显摆。"旺财说。

林述看着旺财，带着三只小符兽，在门外招摇过市。

"这狗，"他说，"比我会来事。"

*（第二百七十九章 完）*
