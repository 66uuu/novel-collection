# 第一百零七章 旺财的十二年

涩谷的间隙，林述靠着墙喘气。旺财趴在他脚边。

"旺财。"

"嗯。"

"你跟了我十二年，现在能传画面了吧。"

"能。"旺财说，"从第二年起就能。"

"那你给我看看，你这十二年。"

旺财沉默了一下。然后，一段画面，涌进林述脑子。

第一年，一条瘦狗，缩在他宿舍门口。它饿，但不敢叫。
第三年，它第一次替他闻到远处的咒灵，兴奋得尾巴直摇（虽然尾巴是断的）。
第五年，它学会在他打架时咬人脚踝。虽然咬不动，但能拖。
第八年，它开始能传模糊的画面给他。第一次传成功时，它得意了好几天。
第十二年，它站在涩谷的废墟里，跟一个人类，一起对抗整个世界。

林述看完，半天没说话。

"你这十二年，"他说，"都在跟着我。"

"嗯。"

"我打架，你咬着。"

"对。"

"我受伤，你守着。"

"对。"

"我病，你饿着肚子守三天。"

"……你提这个干嘛。"

林述笑了。

"旺财。"

"嗯。"

"谢谢。"

"又谢。"旺财别过头，"你十二年，谢了我八百回。"

"八百回也不够。"林述说，"你是我在这世界，唯一没走的。"

旺财没说话。它把脑袋，往林述腿边蹭了蹭。

涩谷的炮火还在响。但这一角，很安静。

*（第一百零七章 完）*
