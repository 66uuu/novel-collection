# 第二百四十四章 我开始"收集"门外的符咒

林述清影的时候，发现影渣里，有东西。

一块亮晶晶的碎片，指甲盖大小。

他捡起来。

十二符咒，同时"震"了一下。

"这是什么。"他问老符纹人。

"符核。"老符纹人说，"影被打碎，会留下符核。符核是'浓缩的符力'。"

"能干什么。"

"喂符咒。"老符纹人说，"一颗符核，顶你干十天活。"

林述愣住了。

他低头看着手里的碎片。

"所以影不是怪物。"他说。

"是什么。"

"是'矿'。"林述说，"我清影，不是打架。是挖矿。"

他把符核喂给牛符咒。

牛符咒，亮了一分。

"一颗符核，一分。"林述说，"我一天能清五十只影。"

"五十颗符核。"

"对。"林述说，"十天干活，换一颗符核。一天挖矿，得五十颗。"

"哪个划算。"

"你说呢。"

他站起来，看着远处那片黑压压的影群。

以前看影，觉得是麻烦。

现在看影，觉得是钱。

*（第二百四十四章 完）*
