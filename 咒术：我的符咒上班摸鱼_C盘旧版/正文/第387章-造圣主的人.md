# 第三百八十七章 造圣主的人

"还有一件事。"那人说。

"圣主是人造的。"

"谁造的。"

"不知道名字。"那人说。

"但我知道，"他说，"他还活着。"

林述愣住了。

"活着？"

"活着。"

"你怎么知道。"

"因为门一直没关死。"那人说。

"圣主是钥匙，"他说，"钥匙要是没主了，门早开了。"

"门没开，说明有人还捏着它的另一半。"

"另一半。"

"钥匙有两半。"那人说。

"一半是圣主。"

"另一半，"他说，"在造它的人手里。"

"所以造它的人，必须活着。"

"死了，门就开了。"

林述坐在那儿，半天没说话。

他想起自己上辈子，写过一个脚本。

脚本跑了三年。

三年里他换了三个公司。

脚本还在跑。

因为没人敢关。

关了就出事。

"造圣主的人，"林述说，"是不是也这样。"

"什么样。"

"不敢关，也走不掉。"

那人看了他一眼。

"你怎么知道。"

"我猜的。"林述说。
