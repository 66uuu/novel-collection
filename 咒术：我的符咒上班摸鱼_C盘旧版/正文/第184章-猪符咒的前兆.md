# 第一百八十四章 猪符咒的前兆

林述拖了羂索半天。

半天里，他被打了无数次，一次没死。

"你为什么还不倒。"羂索问。

"狗符咒。"林述说，"不死。"

"不死，也会累。"

"对。"林述说，"我累。但我不能倒。"

第十槽，在动。

猪符咒。激光。

"第十槽。"林述说，"它在涨。"

"为什么。"羂索问。

"因为我在'想输出'。"林述说，"我打不动你，所以我想'要是有个能打疼你的招就好了'。"

他笑了。

"轮盘，靠'想'开。"

他一边被羂索打，一边想：要是有个能一击打穿羂索的招。

第十槽，一天涨15%。

"快了。"林述说。

"什么快了。"

"能打疼你的东西。"

*（第一百八十四章 完）*
