# 第三十七章 上层的人，比我想象的更恶心

西装带林述去看了一次"内部清算"。

某处村子，出了一级咒灵，伤了人。按规矩，一级得由一级咒术师处理。但那天没人来。等来的是一份"封口协议"：村子划为禁地，伤亡数字压下去，事情就当没发生。

"为什么不派人？"林述问。

"因为派一级，要报备，要走流程，要留记录。"西装压低声音，"上层觉得，划块地封起来，成本更低。"

林述站在原地，看着那村子被拉上警戒线。

里面还住着人。有人不肯走，被强迁。

"那里面的人呢。"

"运气好的，搬走。运气不好的……"西装没说下去。

林述没说话。

他想起自己清的那些怪。他一只一只清，救一个是一个。

而这些人，一句话，就把一村子人划成了"成本"。

"你们管这个叫管理。"他说。

"我叫它恶心。"西装苦笑，"但我是跑腿的，说了不算。"

回去的路上，林述一句话没说。

旺财在他脑里："你在想夏油杰。"

"嗯。"

"为什么。"

"因为他说过，咒术师该保护非术师。"林述望着车窗外，"我以前觉得他矫情。现在觉得，他说得对。"

上层的人，比他想得更恶心。他们不是不懂，是懂了还这么干。

"那你怎么办。"旺财问。

"我不知道。"林述说，"但我不想变成他们。"

*（第三十七章 完）*
