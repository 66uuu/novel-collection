# 第一百九十八章 虎符咒，两个我

第十二槽，满了。

虎符咒，融进身体。

林述感觉自己"裂"开了。

不是痛。是"分成两个"。

左边一个他，穿着高专的制服，一脸想摸鱼。右边一个他，浑身是伤，眼睛很亮。

"你是……"左边的他。

"你是……"右边的他。

两个他，看着对方。

"你是那个想活命的。"右边说。

"你是那个想救人的。"左边说。

"对。"

"我们打了十二年。"

"对。"

"现在，不打了。"两个他，同时说。

他们伸出手，握在一起。

那一瞬间，两个他，合成了一个。

不，不是合成一个。是"两个"，都还在。

林述站在战场上，身边站着一个一模一样的自己。

"分身。"他说，"两个我。"

一个他，负责打。一个他，负责算。

"我早就该这样了。"林述说，"一个冲，一个想。"

*（第一百九十八章 完）*
