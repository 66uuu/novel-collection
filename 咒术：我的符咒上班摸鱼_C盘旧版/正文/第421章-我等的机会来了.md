# 第四百二十一章 我等的机会来了

第二十一天，师兄出事了。

不是受伤。

是"卡住了"。

他坐在桌子前。

手抬着。

放不下。

"怎么了。"林述问。

"令。"师兄说。

"令怎么了。"

"令变了。"师兄说。

"变什么了。"

"以前是'看门'。"

"现在还是'看门'。"

"多了一条。"师兄说。

"多什么。"

"'看门，且不许人接替'。"

林述愣住。

"这令哪来的。"

"上面。"师兄说。

"上面不是没人吗。"

"没人，"师兄说，"但令自己长出来的。"

林述明白了。

"这是流程的自我保护。"

"什么保护。"

"上辈子，"林述说，"我们系统里有个东西。"

"叫'权限锁'。"

"你把活分给别人。"

"分到第三次，"林述说，"系统就会自动锁上。"

"为什么。"

"怕你把活全分出去，"林述说，"然后自己跑了。"

"系统不怕你累死。"

"系统怕没人干活。"

"所以它宁可把你锁在活上。"

"也不让你分出去。"

师兄看着他。

"那我现在怎么办。"

"你分不出来了。"林述说。

"对。"

"那我来分。"林述说。

"怎么分。"

"我不接你的活。"林述说。

"我接'令'本身。"

"上辈子，"他说，"这叫'接管流程'。"
