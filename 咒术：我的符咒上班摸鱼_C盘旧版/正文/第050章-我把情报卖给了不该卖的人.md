# 第五十章 我把情报卖给了不该卖的人

林述的邮箱，收到一封新单。

【求：某御三家分家的护卫路线。价好谈。】

林述查了查。这单的用途，对方写的是"避祸"。一个想避开仇家追杀的人，要一条安全路线。听起来合理。

他卖了。收了三十万。

三天后，那家分家出事了。

不是被追杀。是被伏击。护卫路线泄露，一家老小十几口，死了大半。

买情报的人，不是避祸的。是来杀人的。

林述坐在宿舍，看着新闻，手一直没动。

"你算错了。"旺财说。

"嗯。"

"这单不该接。"

"我接了。"林述说，"我只看钱，没看人。"

他一直以为自己"缺德但不坏"。不害无辜，不出卖自己人。

这次，他卖了一条路线，害了一家人。哪怕他不知道用途，人是他间接害死的。

他第一次，觉得自己脏。

西装来电话，语气很急："你完了。御三家在查谁泄的路线。查到你就死定了。"

"查吧。"

"你疯了？"

"我没疯。"林述挂了电话。

他坐了一夜。天亮时，他做了两件事。

第一，把那三十万，匿名捐给了遇难那家的遗孤。

第二，他把"情报生意"的规矩，重新写了一遍：

【新规一：不问用途的单，不接。】
【新规二：涉及人命的单，先查买家。】
【新规三：宁可少赚，不脏手。】

写到最后，他停了笔。

他想起夏油杰说过的话：咒术师该保护非术师。

他一个卖情报的，保护不了谁。但至少，他可以不害。

"旺财。"他说，"我是不是很蠢。"

"你以前很聪明。"旺财说，"现在……我觉得你像个人了。"

林述苦笑。他合上本子。

门外，脚步声响起。有人来找他了。

*（第五十章 完）*
