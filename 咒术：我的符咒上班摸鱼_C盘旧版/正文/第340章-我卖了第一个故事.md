# 第三百四十章 我卖了第一个故事

第二个故事，林述卖了个好价。

他讲的是"圣主"。

讲一个被锁在门里的东西，想合并两个世界。

那人听完，脸色变了。

"这个故事，"他说，"我要了。"

"值多少。"

"值一个'住处'。"

"什么住处。"

"一间屋子。"

那人带林述去了一间屋子。

不大，能住人。

"讲得值。"林述说。

"不是讲得值。"那人说。

"是'故事本身'值。"

"为什么。"

"因为，"那人说，"外域的人，最怕'被合并'。"

"为什么怕。"

"因为，"那人说，"外域的人，是'自己信自己'的。"

"一旦合并，他们就'被别人信'了。"

"被别人信，"他说，"就没了自己。"

林述站在屋子里，想了一会儿。

"这不就是，"他说，"被大公司收购吗。"

"什么大公司。"

"没事。"林述说，"我上辈子的事。"

"你上辈子，"那人说，"也有'王'。"

"有。"林述说。

"什么王。"

"我们管他叫，"林述说，"资本。"

*（第三百四十章 完）*
