# 第一百零九章 打不动了，真的打不动了

灰原接上手，林述退到后方。

他靠着墙，喘。肩膀的伤口在流血，咒力见底。

"你歇会儿。"旺财说。

"嗯。"

他闭上眼。但耳麦里，消息还在来。

"中央通道清完。"
"东口失守，退守B2。"
"地下三层，发现特级咒灵。"

特级。

林述睁开眼。

"特级在哪。"

"地下三层。往中央通道来了。"

林述撑着墙，想站起来。腿一软，又坐下。

"你打不动了。"旺财说，"二级的咒力，对付特级，跟送死一样。"

"我知道。"

"那你还想去。"

林述看着自己的手。抖的。

十二年，他攒了八件咒具，十七条线人，三条退路。但他没攒下"打特级的能力"。

因为那需要龙符咒。

而龙符咒，还差一点。

"旺财。"

"嗯。"

"第三槽多少了。"

"93%。"

"还差7%。"

林述靠在墙上，看着地下三层的方向。

他打不动了。真的打不动了。

但那只特级，正在往这边来。

"旺财。"

"嗯。"

"帮我个忙。"

"说。"

"去把灰原他们，往西口撤。"林述说，"我在这儿，拖一会儿。"

*（第一百零九章 完）*
