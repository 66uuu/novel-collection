# 第二十章 卷末，入职三个月

三个月。

林述数：入学、学咒力（半吊子）、杀若干怪、旺财成固定队友、跟夏油杰硝子混熟、暗排时间轴。

夜蛾月度评："肉体达标。咒力仍不及格。"

林述："及格的事留给及格的人。"

夜蛾："……你倒会甩。"

食堂。夏油杰端盘坐他对面："三个月了，还信钱？"

"信。钱不背叛。"

夏油杰笑，没驳。三个月，他看明白这人：歪，但护短；黑，但不坏。

硝子叼烟路过，弹他脑壳："还活着，不错。"

"托你福。没被打残。"

"下次残了来找我，别死外头。"

旺财在脑里："这三个人，一个管饭一个管伤一个管训。你挺全。"

林述："全才怪。管饭的嫌我黑，管伤的嫌我烦，管训的嫌我没觉悟。"

"那你图啥。"

"图他们活着。"

狗沉默。这回它没接话。

林述回宿舍，摊本子算总账：

【入职：三个月。等级：未评定（预计 25 章前后评 3 级）。】

【轮盘第二槽：28%。兔还早，按这速度小半年。】

【存款：顾问费二十万日元，没动。】

【情报网：夏油杰（刷怪点）、旺财（雷达）、图书馆（漏洞）。】

他把"28%"圈红。慢，但真在涨。

窗外，一只黑鸟掠过，落对面电线。林述多看一眼。

旺财："鸟咋了。"

"没咋。就是觉得，它像在看这边。"

"你最近疑神疑鬼。"

"先知后遗症。"

林述躺下。旺财在门口趴好，像保安。

"值班。"狗说。

"包吃没五险一金。"

"记得呢。"

三个月，没被炒，没送命，槽在涨，钱在账。

林述咧嘴。上辈子加班到三点没了，这辈子摸鱼式变强，挺划算。

"入职三个月，"他跟狗说，"这班，我上定了。"

旺财："那罐头啥时候发。"

"发了你也不吃。"

"我挑完再发。"

林述笑，灯灭。东京夜，一人一狗，一个等着开挂，一个等着罐头。

游戏，才刚开局。

*（第二十章 完）*
