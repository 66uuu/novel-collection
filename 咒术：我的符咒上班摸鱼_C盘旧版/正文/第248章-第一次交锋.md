# 第二百四十八章 第一次交锋

林述抢了虎符咒一角，引者亲自来了。

还是那件袍子，没有脸。

"交出来。"它说。

"不交。"

"你打不过我。"

"我知道。"林述说，"但你主人，还锁着。你借的符力，有限。"

引者的袍子动了。

"够杀你。"

它出手了。

林述没硬接。兔符咒蹬空，人往后飘。牛符咒一拳，打在引者的袍子上。

袍子，破了一角。

引者愣了一下。它没想到，一个符徒，能破它的袍子。

"你符力薄，"引者说，"但你的符，硬。"

"抄本也硬。"林述说。

引者又出手。这次快了十倍。

林述接不住，被扫飞出去，砸进一堆符石里。

"咳。"他吐了口血。

"你输了。"

"没有。"林述说，"我只是没赢。"

他爬起来，兔符咒一蹬，跑了。

引者追了两步，停住。它出了中立区的界线。

林述回头看了它一眼。

"第一次，"他说，"我赢了一半。"

*（第二百四十八章 完）*
