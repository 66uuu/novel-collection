# 第三百三十九章 这里的"钱"是故事

林述在外域，搞懂了这儿的"钱"。

是故事。

"你讲一个别人没听过的故事，"那人说，"就能换东西。"

"换什么。"

"换你要的。"

"我要吃的。"

"讲吧。"

林述想了想。

他讲了一个故事。

讲的是一个社畜，加班到死，然后穿越了。

穿越到一个咒灵横行的世界。

手里，有十二个符咒。

那人听完，沉默了很久。

"这故事，"他说，"我没听过。"

"怎么样。"

"值一顿饭。"

那人给了他三个饭团。

林述拿着饭团。

"上辈子，"他说，"我卖代码。"

"这辈子，卖情报。"

"现在，卖故事。"

"我这辈子，"他说，"就没干过一件正经活。"

"什么叫正经活。"那人问。

"就是，"林述说，"朝九晚五，交社保的。"

"那有什么好。"那人说。

"至少不用编故事换饭。"

"你错了。"那人说。

"什么。"

"讲故事换饭的人，"他说，"比朝九晚五的人自由。"

"为什么。"

"因为，"那人说，"朝九晚五的人，只有一个故事。"

"就是'我上班'。"

"你有好多故事。"

*（第三百三十九章 完）*
