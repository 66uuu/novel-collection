# 第四百四十四章 我在改流程

圣主挤出来半个身子。

很大。

比下面那层见到的，还大。

"你。"它说。

"我。"

"你把我的东西，拿走了。"

"对。"林述说。

"还回来。"

"不还。"林述说。

"你不还，我杀了你。"

"你杀不了。"林述说。

"为什么。"

"因为你出不来。"林述说。

"你只出来半个。"

"另半个，卡在缝里。"

圣主停了。

"你想干什么。"它问。

"我想关门。"

"门关不上。"

"为什么。"

"因为我不签。"圣主说。

"你不签，"林述说，"是因为你想出去。"

"对。"

"出去了干嘛。"

"出去了，"圣主说，"我就是主人。"

林述笑了。

"上辈子，"他说，"有个人跟我说过一样的话。"

"他说，'我要是当了老板，我就自由了'。"

"后来他当了。"

"更不自由。"

"为什么。"

"因为老板上面有客户。"林述说。

"客户上面有市场。"

"市场上面有政策。"

"他往上爬，"林述说，"爬一层，多一层管他的。"

"你不是想当主人。"

"你是想换个地方当打工的。"
