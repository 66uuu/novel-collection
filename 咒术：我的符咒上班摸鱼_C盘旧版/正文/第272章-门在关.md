# 第二百七十二章 门在关

门，开始关了。

不是圣主关的。是林述加的规则，在生效。

门的两扇，慢慢往里合。

圣主感觉到了。

"你加了什么。"它说。

"补丁。"林述说。

"什么补丁。"

"第六条。"林述说，"门关上后，不能从门那边再开。"

圣主沉默了一下。

然后它疯了。

它不再管林述，转身去撞门。要趁门没关严，把自己挤过去。

"拦住它！"林述喊。

符宗冲上去，九符立域，挡在门前。

圣主一掌，域碎了。符宗飞出去。

旺财扑上去，咬住圣主的"手"。

圣主一甩，旺财撞在门上。

"旺财！"

"别管我！"旺财说，"关门！"

门，还剩一条缝。

林述冲过去，站在门缝里。

*（第二百七十二章 完）*
