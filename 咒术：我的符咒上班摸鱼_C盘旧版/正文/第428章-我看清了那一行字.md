# 第四百二十八章 我看清了那一行字

林述把那一行字，看了很久。

"备注：外来，未登记，需人工处理。"

"还有半行。"旺财说。

"哪儿。"

"底下。"旺财说。

"有个字被压住了。"

林述翻起表角。

底下果然有半行。

写得很小。

"来源：下层。"

"经手人：造者。"

"性质：遗留。"

"遗留。"林述念了一遍。

"什么意思。"

"意思是，"林述说，"我是别人留下的东西。"

"谁留下的。"

"造者。"

"他留的。"

"对。"

"他什么时候留的。"

"不知道。"林述说。

"但表上写了'经手人'。"

"经手，说明他碰过我。"

"碰过，说明他知道我。"

林述手上一紧。

"他知道我。"他说。

"那他还走了。"

"他不知道我在这儿。"林述说。

"他只是……"

"留了个尾巴。"

"什么尾巴。"

"上辈子，"林述说，"我离职的时候，也留过一个尾巴。"

"什么尾巴。"

"一个脚本。"林述说。

"那个脚本，三年后还在跑。"

"跑的时候，没人知道是我写的。"
