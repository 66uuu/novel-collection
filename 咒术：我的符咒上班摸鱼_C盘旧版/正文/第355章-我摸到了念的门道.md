# 第三百五十五章 我摸到了念的门道

林述开始造街。

第一天，造了半条。

没人走。

第二天，他把街拆了，重造。

还是没人走。

第三天，他坐在街上，想了一夜。

"为什么没人走。"他问自己。

"因为街是空的。"他答。

"为什么空。"

"因为没店。"

第四天，他造了店。

一家，两家，三家。

第五天，街上有"人"了。

是他念出来的。

第六天，真的有人走进来了。

一个。

第七天，十个。

"成了。"老头说。

"为什么成了。"

"因为，"老头说，"你先造了店，再造了人。"

"别人看见有店，就以为有人。"

"有人，就走进来了。"

林述站在街上。

"这跟做产品，"他说，"一模一样。"

"先做几个假用户。"

"再让真用户来。"

"来了，"他说，"就真了。"

"那假用户呢。"老头问。

"假用户，"林述说，"最后会变成真的。"

"为什么。"

"因为，"林述说，"店是真的。"

"店真了，人就不假了。"

*（第三百五十五章 完）*
