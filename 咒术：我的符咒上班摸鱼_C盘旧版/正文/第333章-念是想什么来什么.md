# 第三百三十三章 念，是想什么来什么

林述练了三天。

第一天，他想出一块石头。

石头出现，三秒后散。

第二天，他想出一棵树。

树出现，十秒后散。

第三天，他想出一把椅子，坐了上去。

椅子撑住了。

"有进步。"那声音说。

"三天，撑住一把椅子。"林述说。

"我上辈子三天，能写完一个模块。"

"这不是写代码。"那声音说。

"念，"它说，"不是'做'出来的。"

"是'信'出来的。"

"你信这块石头在，它就在。"

"你哪怕有一丝怀疑，它就散。"

林述坐在椅子上。

"那就是说，"他说，"我得骗自己。"

"不是骗。"

"是'当真'。"

"怎么当真。"

"你坐的这把椅子，"那声音说，"你信它在吗。"

林述低头看了看。

"信。"

"那你为什么只敢坐，不敢跳。"

林述愣住。

他站起来，试着跳了一下。

椅子，撑住了。

"你看，"那声音说，"你信了一半。"

"你信它能坐，不信它能扛。"

"念这东西，"它说，"你信多少，它就给你多少。"

林述看着那把椅子。

"上辈子，"他说，"我也这样。"

"信自己能干，不信自己能升。"

"所以干到最后，"他说，"还是个干活的。"

*（第三百三十三章 完）*
