# 第二百三十一章 我把牛符咒练出了新用法

牛符咒二档，林述发现，不止力量翻倍。

他试着推一堵墙。墙没倒。

但墙"晃"了一下。

"不是推倒，"林述说，"是推动。"

他又试。这次不是推，是"带"。一堵半人高的符石墙，被他整块端起来，挪了三步，放下。

"惯性。"他说。

"什么。"

"牛符咒二档，"林述说，"不只是力气大，是能'控制'惯性。我打出去的力量，能收回来。"

他解释给旺财听。以前是一拳出去，力就没了。现在是拳头出去，力还"挂在手上"，能拐弯。

"能拐弯的拳。"旺财说，"打人更阴。"

"对。"林述说，"上辈子写代码，这叫'可控变量'。"

他拿这个新用法去清影。

以前一拳一只。现在一拳过去，惯性带着拳风扫一圈，三只影一起碎。

"效率翻三倍。"林述说。

"活接得更多了。"旺财说，"你能加班了。"

"我上辈子最恨加班。"林述说。

"那你少打两只。"

"不行。"林述说，"我要攒灵。"

他站在碎了一地的影渣里，算了算。

照这个速度，兔符咒进化，用不了半年。

*（第二百三十一章 完）*
