# 第一百六十四章 猴符咒，变形

猴符咒，是在林述被围的时候开的。

羂索的手下，找到了他。五个二级，一个一级。

林述打不过。他咒力不够了。

就在这时候，第七槽，满了。

猴符咒，融进身体。

林述感觉自己的骨头，开始动。他变矮了，变瘦了，脸也变了。

他变成了刚才那个手下。

"你？"领头的愣住了，"你怎么从那边过来？"

林述用那个手下的声音说："林述往西跑了。"

"西边？追！"

五个人，往西跑了。

林述站在原地，看着自己的手。不是自己的手。

"变形。"他说，"我变成了别人。"

"成了。"画面——狗，兴奋。

林述变回自己。

"猴符咒，太有用了。"他说，"变形，伪装，潜入。"

他记本子：

【猴符咒，解锁。能力：变成任何人/动物。】
【用法：潜入、伪装、逃命、整活。】
【第七符咒。已解锁：牛、兔、龙、蛇、马、羊、猴。】

"七个了。"林述说，"十二个槽，过半了。"

画面：狗，点头。

"接下来，"林述说，"我能光明正大地，混进羂索的队伍里了。"

*（第一百六十四章 完）*
