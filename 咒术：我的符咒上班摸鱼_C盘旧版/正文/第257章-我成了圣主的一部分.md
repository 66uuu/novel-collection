# 第二百五十七章 我成了"圣主"的一部分

用了太多次符咒，林述开始"变"。

先是耳朵。他开始能听到一种声音，很低，像有人在很远的地方说话。

"你听见了吗。"他问旺财。

"听见什么。"

"有人在说话。"

旺财竖起耳朵，听了半天。

"没有。"

林述又用了一次龙符咒。这次，声音更清楚了。

一个很老、很沉的声音，在他脑子里响。

【回来。】

林述僵住。

【把身体，还给我。】

"是圣主。"他说。

"它跟你说话了。"旺财说。

"对。"林述说，"它开始'叫'我了。"

他捂住耳朵。没用。声音在脑子里。

"你变了吗。"旺财问。

林述低头，看自己的手。手上，符纹在亮，亮得比平时久。

"我，"他说，"正在变成它的一部分。"

"上辈子加班久了，"旺财说，"你也变成了KPI的一部分。"

"对。"林述说，"这次是变成圣主的一部分。"

*（第二百五十七章 完）*
