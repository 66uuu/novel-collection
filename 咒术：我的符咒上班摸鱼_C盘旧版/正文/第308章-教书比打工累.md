# 第三百零八章 教书比打工累

教了半年书，林述瘦了。

"你怎么瘦了。"旺财问。

"累。"

"教书有什么累的。"

"你不懂。"林述说，"二十个孩子，二十张嘴。"

"这个问，那个哭，还有一个打架。"

"上辈子我带项目组，五个人。"

"这辈子带二十个。"

"带一个孩子，比改一个需求难。"

"改需求，改坏了还能回滚。"

"孩子带坏了，回滚不了。"

旺财趴在门口，看着院子里那二十个符童。

"那你还教。"

"教。"林述说。

"为什么。"

林述想了想。

"上辈子，"他说，"我做的产品，用户用完就卸载。"

"没人记得我。"

"这辈子我教的孩子，"他说，"他们长大了，会记得我。"

"这算不算，"他说，"KPI 之外的东西。"

"什么KPI。"旺财问。

"就是，"林述说，"上辈子老板给我定的目标。"

"完成不了，扣钱。"

"完成了，也就那样。"

"那你这辈子，"旺财说，"没KPI了？"

"有。"林述说。

"谁的。"

"我自己的。"

"我自己给自己定。"

"定什么。"

"定，"林述说，"把这二十个孩子，教到能自己活着。"

"这个KPI，"他说，"比上辈子那个，难。"

"但我愿意干。"

*（第三百零八章 完）*
