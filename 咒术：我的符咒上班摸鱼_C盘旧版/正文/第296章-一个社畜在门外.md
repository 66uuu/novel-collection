# 第二百九十六章 一个社畜，在门外

林述在门外，还是"打工的"。

早上清影，中午卖情报，下午看店，晚上练符力。

符塾的账，他得算。符童的课，他得上。老符纹人的铺子，他得看。

一天下来，比在门里还忙。

"你不是锁了门吗。"旺财问，"怎么还这么累。"

"锁门，"林述说，"不是'不上班'。锁门是'把老板锁起来'。"

"然后呢。"

"然后，"林述说，"我还得自己找活干。"

他坐在屋前，看着门外那片灰天。

"上辈子，"他说，"我打工，是给老板。"

"这辈子呢。"

"这辈子，"林述说，"我打工，是给自己。"

他想了想，又补了一句。

"也是给那三十个符童。"

*（第二百九十六章 完）*
