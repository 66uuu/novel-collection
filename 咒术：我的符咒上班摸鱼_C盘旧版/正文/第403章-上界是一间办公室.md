# 第四百零三章 上界是一间办公室

再往前走，林述看清了上界。

真的是间办公室。

桌子。

椅子。

灯。

灯是亮的。

没有人。

一张桌子挨着一张桌子。

一直排到看不见的地方。

"人呢。"旺财说。

"没人。"

"那灯谁开的。"

"没人开。"

"那怎么亮着。"

"因为它一直亮着。"林述说。

"上辈子，"他说，"我们公司也这样。"

"晚上十点，整层楼没人。"

"灯全亮着。"

"保安说，省得第二天再开。"

"其实是，"林述说，"关灯要走流程。"

"关灯要报备。"

"报备要审批。"

"审批要等。"

"等着等着，"林述说，"天就亮了。"

"所以干脆不关。"

旺财看着那一排排亮着的灯。

"这地方，"它说，"比下面冷。"

"冷就对了。"林述说。

"办公室都冷。"

"为什么。"

"因为空调是给机器开的。"林述说。

"人只是顺便在里面。"
