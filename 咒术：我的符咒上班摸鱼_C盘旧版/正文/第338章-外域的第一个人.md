# 第三百三十八章 外域的第一个人

走了三天，林述见到了外域的第一个人。

那人坐在路边，摆了个摊。

摊上，什么都没有。

"你卖什么。"林述问。

"故事。"那人说。

"什么故事。"

"你想听什么。"

"你随便讲。"

那人看了他一眼。

"你从下面来的。"他说。

林述愣住。

"你怎么知道。"

"因为，"那人说，"你身上有'下'的味。"

"下面来的，都想知道上面是什么样。"

"那我告诉你。"

他讲了一个故事。

讲的是上面。

上面有个"王"，很强。

王想让三层世界合成一层。

王有个手下，叫"造者"。

造者造了十二个东西，叫"符"。

符能锁世界。

林述听着。

"你讲的，"他说，"跟我认识的一件事，对上了。"

"什么事。"

"十二符咒。"

那人笑了。

"你不是来听故事的。"他说。

"你是来找答案的。"

"对。"林述说。

"那我也问你一个问题。"

"你问。"

"你那个十二符咒，"那人说，"是买的，还是自己挣的。"

林述想了很久。

"挣的。"他说。

"那还行。"那人说。

"自己挣的东西，"他说，"别人收不走。"

*（第三百三十八章 完）*
