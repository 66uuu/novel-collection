# 第四百七十四章 表没了

林述把令展开，最后看了一次那张表。

表上，所有名字都亮了。

"已完成。"

"已归档。"

"已离职。"

"已封存。"

"已注销。"

最后一个，是他自己。

"林述：待定。"

"还是待定。"旺财说。

"对。"

"为什么。"

"因为我是外来户。"林述说。

"表处理不了我。"

"它到死，"林述说，"也没想好把我归哪一类。"

"那它就把你带着？"

"它带不了。"林述说。

"它自己都要没了。"

"它没了，我怎么办。"

"我还在。"林述说。

"表没了，但我还在。"

"上辈子，"林述说，"我从公司离职。"

"系统里我的账号，被删了。"

"删了以后，我进不去门。"

"但我在门口站着。"

"我还在。"

"账号没了，"林述说，"不等于人没了。"

"人在，就行。"

"表是给'账号'用的。"

"不是给'人'用的。"

林述把令合上。

令在他手里，化成了一点光。

散了。
