# 第四百六十三章 他说谢谢你

造者的影子，笑了。

很淡。

"砌墙。"他念了一遍。

"对。"

"我怎么没想到。"

"因为你不敢。"林述说。

"对。"影子说。

"我怕砌死了，"他说，"就再也开不了了。"

"万一有一天，需要开呢。"

"万一有一天，"林述说，"上面的人回来了呢。"

"我得留个门。"

"所以你留了三百年。"林述说。

"对。"

"留到最后，"林述说，"你把自己留成了门。"

"上辈子，"他说，"我留过一份文档。"

"我写得特别详细。"

"怕后来的人看不懂。"

"结果那份文档，"林述说，"没人看过。"

"为什么。"

"因为接手的人，直接重写了系统。"

"他根本没用我的文档。"

"我白写了。"

"但那件事教了我一件事。"

"什么事。"

"你留的东西，"林述说，"不一定有人接。"

"所以别指望接。"

"该关就关。"

"该埋就埋。"

"留个尾巴，"他说，"最后缠住的是自己。"
