# 第三十章 旺财说它以前也是被人养的

旺财今晚反常，没在门口趴着。

它缩在林述脚边，团成一团，土黄色的毛在灯下显得更枯了。林述低头："你怎么了，饿的？"

旺财没接话。过了会儿，一段画面，直接砸进他脑子。

不是声音，是记忆。

一只手，很小，挠它下巴。小孩的笑声。"旺财，旺财，吃饭啦。"

搬家。纸箱，灰尘。那双手把它塞进纸盒，说"先放这儿，到了新家就接你"。

没有人来接。纸箱在阳台淋了雨，发霉。它饿了三天，叫，没人应。

最后它不叫了。缩在箱底，慢慢冷下去。怨气凝结的那一刻，它才变成咒灵。

林述坐在地板上，半天没动。

旺财："……你看够了没。"

"你以前叫旺财？"

"那小孩起的。我死了以后，这名字跟着怨气一起留着。你再叫我旺财，我嫌土，但没办法，打不过。"

林述嗓子有点堵。他这人，平时嘴硬的很，这会儿卡壳了。

"那小孩后来呢？"

"不知道。我成咒灵以后，就只记得被扔的那一下。"

旺财语气很平。像在说别人的事。但林述知道，能被记住的怨，都是没放下的。

"你打服我那回，"林述说，"你其实挺惨的。一条被丢掉的路都走不完的狗，碰上个能打你的社畜。"

旺财："彼此彼此。你加班加死了，我饿死了。咱俩都是被这世界辞退的。"

林述笑了下。

他起身，从柜子里摸出那罐罐头——旺财一直嫌生的不吃。他拆了，倒进小碗，用热水泡了泡，吹凉。

"吃吧。"

旺财："……你泡它干嘛。"

"你以前主人喂你热的。今天破个例。"

旺财没说话。它低头，舔了口。

林述靠墙坐着，看一条狗吃罐头。灯很暗，但够看清它缺了块左耳，断了的尾巴。

"以后你是我养的，"他说，"我穷，但饭管够。热的。"

旺财："你二十万存款，够喂几顿？"

"……别算账。"

"你这人，嘴上舍命，手上算钱。"

"习惯了。"

旺财把碗舔干净，团回他脚边。这次是贴着的。

林述摊开本子，今天没写战绩。他写：

【旺财：前主人是小孩，被遗弃致死成咒灵。怨气根源=被扔。】
【结论：它要的不是罐头，是'有人接'。】
【轮盘第二槽：50%。今日无战，没动。】

他把本子合上。窗外东京的灯，一盏盏灭。

"旺财。"

"嗯。"

"你那小孩，要还在，我帮你找。"

旺财沉默很久。

"……不用。他要是长大了，早该来接我。没来，就是忘了。我记着那一下，就够了。"

林述没再劝。有些怨，是狗自己要扛的。他能把饭管够，已经算它这辈子，第一个没扔它的人。

"睡吧，"他关灯，"明天还得刷怪。"

黑暗里，旺财贴着他脚，呼噜很轻。

一人一狗。这回，都不是被丢下的那个。

*（第三十章 完）*
