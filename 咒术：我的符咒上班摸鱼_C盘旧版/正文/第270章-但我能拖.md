# 第二百七十章 但我能拖

林述的打法，就一个字。

拖。

"你打不过我，"他说，"但你也关不掉我。"

他不再进攻。牛符咒护住身子，兔符咒躲闪，龙符咒挡在中间。

圣主一拳，他退三步，爬起来。

圣主一压，他吐口血，站起来。

"你撑不了多久。"圣主说。

"我知道。"林述说，"一炷香。"

"一炷香之后呢。"

"一炷香之后，"林述说，"换下一个符咒。"

他把牛符咒收回来，换成兔符咒全开。

速度暴涨。他不打，只躲。圣主的每一击，都落空。

一炷香。

"上辈子，"林述一边躲一边说，"开会的时候，我最擅长的，就是拖。"

"拖到甲方忘了需求。"

"拖到老板下班。"

"今天，"他说，"我拖到门关。"

*（第二百七十章 完）*
