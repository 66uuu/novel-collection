# 第二十七章 五条悟的委托，从来都不简单

五条悟的"私活"，约在涩谷天桥底下。

林述到的时候，这人正蹲在自动贩卖机前买罐装咖啡，买了两罐，递他一罐。

"前辈，你叫我跑腿？"

"～不是跑腿。是兼职。"五条悟拉下罩子，难得正经了半秒，"有处地方，咒力读数不对。不高，但怪。像有人故意压着不让它冒头。"

林述拧开咖啡："地点？"

"新宿，一栋废弃公寓。三层，住了三家'不该住的东西'。"

"三家？"

"一只二级，挂了层伪装。一个诅咒师的落脚点，人走了，留了点残渣。还有……"五条悟顿了顿，"说不清。你去了就懂。"

林述敏感地停住。五条悟说"说不清"，那就是真有他都在意的东西。

"报酬怎么算？"

五条悟笑："～谈钱伤感情。"

"但伤不到我。按次计费，差旅报销，危险补贴另算。"

"行行行，"五条悟掏出张黑卡，"这个你拿着，咒术界内部的消费，刷我的。"

林述接过，翻来覆去看："这卡能刷多少？"

"够你用到退休。"

"……前辈，你这么有钱，怎么不早说。"

"你也没问啊。"

林述把卡收好。有钱人真恶心，但也真香。

他当晚去了新宿那栋公寓。

二级咒灵好解决，伪装层一揭就现形，牛符咒一拳闷死。诅咒师残渣麻烦点，得一点点清，他花了两小时，烧了三张符。

第三样"说不清"的东西，在地下室。

一扇封死的门，门后咒力像被按在水底，只偶尔冒个泡。林述贴上去听——

没有声音。但轮盘，热了。

又是那种热。第二槽，轻轻颤了一下。

"旺财，你感觉没？"

旺财："门后有东西，在跟你的轮盘打招呼。"

"打招呼？"

"我形容不了。就像……同频。"

林述退开。他没开门。五条悟让他"去就懂"，但他懂了个更吓人的——这世界，不止他一个"体系外"的东西。

他清完地表，拍了门照，发给五条悟。

【新宿废弃公寓：二级×1已除，诅咒师残渣已清。地下室封门未动，建议上级处理。】
【轮盘第二槽：43%。今日战绩：二级×1。】
【资产新增：五条悟黑卡×1（消费权限未知，先当信用卡用）。】

五条悟回得快："～干得漂亮。门别动，我来处理。"

林述："那东西是什么？"

"……以后告诉你。先好好升级。"

林述没再问。这人肯说的，不用逼；不肯说的，逼也没用。

回程他刷了黑卡，买了两罐热咖啡、一包罐头（旺财挑的）、一份炸鸡。

"这卡，"他跟旺财说，"刷着刷着，我觉得我像被包养了。"

旺财："你终于承认你是个靠金主的了。"

"放屁，这是劳务报酬。"

林述嚼着炸鸡。五条悟的委托不简单，但他接了。报酬到位，风险可控，信息还能换。

这生意，能做。

*（第二十七章 完）*
