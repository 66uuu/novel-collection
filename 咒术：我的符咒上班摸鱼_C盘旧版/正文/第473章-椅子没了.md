# 第四百七十三章 椅子没了

林述走到那把椅子前。

椅子还在。

但已经透明了。

"这就是'上面'。"旺财说。

"对。"

"就这么一把椅子。"

"就这么一把。"林述说。

"你想坐吗。"

"不想。"

"为什么。"

"因为坐上去，"林述说，"就得看门。"

"门已经关了。"

"关了，"林述说，"也没人坐。"

"那它为什么还在。"

"因为规矩还在。"林述说。

"规矩还没删。"

"它自己不会删。"

"得有人删。"

"谁删。"

"没人。"林述说。

"那它就一直在。"

"在就一直在。"林述说。

"上辈子，"他说，"我们公司有个'已注销'的部门。"

"部门没了。"

"人也没了。"

"但组织架构图上，还有那个框。"

"框里写着'待定'。"

"挂了五年。"

"为什么。"

"因为删框要走流程。"

"流程要人签。"

"人没了，签不了。"

"所以那个框，"林述说，"一直挂到公司倒闭。"

"公司倒闭那天，整个图都没了。"

"框也就没了。"

"有些东西，"林述说，"不是被删掉的。"

"是跟着一起没的。"
