# 第八十七章 他说了一句让我记了很久的话

夏油杰走之前，回头看了林述一眼。

"林述。"他说。

"嗯。"

"你说你打不过伏黑甚尔，打不过我，打不过五条悟。"夏油杰说，"那你有没有想过，为什么你还要留在这。"

林述没答。

"因为你想保护人。"夏油杰替他答了，"可你想保护的那些人里，有一半，根本不在乎你保护他们。"

"我知道。"

"知道你还保护。"

"对。"

夏油杰看着他，忽然说了那句林述记了很久的话：

"林述，你不是想救人。你是想证明，这世界还有救。"

林述愣在原地。

夏油杰走了。

那句话，像一根针，扎在他心里。

"他说的对吗。"旺财问。

"……对。"

林述靠着墙，慢慢坐下去。

他一直以为，自己救人是因为"划算"、"护短"、"顺手"。但夏油杰一句话，把他看穿了。

他不是想救人。他是想证明，他穿越过来的这个烂世界，还值得他救。

"旺财。"

"嗯。"

"他说得对。"林述说，"我就是想证明，这世界还有救。"

"那你证明给谁看。"

"证明给我自己看。"林述说，"我上辈子加班死了，什么都没证明。这辈子，我想证明一次——活着，是有意义的。"

旺财沉默。

"那你继续证明。"它说，"反正你也没别的事干。"

林述笑了。他站起来，拍拍灰。

夏油杰走了。但他留下的那句话，会跟着林述很久。

*（第八十七章 完）*
