# 第二百六十五章 我加了一条规则

林述盯着终局规则，看了一夜。

然后，他在上面，加了一条。

【六、门关上后，不能从门那边，再开。】

"你加这条干什么。"旺财问。

"打补丁。"林述说。

"什么补丁。"

"上辈子，"林述说，"我写的代码，总有人能找到漏洞。"

"200 章那次关门，"林述说，"门只是'合上'，没锁死。所以它又从里面敲开了。"

"这次，"他说，"我把漏洞补上。"

"加了这条，门就锁死了。"

"对。"

"那你呢。"

"我？"林述说，"我留在门外。"

他想了想。

"上辈子，我提交代码前，都得测一遍。"他说，"这是最后一次提交。得测好。"

*（第二百六十五章 完）*
