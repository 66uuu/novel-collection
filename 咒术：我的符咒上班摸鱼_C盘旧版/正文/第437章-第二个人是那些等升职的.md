# 第四百三十七章 第二个人是那些等升职的

林述找的第二批人，是那些坐在桌子前等升职的。

一共十七个。

"我要关一个任务。"他说。

没人理他。

"关完，你们就不用等了。"

有一个人抬起头。

"不用等什么。"

"不用等升职。"

"不等升职，我干什么。"

"你可以走。"林述说。

那人笑了。

"走哪儿去。"

"哪儿都行。"林述说。

"我在这儿待了三十年。"

"三十年，"那人说，"我已经不会走路了。"

"上辈子，"林述说，"我见过这样的人。"

"哪种。"

"在一个公司待了太久的人。"

"他不是不想走。"

"他是走不了了。"

"因为他会的，"林述说，"只有这家公司里的那一套。"

"出了门，那套没用了。"

"所以他只能留下。"

"留下，"林述说，"一边骂公司，一边怕公司倒。"

十七个人，都低下了头。

"所以你们不反对我。"林述说。

"我们没同意。"

"不反对，"林述说，"就算默认。"

"规矩里写了。"
