# 第二百七十一章 拖住圣主

林述开始"轮换"。

牛符咒一炷香，扛打。

兔符咒一炷香，躲闪。

龙符咒一炷香，挡路。

蛇、马、羊、猴、鸡、狗、猪、鼠、虎，一个一个上。

每换一个，圣主就多耗一分。

"你撑不住的。"圣主说。

"我不用撑住。"林述说，"我只要比你久。"

门，在慢慢合。

林述的盟友，在门边帮他撑。符宗用九符立域，把门撑住。老符纹人在给门喂灵。旺财咬着引者，不让它靠近。

"再撑一会儿。"林述喊。

"撑不住了。"符宗说。

"再撑一会儿。"

林述换了第八个符咒。

他的手，在抖。借来的力量，在退。

"还有四个。"他说。

"你撑不到。"圣主说。

"试试。"

*（第二百七十一章 完）*
