# 第四百六十章 我看见了造者

签到最后一遍，林述看见了造者。

不是活人。

是表上，一个淡淡的影子。

影子很瘦。

弯着腰。

像常年坐着的人。

"你来了。"影子说。

"我来了。"林述说。

"你比我强。"影子说。

"哪儿强。"

"你签得下去。"影子说。

"我签不下去。"

"为什么。"

"因为我怕。"影子说。

"怕什么。"

"怕签完，"影子说，"就没人看门了。"

"没人看门，门就开了。"

"门开了，"影子说，"下面那层就完了。"

"所以我不敢签。"

"我拖了三百年。"

"拖到死。"

林述看着他。

"上辈子，"林述说，"我也怕过。"

"怕什么。"

"怕离职。"林述说。

"怕离了职，公司就转不动。"

"怕项目没人接。"

"怕客户找不到我。"

"怕到后来我发现，"林述说，"我走了，公司照转。"

"项目有人接。"

"客户找了别人。"

"只有我自己，"林述说，"以为我很重要。"

"其实谁都不重要。"

"只有那扇门，"他说，"重要。"
