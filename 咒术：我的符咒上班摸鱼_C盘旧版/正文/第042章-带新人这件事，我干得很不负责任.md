# 第四十二章 带新人这件事，我干得很不负责任

林述带新生的方式，是把他们扔给旺财。

"这只狗，是我的搭档。"他指地上那条土黄田园犬，"它负责侦察。你们跟着它，别跟丢。"

新生A："林前辈，狗能侦察？"

"它比你们能。"

旺财在脑里："你把我当教具？"

"你便宜。"

实战演练。旺财钻进草丛，闻到一只三级咒灵。它回来，在林述脑里报点。林述转头："三点钟方向，六十米，三级。你们去。"

新生们面面相觑，壮着胆子去了。三打一，还打输。

林述蹲树上看着，没帮。等他们被揍得差不多了，他跳下去，一拳清了。

"看到了吗。"他说，"你们三个打不过一只三级。原因不是力小，是乱。"

"那怎么办。"

"分工作业。一个引，一个打，一个补。跟写代码一样，模块化。"

新生们似懂非懂地记。

旺财："你这是在教团队协作。"

"我在教他们别互相甩锅。"

演练结束，新生们累趴。林述给他们一人买了瓶饮料——记账上。

"林前辈，"女生小声问，"您为什么不一开始就帮我们。"

"因为帮了，你们记不住。"林述拧开瓶盖，"被揍过才记得住。"

"那您呢？您也被揍过？"

林述想起被五条悟随手扔飞那回。想起打二级被烫伤那回。

"揍过。"他说，"多了去了。"

新生们愣住。在他们眼里，林前辈是"一拳打穿二级"的狠人。

"前辈也会被打？"

"谁都会被打。"林述说，"区别是，被打完了还站不站得起来。"

他把空瓶扔垃圾桶。带新人，他确实不负责。但有些话，他愿意说。

*（第四十二章 完）*
