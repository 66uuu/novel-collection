# 第二百七十六章 我在门外，回不去了

门关了之后，林述推了三次。

第一次，用牛符咒。

第二次，用十二符咒全开。

第三次，他把脸贴在门上，什么也没用。

门纹丝不动。

"别推了。"旺财说。

"我就试试。"

"你加的那条规矩，"旺财说，"门那边不能开。门这边呢。"

林述愣住。

他掏出十二符咒，按在门上。

门，没开。

"锁死了。"他说。

"你自己锁的。"

"对。"林述说，"我锁门的时候，没想过自己回不回得去。"

他坐在地上，靠着门。

"上辈子离职，"他说，"还能回原公司。老板还会说'随时欢迎'。"

"这次呢。"

"这次，"林述说，"真的回不去了。"

*（第二百七十六章 完）*
