# 第三百二十一章 我决定去看看

林述想了一夜。

第二天早上，他做了决定。

"我去看看那扇门。"他说。

"你疯了。"旺财说。

"没有。"

"他说的，你信了？"

"信一半。"

"哪一半。"

"上面有扇门，"林述说，"这一半我信。"

"他是从上面来的，这一半我信。"

"他说的'我是锁'，这一半，我不信。"

"为什么。"

"因为，"林述说，"锁不会自己走路。"

"锁会被人拿。"

"我是被人拿的那把锁。"

"拿我的人，"林述说，"上辈子就死了。"

旺财看着他。

"那你去干嘛。"

"去看看。"

"看看有什么好看的。"

"看看那扇门，"林述说，"是不是真在被人敲。"

"要是真在敲，"他说，"我得想想办法。"

"想什么办法。"

"想，"林述说，"怎么把敲门的那个，也锁进去。"

"你打得过？"

"打不过。"

"那你怎么锁。"

"上辈子，"林述说，"我打不过的需求，我一般都能改。"

"怎么改。"

"改成，"林述说，"不做。"

*（第三百二十一章 完）*
