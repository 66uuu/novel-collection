# 第三百五十八章 我造了个旺财

林述试着造了一条狗。

土黄色的。

断耳，断尾。

"你造我干嘛。"旺财说。

"练手。"林述说。

"练手。"

"对。"

"你造出来的，"旺财说，"不是我。"

"我知道。"

"那你还造。"

"因为，"林述说，"我想看看，我能不能造出你。"

那条造出来的狗，摇着尾巴，看着他。

很乖。

不嘴欠。

"你看，"旺财说，"它多乖。"

"嗯。"

"你喜欢乖的。"

"不喜欢。"林述说。

"为什么。"

"因为，"林述说，"乖的，不是共犯。"

"乖的，是宠物。"

他抬手，那条狗散了。

"造出来的东西，"他说，"再好，也不是你。"

旺财看着他。

"你这话，"它说，"说得我有点感动。"

"别感动。"林述说。

"感动了，你又要跟我谈分红。"

"谈分红怎么了。"

"谈了三年了。"林述说。

"没谈成一次。"

"这次谈成。"旺财说。

"滚。"

*（第三百五十八章 完）*
