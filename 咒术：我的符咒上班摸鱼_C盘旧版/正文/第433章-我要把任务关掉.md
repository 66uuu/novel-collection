# 第四百三十三章 我要把任务关掉

林述在表上，找到"验收"那一栏。

空的。

空的下面，有个小小的加号。

"这个加号是什么。"旺财说。

"是'填写'。"林述说。

"填了就关了？"

"填了，就进'待审批'。"

"待审批之后呢。"

"之后要'复核'。"

"复核之后呢。"

"之后要'确认'。"

"确认之后呢。"

"之后要'归档'。"

"归档之后呢。"

"归档之后，"林述说，"才真正关掉。"

旺财沉默了一会儿。

"这几步，"它说，"谁做。"

"没人。"林述说。

"没人怎么做。"

"上辈子，"林述说，"这几步，本来是一个人的活。"

"一个人，从头做到尾。"

"做完，任务就关。"

"那现在为什么没人。"

"因为那个人，"林述说，"就是造者。"

"他死了。"

"他死了，这活就没人接。"

"没人接，就一直卡在'验收'。"

"卡在这儿，"林述说，"门就一直有缝。"

"所以你要接。"旺财说。

"对。"林述说。

"我接。"

"我要一个人，"林述说，"把这五步全走完。"

"从'验收'到'归档'。"

"一个人走完，系统才认。"
