# 第一百一十九章 拖住三分钟，救下四百人

林述拖了宿傩三分钟。

三分钟里，他堵了五次通道，被打了五次，爬起来五次。

第三分钟，旺财的消息传来："四百人，撤出去了。"

林述笑了。

"够本了。"

宿傩看着他，那眼神里有种奇怪的东西。不是愤怒，也不是兴趣。是一种……罕见的"认真"。

"你叫什么。"宿傩问。

"林述。"

"林述。"宿傩说，"我记住了。"

他抬手。林述知道，这次躲不过了。

就在这时，通道另一头，传来声音。

"林述！"

是七海。带着几个人，冲了进来。

宿傩回头看了一眼，皱了皱眉。

"人多了。"他说，"没意思。"

他转身，往通道的另一头走。那里，他刚刚堵开了一条路。

林述瘫在地上。

七海冲过来："你怎么样。"

"死不了。"林述喘着，"宿傩……走了？"

"走了。"

林述闭眼。他拖了三分钟，救下四百人。

代价是：被宿傩打了五次，浑身是伤。

"你疯了。"七海说，"那是宿傩。"

"我知道。"林述说，"但通道那头，有四百个普通人。"

七海沉默。

"你这人，"他最后说，"真是个怪物。"

林述笑。笑得很累。

*（第一百一十九章 完）*
