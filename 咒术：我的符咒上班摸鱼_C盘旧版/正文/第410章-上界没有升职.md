# 第四百一十章 上界没有升职

"上界没有升职。"师兄说。

"那你还等。"

"不等，我干什么。"

林述想了想。

"你可以走。"

"走不了。"师兄说。

"为什么。"

"我在门里面。"师兄说。

"门没关，我出不来。"

"那我帮你关。"林述说。

师兄看着他。

"你能关？"

"我能试试。"

"你拿什么关。"

"用我自己。"林述说。

"你？"

"我下面还有一扇门。"林述说。

"外域和门外那扇。"

"我锁过。"林述说。

"那次我用了十二个符咒。"

"这次，"他说，"我也能用。"

师兄摇头。

"不一样。"

"怎么不一样。"

"你锁下面那扇，"师兄说，"那是两层的门。"

"这扇，"师兄说，"是三层的门。"

"三层的门，得三层的钥匙。"

"钥匙在哪儿。"

"钥匙不是东西。"师兄说。

"钥匙是'所有人都同意'。"

林述愣住。

"同意什么。"

"同意关。"师兄说。

"只要有一个不同意，"他说，"门就关不上。"

"这三十年，"师兄说，"我一直是唯一一个同意的。"

"所以门，"他说，"一直开着。"
