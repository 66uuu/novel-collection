# 第四百七十九章 从我身上

林述脱下上衣。

背上，有一道印。

不是疤。

是一道很淡的线。

像铅笔画的。

"这就是缝。"他说。

"这么细。"旺财说。

"细就够了。"林述说。

"上辈子，"他说，"我修过一个水管。"

"漏得很厉害。"

"我拿胶带缠了三层。"

"不漏了。"

"但有个地方，"林述说，"还渗。"

"渗得很慢。"

"一天一滴。"

"我说，'这不行'。"

"师傅说，'行'。"

"他说，'你别管它'。"

"'它自己会堵'。"

"为什么。"

"因为水里的杂质，"林述说，"会慢慢把那点缝填上。"

"填上以后，就一点不漏了。"

"所以缝不用大。"

"大缝反而堵不上。"

"就这点细的，"林述说，"刚好。"

"刚好够我过去。"

"再多一点，"他说，"门就关不严了。"
