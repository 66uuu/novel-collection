# 第一百三十一章 战后，我还是要上班

涩谷之后，林述回了高专。

不是休整。是上班。

"战损报告、伤员安置、后手盘点。"夜蛾扔给他一沓文件，"你是现场调度，你来写。"

林述接过来。涩谷那么大的仗打完，别人休整，他写报告。

"你这人，"旺财说，"打完仗第一件事是写报告。"

"上辈子习惯了。"林述说，"打完项目，得复盘。"

他写报告，写得很细。哪条后手响了，哪条没用上，哪条出了岔子。

【复盘：】
【有效后手：情报网、咒具、撤离路线、御三家支援队。】
【失效后手：咒具'隙'（三刀用完）、线人损失三个。】
【意外收获：龙符咒、蛇符咒、一级评定。】
【教训：咒力续航仍是短板。】

写完，他交了。

"你这报告，"夜蛾看了半天，"比正式的还细。"

"因为是我自己埋的线，我自己清楚哪条断了。"

夜蛾沉默。他把报告收起来："下次，还让你调度。"

林述点头。

涩谷过去了。但日子还得过。

"旺财。"

"嗯。"

"回家。"

"回哪个家。"

"宿舍。"林述说，"我的宿舍，还在。"

*（第一百三十一章 完）*
