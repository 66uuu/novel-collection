# 第一百零六章 我成了这群人的主心骨

五条悟没了，涩谷的咒术师群龙无首。

消息一个接一个传来，全是坏消息。谁被困了，谁受伤了，哪条路被堵了。

有人开始慌。

林述打开耳麦。

"所有人，听我说。"

他的声音不大，但通过十七条线人的中继，传遍了涩谷的咒术师。

"五条悟被封印了。但涩谷还没丢。"

"我现在手里有：一张涩谷全图，十七个线人，八件咒具，三条撤离路线。"

"谁在哪个位置，报给我。我来调度。"

耳麦里安静了一下。然后，声音一个个来。

"东口，灰原，需要支援。"
"中央通道，两名二级咒术师，听你指挥。"
"地下三层，被困五人，位置不明。"

林述把他们标在图上。

十二年，他背下了涩谷的每一条路。现在，这些路，成了他的武器。

"东口，退到B2出口，灰原接应。"
"中央通道，往南走，那里有咒具补给。"
"地下三层，往东，第三道门能开。"

他一条条指挥。人群开始有序起来。

"你什么时候成了指挥官。"旺财问。

"从五条悟被封印那刻起。"林述说，"没人站出来了，我就得站出来。"

他看着手里的图。

他不是最强的。但他有一张图，和十二年的准备。

这就够了。

*（第一百零六章 完）*
