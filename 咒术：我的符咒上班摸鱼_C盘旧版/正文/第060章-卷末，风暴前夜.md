# 第六十章 卷末，风暴前夜

林述在医务室躺了半个月。

断了的肋骨，硝子一根根接回去。她一边接一边骂："特级咒灵。你一个三级，冲特级。你脑子呢。"

"我脑子在。"

"在个屁。"硝子按他伤口，他疼得龇牙，"下次这种活，让五条悟去。"

"他去了。"林述说，"我拖到他来。"

硝子停手，看了他一会儿。

"……你知不知道，你差点死。"

"知道。"

"知道还去。"

"那几万人，不知道自己要死。"林述说，"我知道。所以我去。"

硝子没再骂。她点烟，坐窗边，抽了很久。

"怪物。"她说。这句，她说了第二遍。

林述笑。他躺床上，翻本子。

【特级咒灵事件：住宅区数万人，伤亡0（五条悟及时到）。】
【我：重伤，躺半月。牛符咒扛住了第一击，兔符咒拖住了时间。】
【结论：纯力量天花板已到。牛兔能打二级，扛不住特级。】
【第三槽（龙）：13%。】

他盯着"13%"，很久。

龙符咒，要等到涩谷。中间还有几年。

"旺财。"他说。

"嗯。"

"我上次说，三年后涩谷，我攒的东西要一把甩出去。"

"嗯。"

"现在我觉得，我得再快点。"林述说，"这世界，比我以为的更危险。"

窗外，夜蛾在训新人。夏油杰靠在栏杆上，看着远方，不知道在想什么。

硝子抽完烟，回来看他的伤。

林述躺在这间小小的医务室里，听着外面的声音。

他知道，风暴快来了。

天内理子，还有不到半年。夏油杰的崩坏，也快了。

他一个三级咒术师，牛兔两个符咒，一本账，一条狗。

够不够用？

他不知道。但他躺不住。

"硝子。"他撑着坐起来，"我什么时候能下地。"

"一个月。"

"太久了。"

"你急什么。"

林述看向窗外，夏油杰的背影。

"我得赶在，某些事发生之前，把该做的做了。"

*（第六十章 完）*
