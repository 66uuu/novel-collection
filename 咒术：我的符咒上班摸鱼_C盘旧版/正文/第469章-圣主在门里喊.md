# 第四百六十九章 圣主在门里喊

门关到一半，圣主喊了。

"林述。"

"在。"

"你放我出去。"它说。

"不放。"

"我给你好处。"

"什么好处。"

"我把上面那层，"圣主说，"给你。"

"上面那层没人。"

"没人，你就是主人。"

林述笑了。

"上辈子，"他说，"有人也这么跟我说过。"

"谁。"

"一个要卖我公司的人。"

"他说，'你跟我干，我给你股份'。"

"我说，'多少'。"

"他说，'百分之五'。"

"我说，'公司值多少'。"

"他说，'现在不值钱，以后值钱'。"

"我说，'那以后再说'。"

"他急了。"

"他说，'你不信我'。"

"我说，'我不信'。"

"为什么。"

"因为他自己都不信。"林述说。

"他要真信，"林述说，"就不会急着拉人。"

"急着拉人的，都是快撑不住的。"

"所以你上面那层，"林述说，"我不要。"

"我拿了，就得替你看门。"

"我不看。"

"我要下班。"
