# 第八十八章 回来之后，我病了一场

从夏油杰那场架之后，林述的身体就开始不对。

先是胳膊。旧伤复发，一使劲就疼。然后是腰，然后是整个后背。

他没在意。擦点药，接着干活。

一个月后，他倒在了训练场。

不是被打倒的。是练着练着，眼前一黑，人栽下去。

醒来时，在医务室。硝子站床边，脸色很难看。

"你的身体，是空的。"她说。

"什么意思。"

"你这两年，一直在用咒力、扛伤、熬夜。"硝子说，"牛符咒给你力量，但它不给你恢复。你把身体当机器用，用到了极限。"

"那我……"

"你要休息。"硝子说，"真休息。不是躺三天那种。是一个月，什么都不干。"

林述想说什么。

"别跟我讲条件。"硝子打断他，"你再这么下去，不用别人打你，你自己就先垮了。"

林述沉默。

他躺床上，看天花板。

这两年，他确实拼。清怪、布局、战斗、养伤、再战斗。像一台永不停的机器。

他上辈子就是这么死的。加班，熬夜，然后没了。

这辈子，他又走上同一条路。

"旺财。"他说。

"嗯。"

"我是不是，又要犯同样的错。"

"有点。"旺财说，"你老说要'活得久'，可你活得比谁都拼。"

"因为时间不够。"

"时间是够的。"旺财说，"你要是死了，就真不够了。"

林述愣住。

这话，扎心。

"行。"他说，"我休息。"

*（第八十八章 完）*
