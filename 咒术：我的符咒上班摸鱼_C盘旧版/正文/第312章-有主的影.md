# 第三百一十二章 有主的影

林述抓了一只"会躲"的影。

他没杀，把它困在符纹里。

"你听。"他跟旺财说。

旺财竖起耳朵。

"它在说话。"

"说什么。"

"听不懂。"旺财说，"但它不是自己在说。"

"是有人在它后面，说。"

林述盯着那只影。

影的身上，有一道纹。

不是符纹。

是一种他没见过的纹。

"这纹，"他说，"不是门外的。"

"那是哪的。"

"我不知道。"林述说，"但我知道一件事。"

"什么。"

"有人在门外之外，"他说，"往这儿派兵。"

"你怎么知道。"

"因为，"林述说，"符纹是我这儿的写法。"

"咒纹是我门里的写法。"

"这道纹，两种都不是。"

"是第三种。"

旺财凑近看那道纹。

"这道纹，"它说，"看着比符纹老。"

"老多少。"

"不知道。"旺财说，"但我闻着，它比圣主还老。"

*（第三百一十二章 完）*
