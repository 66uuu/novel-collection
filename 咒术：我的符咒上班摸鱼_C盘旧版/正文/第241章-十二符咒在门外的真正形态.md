# 第二百四十一章 十二符咒在门外的真正形态

引者走后，老符纹人来找林述。

"你知道你持的十二符，是什么吗。"

"金手指。"林述说。

"什么。"

"……一个能让我变强的宝贝。"

老符纹人摇头。

"门外看十二符，"它说，"不是'宝贝'。是'身体'。"

"什么身体。"

"圣主的身体。"老符纹人说，"圣主有十二块。牛、兔、龙、蛇、马、羊、猴、鸡、狗、猪、鼠、虎。每一块，是一种力量。"

林述愣住。

"那门里那本书上的十二符咒……"

"是'抄本'。"老符纹人说，"照圣主的身体，抄的。抄本有力量，但没有'魂'。"

"所以我手里这十二个，是抄的。"

"对。"

林述低头，看着自己的手。

十二符咒，一直在。

"抄本也能用。"老符纹人说，"但真正的十二块，还在门外，散着。"

"散在哪。"

"圣主被锁的时候，身体碎了。"老符纹人说，"碎成十二块，散在门外各处。"

林述沉默了很久。

"我一直以为，"他说，"我捡了个金手指。"

"你捡的是，别人的器官。"

*（第二百四十一章 完）*
