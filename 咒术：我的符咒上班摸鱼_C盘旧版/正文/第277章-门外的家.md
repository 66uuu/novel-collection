# 第二百七十七章 门外的"家"

门外的棚子，林述重新盖了。

老符纹人给了他一堆符石。符宗用九符立了个域，把域缩小，做地基。

三天，盖好一间屋子。

不大，一间。四面墙，一个门。屋顶是符纹搭的，不漏雨。

"这算家了。"旺财说。

"算。"林述说。

他坐在屋里，看了看四周。

一张符石床，一张符纹桌，一个符力灶。

"上辈子，"林述说，"我在城里租过八平米的隔断。"

"什么样。"

"一张床，一个马桶，一个灶台，挤在一起。"林述说，"晚上隔壁打呼，我听得一清二楚。"

"这儿呢。"

"这儿，"林述说，"好歹是我自己盖的。"

他躺在符石床上。

门外，天是灰的。但他睡得着。

*（第二百七十七章 完）*
