# 第三百一十三章 我去查影的源头

林述带着旺财，往影最多的方向走。

走了七天。

越走，影越多。

越走，那些纹越清楚。

"快到了。"旺财说。

"到哪。"

"源头。"

他们站在一片荒地前。

荒地上，有一个坑。

坑很深，看不到底。

影，从坑里爬出来。

一只，两只，三只。

"这不是源头。"林述说。

"那是什么。"

"这是井。"

"什么井。"

"有人在另一头，"林述说，"往下倒东西。"

"倒出来的，就是影。"

林述蹲在坑边，往下看。

黑。

深。

有风从下面吹上来，是酸的。

"我要下去。"他说。

"下去干嘛。"

"看看谁在倒东西。"

"你下不去。"旺财说，"这坑，是往外的。"

"什么意思。"

"意思是，"旺财说，"这坑不在这世上。"

"它在两界之间。"

"你下去了，"旺财说，"就到别的地方了。"

林述站在坑边，看了很久。

"那我记下这个位置。"他说。

"迟早要下去。"

*（第三百一十三章 完）*
