# 第四百四十五章 流程改不动

圣主盯着林述。

"你说这些，没用。"它说。

"我知道没用。"林述说。

"那你还说。"

"我说这些，不是为了说服你。"林述说。

"是为了拖时间。"

"拖什么时间。"

"拖到任务关闭。"林述说。

"任务关不掉。"

"为什么。"

"因为我不签。"圣主说。

"你不签，"林述说，"也可以。"

"什么意思。"

"上辈子，"林述说，"流程里有一条。"

"叫'逾期自动通过'。"

"逾期？"

"对。"林述说。

"一个审批，"林述说，"挂着不动。"

"挂够时间，系统就默认通过。"

"为什么。"

"因为系统不能一直等。"林述说。

"系统要往下走。"

"你不表态，系统就当你默认。"

"所以，"林述说，"你现在拖得越久，对你越不利。"

"你越不签，我就越省事。"

圣主愣了。

"你这是耍赖。"

"对。"林述说。

"上辈子我学会的最有用的一招。"

"叫'熬'。"

"熬死甲方，熬走领导。"

"熬到没人管了，"林述说，"你就赢了。"
