# 第三百六十八章 我又变回普通人

林述醒了。

躺在一块石头上。

旁边，旺财趴着。

"你醒了。"旺财说。

"我……"

"你被空吃了。"旺财说。

"吃了什么。"

"吃了你的'信'。"

林述坐起来。

他摸了摸胸口。

十二块石头，还在。

但他看着它们，什么感觉都没有。

"我想不起来。"他说。

"想不起来什么。"

"想不起来我为什么要上去。"

"想不起来符塾。"

"想不起来那二十个孩子。"

旺财看着他。

"你还记得我吗。"

林述看了看它。

"记得。"他说。

"你是谁。"

"你是……"林述想了想，"一条狗。"

"对。"

"跟着我的。"

"对。"

"我为什么带着你。"

"因为，"旺财说，"你上辈子，答应过养我。"

"我上辈子养过狗？"

"没有。"旺财说。

"是你自己说的。"

"你活过来了，"它说，"就得养我。"

林述沉默了一会儿。

"我记得你。"他说。

"为什么。"

"不知道。"林述说。

"就是记得。"

*（第三百六十八章 完）*
