# 第六十六章 从伏黑甚尔手里活下来

林述用一只断手，把理子拽出了巷子。

甚尔没追。他在跟五条悟、夏油杰打。在他眼里，一个三级的小角色，不值得回头。

林述拖着理子，跑到一条岔路口。

"往那边跑。"他指左边，"一直跑，别回头。"

"你呢。"理子哭着问。

"我断后。"

理子不肯走。林述把她推开："跑！你活着，我才有意义！"

理子跑了。

林述站在岔路口，靠着墙。他一只手臂废了，另一只还能动。牛符咒，兔符咒，都还在。

他知道自己挡不住甚尔。但他知道，甚尔只要多花一秒在他身上，理子就多跑一秒。

果然，甚尔来了。

"你怎么还在这。"甚尔看着他，有点意外，"你不是她的护卫。你是打杂的。"

"打杂的也有工钱。"林述说，"我得对得起工资。"

甚尔笑了："有意思。"

他抬手，一拳。

林述用牛符咒硬扛。

扛住了。

不是没受伤。是那一拳的力，被牛符咒的力顶住了七成。剩下三成，震得他内脏翻涌，嘴角流血。

但没死。

甚尔挑眉："你这力气，能扛我一拳。"

"还能扛第二拳。"林述喘着。

"扛不了。"

甚尔第二拳，林述用兔符咒躲了半招，另一半砸在肩上。他飞出去，撞断一根电线杆。

他趴在地上，眼前发黑。

但甚尔没补第三拳。

远处，传来五条悟的声音。

甚尔回头看了一眼，骂了句什么，走了。

林述躺在废墟里，看天。

他活下来了。

代价是：手臂断，肋骨断，内脏挫伤，浑身是血。

【遭遇伏黑甚尔：败。牛符咒能扛一拳（七成），扛不了第二拳。】
【结论：'体系外力量'不是无敌。甚尔就是反例。纯力量，有天花板。】

旺财跑过来，用鼻子拱他。

"别死。"

"死不了。"林述笑，笑着咳血，"我还欠硝子治疗费。"

*（第六十六章 完）*
