# 第三百二十七章 第二扇门

墙上有门。

门不大，比林述锁的那扇，小。

但门是"活"的。

它会呼吸。

一起，一伏。

"这就是第二扇门。"小懒说。

"对。"

"上面那扇。"

林述站在门前。

门缝里，透出光。

不是符力的光。

是另一种光。

白的，很亮。

"有人在敲。"旺财说。

林述侧耳听。

门后，有声音。

一下，一下。

很慢。

很沉。

像有人在门后面，用拳头砸。

"敲了多久了。"林述问。

"不知道。"旺财说，"但我闻着，这声音，比圣主还老。"

林述伸手，按在门上。

门，温的。

像有人在门后面，贴着手。

"它知道我在。"林述说。

"你怎么知道。"

"因为，"林述说，"我手贴上去，它不敲了。"

"停了。"

门后，安静了。

一秒。

两秒。

三秒。

然后，门后传来一个声音。

很轻。

"……终于来了。"

*（第三百二十七章 完）*
