# 第三百一十五章 一个受伤的陌生人

回符塾的路上，林述捡了个人。

躺在路边，浑身是伤，晕着。

"救不救。"旺财问。

"救。"林述说。

"万一是坏人呢。"

"坏人，"林述说，"也得先醒过来，才能当坏人。"

他把人背回符塾。

符七给他包了伤口。

三天后，那人醒了。

他睁眼，看见林述。

第一句话是：

"这里……是第几层。"

林述愣住。

"什么第几层。"

"你这里，"那人说，"是第几层世界。"

"我不知道你在说什么。"

那人沉默了一会儿。

"我来自外面。"他说。

"我知道，"林述说，"门外。"

"不。"那人说。

"是门外之外。"

林述没说话。

"你说清楚点。"他说。

那人抬手指了指头顶。

"你们这儿，"他说，"是中间。"

"上面还有一层。"

"下面，还有一层。"

"我，"他说，"从上面掉下来的。"

林述看着他。

"你叫什么。"

"……"那人想了想，"我叫什么，忘了。"

"忘了？"

"掉下来的时候，"那人说，"名字摔碎了。"

*（第三百一十五章 完）*
