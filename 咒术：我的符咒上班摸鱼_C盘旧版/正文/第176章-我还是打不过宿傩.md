# 第一百七十六章 我还是打不过宿傩

林述还是打不过宿傩。

八个符咒全开，被宿傩按着打。他被一掌拍下去，砸进地里。

"你打不过。"宿傩站在坑边，"承认吧。"

林述从坑里爬出来，一身伤。马符咒在治。

"打不过。"他承认，"但我还在。"

"你还想打？"

"不想。"林述说，"但我不走。"

宿傩看着他，有点无奈。

"你这人，"他说，"是块牛皮糖。"

"对。"林述说，"我上辈子，就是这么熬项目的。"

他站起来，又冲上去。

被拍飞。爬起来。再冲。再被拍飞。

八个符咒，一个接一个被打散。马符咒治伤，治完又被拍。

"你在干嘛。"旺财喊。

"拖。"林述说，"五条悟那边，快好了。"

"你怎么知道。"

"我埋的线。"林述说，"有人在拆狱门疆。"

宿傩停下动作。

"你埋了线？"

"对。"林述说，"十二年前，我就知道五条悟会被封印。所以，我一直在准备'解开它'。"

*（第一百七十六章 完）*
