# 第四百八十六章 符塾还在

第二天，林述去了符塾。

还在。

墙歪了。

屋顶补过。

门牌还是他走之前那块。

"符塾"两个字，是他刻的。

"你刻的字，还在。"旺财说。

"嗯。"

"歪了。"

"歪了也没倒。"林述说。

"为什么。"

"因为地基好。"林述说。

"上辈子，"他说，"我们公司搬过三次家。"

"搬一次，牌子重做一次。"

"最后一次，牌子做得特别大。"

"挂上去，三个月，公司倒了。"

"牌子被人拆下来，卖了废铁。"

"我当时想，"林述说，"牌子再大，也没用。"

"公司好不好，不看牌子。"

"看地基。"

"地基就是人。"

"人还在，"林述说，"牌子歪了也没事。"

"人没了，牌子再正，也是空的。"

林述走进符塾。

里面有孩子。

在念东西。

念得不齐。

但很响。
