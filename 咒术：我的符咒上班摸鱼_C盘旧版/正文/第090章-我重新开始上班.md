# 第九十章 我重新开始上班

休息一个月后，林述回高专了。

夜蛾看他一眼："气色好了。"

"睡够了。"

"那就干活。"夜蛾扔给他一沓委托，"积压的，自己挑。"

林述接过来，翻了翻。全是二级、三级。

他挑了三单。剩下的推给七海。

"你又转包。"夜蛾说。

"资源优化。"

日子重新过起来。

早上训练，白天跑委托，晚上记本子。周末去看灰原，或者去情报据点收消息。

夏油杰走后，高专冷清了一阵。但人总得往前过。

"你不难受了？"旺财问。

"难受。"林述说，"但难受不能当饭吃。"

他学会了一件事：把难受，折成具体的活。

想夏油杰，就去整理他留下的档案。想理子，就去看看她侍从过得怎么样。

"你这是把情绪，做成KPI。"旺财说。

"对。"林述说，"上辈子加班教会我的——难受归难受，活还得干。"

他摊开本子，重新写日程。

【日常：训练（早）→委托（日）→记账（晚）。】
【周常：看灰原、收情报、维护布局。】
【月常：评估后手表，补充资源。】

"你这表，跟公司排班一样。"旺财说。

"我就是按排班活的。"

林述合上本子。窗外的樱花落了。

他重新上班了。

这班，他上得比谁都认真。因为他知道，剩下的时间，不多了。

*（第九十章 完）*
