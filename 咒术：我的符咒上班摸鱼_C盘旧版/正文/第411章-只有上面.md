# 第四百一十一章 只有"上面"

"上面到底是什么。"林述问。

"上面是个位置。"师兄说。

"位置？"

"对。"

"一张椅子。"

"谁坐。"

"没人坐。"师兄说。

"没人坐，但它在那儿。"

"谁定的。"

"不知道。"师兄说。

"我来的时候，它就在。"

"你坐过吗。"

"没有。"

"为什么。"

"不敢。"师兄说。

"坐了会怎样。"

"不知道。"师兄说。

"上辈子，"林述说，"我们公司也有这么个位置。"

"什么位置。"

"总监的椅子。"林述说。

"总监跑了半年。"

"椅子一直空着。"

"但每天还有人给那把椅子擦灰。"

"为什么。"

"因为万一新总监来了呢。"林述说。

"擦灰的人，"他说，"是想让新总监记住他。"

"结果新总监一直没来。"

"椅子擦得比谁都亮。"

"后来呢。"

"后来那把椅子，"林述说，"被搬去做会议室的备用椅了。"

"擦灰的人，白擦了半年。"
