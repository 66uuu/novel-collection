# 第四百六十六章 门开始关

任务归档的那一刻，门动了。

不是被撞。

是它自己动。

"它关了。"旺财说。

"关了。"

门上的缝，一点一点收。

慢。

很慢。

"为什么这么慢。"旺财说。

"因为关了，"林述说，"就回不去了。"

"什么回不去。"

"上面那层，"林述说，"会跟着一起消失。"

"为什么。"

"因为上面那层，"林述说，"是'门没关'长出来的。"

"门一直没关，上面就一直在。"

"门关了，上面就没了。"

"就像上辈子，"林述说，"一个项目不结。"

"它的目录就一直在。"

"占着地方。"

"结了，目录就删了。"

"删了以后，"林述说，"你连它叫什么，都会忘。"

旺财看着那扇门。

门里，圣主的影子，慢慢缩下去。

"它呢。"旺财说。

"它回去。"林述说。

"回哪儿。"

"回它该在的地方。"

"它该在哪儿。"

"锁里。"林述说。

"它本来就不该有'想'。"

"它有'想'，是因为门有缝。"

"缝没了，它的'想'就没了。"

"没了'想'，它就只是把钥匙。"

"钥匙，"林述说，"不会想跑。"
