# 第四百五十七章 全体同意达成了

"造者呢。"旺财说。

"他死了。"林述说。

"死了怎么签。"

"他不用签。"林述说。

"为什么。"

"上辈子，"林述说，"有个规矩。"

"叫'代签'。"

"人没了，他的活，由接手的人代签。"

"谁接手。"

"我。"林述说。

"你凭什么接手。"

"凭我是'遗留任务'。"林述说。

"表上写了，我是他留的。"

"他留的东西，我接。"

"那圣主呢。"

"它不签。"

"那就不算全体同意。"

"算。"林述说。

"为什么。"

"因为有一条，"林述说，"'利益相关方，逾期未表态，视为同意'。"

"它表了吗。"

"它撞了十四天门。"林述说。

"撞门，就是表态。"

"表态的内容是'我不同意'。"

"那是不同意。"

"对。"林述说。

"但它撞不动。"

"撞不动，"林述说，"就等于它没有反对的能力。"

"没有能力反对的反对，"他说，"不算反对。"

"上辈子，这条叫'无效反对'。"
