# 第九十一章 五条悟当了老师，我还在原地

五条悟当了老师。

高专改革，他成了新一届一年级的班主任。

"林述，"他晃到林述面前，"来给我当助教。"

"我？"

"你带过新人，有经验。"

"我带新人，教的是'打不过就跑'。"

"挺好。"五条悟说，"现在的新人，就是缺这个。"

林述成了助教。他一边带新人，一边看五条悟怎么当老师。

这人当老师，跟他当咒术师一样随意。上课不讲理论，直接实战。学生被打哭，他笑。学生打赢了，他也笑。

"你这不是教学生。"林述说，"你这是放养。"

"咒术师本来就是放养的。"五条悟说，"我当年也是这么过来的。"

林述想起，五条悟和夏油杰，也是这么过来的。

一个成了最强，一个走了。

"五条。"林述问，"你还想夏油杰吗。"

五条悟的笑，停了一下。

"想。"他说，"但不影响我干活。"

"你比我豁达。"

"不是豁达。"五条悟说，"是我知道，想他没用。他会回来的。到时候，我再跟他算账。"

林述看着他。

这人嘴上说着"算账"，眼神里却是别的。

"你等着他回来。"

"对。"五条悟说，"我等着。"

林述没再问。

他继续带新人。五条悟当了老师，成了高专的招牌。他还在原地，二级，牛兔，带几个新人。

但他不急了。

"旺财。"他说。

"嗯。"

"有人负责当最强。我负责当'还在的那个人'。"

"什么意思。"

"五条悟会往前走，去当他的最强。"林述说，"我留在原地，等夏油杰回来，等涩谷那天。"

"你原地不动，怎么等得到。"

"我不是不动。"林述说，"我是在原地，垒我的楼。"

*（第九十一章 完）*
