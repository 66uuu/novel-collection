# 第三百七十章 一个外域的村子

往上走的第十五天，林述看见了村子。

村子不大。

十几间屋子。

屋子里有人。

"这里怎么有人。"林述问。

"外域到处都有人。"旺财说。

"他们不怕空吗。"

"怕。"旺财说。

"那他们怎么活。"

"挤在一起活。"旺财说。

"为什么挤在一起，就不怕空。"

"因为，"旺财说，"人多了，信就多了。"

"一个人的信，容易被吃。"

"十个人的信，难吃。"

林述走进村子。

村子里的人，看着他。

"你是外面来的。"一个人说。

"对。"

"你从哪来。"

"下面。"

那人愣了一下。

"下面还有人？"

"有。"林述说。

"下面什么样。"

"下面，"林述说，"有影，有符师，有门。"

那人听不懂。

但那人请林述进屋，给了他一碗水。

"你叫什么。"林述问。

那人想了很久。

"不知道。"他说。

*（第三百七十章 完）*
