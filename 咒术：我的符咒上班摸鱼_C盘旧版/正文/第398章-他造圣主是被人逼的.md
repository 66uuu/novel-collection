# 第三百九十八章 他造圣主，是被人逼的

林述钻到桌子底下。

底下真有东西。

不是钥匙。

是一块石板。

石板上刻着一段话。

刻得很深，像刻了很多年。

"我造圣主的时候，"石板上写，"不是我想造。"

"上面有人要一把锁。"

"我就造了一把锁。"

"他要锁门。"

"我就锁门。"

"他要钥匙。"

"我就把钥匙做成活的。"

"做成活的，它就能自己看门。"

"我就能歇会儿。"

"但活的东西，会想。"

"圣主开始想了。"

"它想，凭什么它看门。"

"凭什么我不能当主人。"

"于是它不看了。"

"它要开门。"

"我只好把它锁死。"

"锁死它，我就走不了了。"

"我得一直看着它。"

"因为我一走，"石板上写，"它就知道我走了。"

"它就会自己开门。"

"所以我留在这儿。"

"留了很多年。"

"我不是不想走。"

"我是走不了。"

最后一行，刻得最浅。

"谁造的锁，谁就得看门。"

"这条规矩，"石板上写，"是上面定的。"
