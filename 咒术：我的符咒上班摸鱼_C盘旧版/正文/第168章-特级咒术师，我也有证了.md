# 第一百六十八章 特级咒术师，我也有证了

从回游出来，林述被评了特级。

不是因为他强。是因为回游里的战绩——他一个人调度了整场，救下的参赛者数量，破了记录。

"特级。"夜蛾把证递给他，"高层批的。"

林述接过证，看了看。

【评定：特级咒术师。】
【评语：战力一级，战功特级。以规则战、调度、救人见长。术式：无。】

"战力一级，战功特级。"林述念着，"这证，有意思。"

"因为你的战力，确实够不到特级。"夜蛾说，"但你做的事，特级。"

林述笑。

十二年，他从无级爬到特级。虽然战力还是"一级"，但官方给了特级的名号。

"旺财。"

"嗯。"

"特级了。"

"你战力还是打不过宿傩。"旺财说。

"我知道。"林述说，"但这证，是我十二年的证明。"

他想起ch25，三级证。想起ch73，二级证。想起ch122，一级证。

现在，特级证。

四张证，十二年。

"旺财。"

"嗯。"

"我把证，都裱起来。"

"你上辈子，是不是也爱裱奖状。"

"上辈子，奖状是公司发的。"林述说，"这辈子，证是我自己挣的。"

*（第一百六十八章 完）*
