# 第四百零五章 令不是念

"令跟念，有什么不一样。"旺财问。

"念是'我要'。"林述说。

"令是'你必须'。"

"念是你自己的。"

"令是别人的。"

"那我怎么用令。"

"你不用。"林述说。

"你用不了。"

"为什么。"

"因为令不是修出来的。"林述说。

"令是发下来的。"

"发下来。"

"对。"林述说。

"上辈子，"他说，"有个东西，叫'权限'。"

"权限不是你自己练的。"

"是别人给你的。"

"给你，你就有。"

"不给，你就没有。"

"你练一辈子，也练不出权限。"

"只能等上面给。"

"那上面不给呢。"

"那你就一辈子用不了。"林述说。

"所以这层，"他说，"比下面更狠。"

"下面靠实力。"

"外域靠信。"

"这层，"林述说，"靠'分配'。"

"实力你能练。"

"信你能攒。"

"分配，你只能等。"

旺财沉默了一会儿。

"那你不就废了。"

"不一定。"林述说。

"为什么。"

"因为分配，"林述说，"也有漏洞。"

"上辈子我见过一个。"

"什么漏洞。"

"被分配的人多了，"林述说，"就会有'临时权限'。"
