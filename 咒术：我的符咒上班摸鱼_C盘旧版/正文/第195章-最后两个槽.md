# 第一百九十五章 最后两个槽

鼠符咒开了。还剩最后一个：虎。

虎符咒。阴阳平衡，分出独立分身。

"最后一个。"林述说。

"虎符咒。"旺财说，"分成两个你。"

"对。"林述说，"这个最难。因为它需要'另一个我'。"

"你怎么分。"

"不知道。"林述说，"虎符咒跟别的都不一样。它要'平衡'。要我承认，我心里有'两个我'。"

他想了想。

"一个是社畜。"林述说，"想摸鱼，想活命，想下班。"

"另一个呢。"

"另一个，"林述说，"想救人。想护住这世界。想证明'活着有意义'。"

"这两个你，"旺财说，"一直打架。"

"对。"林述说，"虎符咒，就是要我把这两个'我'，分开。"

他闭上眼。

"旺财。"

"嗯。"

"最后一个了。"

*（第一百九十五章 完）*
