# 第七十八章 我没能拦住他，这事我记一辈子

林述病了一场。

不是伤，是病。发高烧，烧了五天，说胡话。

硝子守着他，一遍遍降温。他烧得迷糊的时候，喊的还是"夏油"。

第五天，他醒了。

"你终于醒了。"硝子把湿毛巾扔盆里，"我还以为你要死这儿。"

林述看着天花板，没说话。

"夏油杰的事，我知道了。"硝子说，"你别自责。"

"我没自责。"林述说，"我就是……难受。"

他坐起来，翻本子。

翻到"夏油杰"那页。上面是他写的①②③④。

①继续塞东西，做了。
②找机会再谈，做了。
③留退路，做了。
④不拦，但让他知道有人在等，做了。

四条，他全做了。

可夏油杰还是走了。

"我做了所有能做的。"林述说，"他还是走了。"

"因为有些事，不是'做够了'就能改。"硝子点烟，"夏油杰不是被你劝走的，是被这世界推走的。你拦不住一个，被整个世界推着走的人。"

林述沉默。

他知道硝子说得对。可他还是难受。

"我以前觉得，穿越了，知道剧情，就能改变一切。"他说，"现在我知道，我改不了。理子死了，夏油杰走了。"

"你改了一些。"硝子说，"你救了理子的侍从。你让夏油杰走之前，有人跟他道别。"

"这些够吗。"

"不够。"硝子说，"但比什么都不做，强。"

林述躺回去。

他想起夏油杰最后那句话："谢谢你，把我当朋友。"

至少，他做到了这个。

"旺财。"

"嗯。"

"这事，我记一辈子。"

"记着吧。"旺财说，"记着，下次别再让这种事发生。"

*（第七十八章 完）*
