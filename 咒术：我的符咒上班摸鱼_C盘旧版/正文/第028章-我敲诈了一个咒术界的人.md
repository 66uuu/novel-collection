# 第二十八章 我敲诈了一个咒术界的人

林述刷黑卡的时候，被一个人盯上了。

那人穿西装，胸口别枚家纹徽章——御三家外围的狗，替主家跑腿那种。他看见林述刷五条悟的卡，眼神变了。

"小子，那卡哪来的？"

林述："我金主给的。关你屁事。"

那人笑："五条悟的卡，咒术界没几个人敢刷。你是他新养的？"

"养你大爷。"

林述没理他，走了。但旺财在脑里说："这人记你脸了。御三家的人，睚眦必报。"

"记就记。我怕他？"

怕倒不怕。但林述这人，被人惦记，第一反应不是躲，是反手薅一把。

他查了这人。

花三天，用图书馆的系统漏洞，翻出这哥们儿替主家干过的几桩"不干净"的活——私下调拨咒具、瞒报咒灵危害、把责任推给底层术师。每一条，单独拿出来都够他掉层皮。

"证据齐了，"林述跟旺财说，"该去谈笔生意了。"

他约那人在同一家便利店门口。

"你找我？"那人叼烟，"想明白了，来认个错？"

"错你大爷。"林述把一叠照片拍他胸口，"你替主家干的这几票，我存了云盘。三份备份，定时邮件，我三天没上线就群发。"

那人脸色变了。

林述："别紧张。我不是来举报的。我是来谈合作的。"

"合作？"

"你手里有情报，我有渠道。你偶尔漏点御三家内部的风声给我，我手里的东西，就永远躺在云盘里。"

那人盯他半天："你个野路子，敢敲诈御三家的人？"

"野路子才敢。有编制的人怕丢饭碗，我没饭碗可丢。"

林述笑："而且你不亏。我只要情报，不要你的命，不要你的钱。你照常混，我照常看。双赢。"

那人咬牙："……你要什么情报？"

"近半年的异常咒力点。尤其是'被压着不让冒头'的那种。"

那人一愣："你怎么知道有这种？"

"猜的。五条悟也让我查过类似的。"

这话半真半假。林述把五条悟抬出来，既是威慑，也是真话。

那人权衡半天，点了头。

"每月一次。多了没有。"

"成交。"

林述把照片收回来，转身走。走出三步，那人叫住他："……你叫什么？"

"林述。记好，别记错。记错了我天天给你发邮件。"

他走了。旺财在脑里笑："你这敲诈，比我还像狗。不对，比我像人。"

"这叫信息差变现。"

林述回宿舍记账：

【情报源新增：御三家外围人员×1（代号：西装）。】
【获取内容：异常咒力点清单（含"被压制的"若干）。】
【轮盘第二槽：47%。今日没杀怪，靠嘴谈成——不对，是顺路清了只二级。】
【警示：已与御三家结缘，风险上升。但收益更大。】

他把"已结缘"圈红。这步走险，但他算过了：御三家这种庞然大物，不会为一个外围跑腿的小事动真格。动真格的代价，比放着一个"知道太多但不说"的野路子高得多。

他们的最优解是：让他活着，当个不发声的知情人。

而林述的最优解是：用这把柄，换十二年后能用的情报。

"旺财，你说我是不是太缺德了。"

旺财："你问一条狗道德标准？"

"也是。"

林述躺下。五十了。第二槽过半。

*（第二十八章 完）*
