# 第三百章 一个社畜，终于，真的下班了

林述忙完一天的活。

清影，卖情报，看店，上课。

天，暗下来了。

他回到屋前，坐下。旺财趴在他脚边，三只小符兽挤在旁边。

符塾那边，灯还亮着。小懒在带新的符童。

"今天的活，干完了。"林述说。

"干完了。"旺财说。

"灵呢。"

"攒着。"旺财说，"够喂下一个符咒了。"

林述点点头。

他靠在墙上，看着门外那片灰天。

门，锁着。门那边，是五条悟、硝子、七海。是他从 3 级爬到特级的地方。

门这边，是他盖的屋子，是他的符塾，是他的三十个符童。

是他锁的门，他护的人，他干的活。

"上辈子，"林述说，"我加班到死，都没下过班。"

"这辈子呢。"

"这辈子，"林述说，"我锁了门，干了活，护了人。"

天，全暗了。

活，全干完了。

"一个社畜，"林述说，"终于，真的下班了。"

他闭上眼睛。

旺财趴在他脚边，没再说话。

*（全书完）*
