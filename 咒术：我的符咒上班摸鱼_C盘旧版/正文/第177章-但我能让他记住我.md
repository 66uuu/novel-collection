# 第一百七十七章 但我能让他记住我

林述拖住了宿傩三天。

三天里，他被拍了无数次，爬起来无数次。

"你为什么还不倒。"宿傩问。

"因为我倒了，后面的人就死。"林述说。

"后面有谁。"

"有几千个普通人。"林述说，"有我的同事，我的学生，我的朋友。"

宿傩看着他。

"为了几千个跟你无关的人，"宿傩说，"拿命拖我三天。"

"对。"

"蠢。"

"对。"林述说，"我上辈子，也这么蠢。加班到三点，为了一个没人看的项目。"

他站起来，第八次。

"但这次不一样。"林述说，"这次，有人看。"

他抬手，一束火。

宿傩躲开，看着他。

"你叫什么。"

"林述。"

"林述。"宿傩说，"我记得你了。"

"记住就行。"林述说，"打不过你，但能让你记住我。"

*（第一百七十七章 完）*
