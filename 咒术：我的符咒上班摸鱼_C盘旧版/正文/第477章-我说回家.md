# 第四百七十七章 我说，回家

"我也想跟你走。"师兄说。

"你不能。"林述说。

"为什么。"

"你在门里待了三百年。"林述说。

"你的身子，早就是门的一部分了。"

"门关了，你也就……"

"我就没了。"师兄说。

"对。"

师兄笑了笑。

"那我还剩多久。"

"不知道。"林述说。

"可能一会儿。"

"可能很久。"

"上辈子，"林述说，"有个老机器。"

"退休那天，我关了它。"

"关机以后，风扇还转了两秒。"

"两秒。"

"两秒以后，它才停。"

"那两秒，"林述说，"它就是还在。"

"但它已经关了。"

"我想，"林述说，"你也是那两秒。"

"但这两秒，"师兄说，"我想站着过。"

"坐着过了三百年。"

"最后两秒，"他说，"让我站直了。"

他站直了。

没扶桌子。

风吹过来。

他的衣角，动了一下。
