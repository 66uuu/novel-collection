# 第四百一十五章 造圣主的人是被流程逼的

林述回到师兄面前。

"我懂了。"他说。

"懂什么。"

"你师弟，"林述说，"不是被谁逼的。"

"他是被'流程'逼的。"

师兄点头。

"流程要一把锁。"

"他就造了一把锁。"

"流程要锁住门。"

"他就锁了门。"

"流程要他看门。"

"他就看了门。"

"流程没说要他走，"林述说，"所以他没走。"

"他一辈子，"林述说，"都在办流程的活。"

"流程不结束，他就得一直办。"

"那流程为什么结束不了。"

"因为流程的最后一环，"林述说，"是'上面签字'。"

"上面没人。"

"所以签不了。"

"签不了，"林述说，"流程就永远在'进行中'。"

"进行中的活，"他说，"不能丢。"

"丢了就是你的责任。"

"所以他就一直扛着。"

"扛到死。"

师兄看着他。

"你说得对。"他说。

"但你漏了一样。"

"什么。"

"他扛到最后，"师兄说，"不是累死的。"

"是自己不想走的。"

"为什么。"

"因为他觉得，"师兄说，"这活总得有人干。"
