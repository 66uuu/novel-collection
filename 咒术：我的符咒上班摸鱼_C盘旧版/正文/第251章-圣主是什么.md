# 第二百五十一章 圣主是什么

第一个点，在中立区外三百里。

守符者，是一个石头人。坐在地上，一动不动，守着一块亮着的符石。

"你是来抢的。"它开口。

"不是。"林述说，"我是来问的。"

"问什么。"

"圣主是什么。"

石头人看了他很久。

"你不知道。"

"不知道。"林述说，"我持十二符，却不知道我持的是什么。"

石头人沉默了。

"圣主，"它说，"不是神。"

"那是什么。"

"是'门'。"石头人说，"它原本，是隔着两边的'墙'。后来墙想'合'，把两边并成一边。"

林述愣住。

"合并。"

"对。"石头人说，"它想让门两边的世界，变成一个。它觉得，分开是'错'的。"

林述沉默了一会儿。

"上辈子，"他说，"我见过这种老板。天天说要'合并部门'。"

"结果呢。"

"结果，"林述说，"裁的都是员工。"

*（第二百五十一章 完）*
