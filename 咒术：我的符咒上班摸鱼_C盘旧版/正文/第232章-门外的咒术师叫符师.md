# 第二百三十二章 门外的"咒术师"叫"符师"

老符纹人让林述去登记。

"登记什么。"

"符师。"老符纹人说，"你要接正经活，得有身份。"

"没身份呢。"

"没身份，叫'野符'。"老符纹人说，"谁都敢抢你。"

林述想了想。

"登记，要钱吗。"

"五点灵。"

"这么贵。"

"你也可以当野符。"老符纹人说，"被抢一次，就不止五点了。"

林述交了五点灵，去登记处。

登记处在中立区中间，一间符纹搭的大屋子。里面排队，几十个"人"。

林述排到最后。

轮到他，登记的人抬眼。

"姓名。"

"林述。"

"来源。"

林述顿了一下。

"外面。"

登记的笔停了。

"外面是什么。"

"很远的地方。"林述说，"说了你也不知道。"

登记的人没多问，低头写了一行。

"持符。"

"十二个。"

登记的笔，又停了。

它抬头，仔细看了林述一眼，然后写下两个字。

"待核。"

林述拿着身份符牌出来，看着上面那两个字。

"待核。"他说，"上辈子入职，也有一段试用期。"

*（第二百三十二章 完）*
