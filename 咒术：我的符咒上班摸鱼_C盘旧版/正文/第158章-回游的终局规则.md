# 第一百五十八章 回游的终局规则

死灭回游快结束了。

羂索宣布了终局规则：

【终局：点数最高者，获得"开门的资格"。】

"他改规则了。"林述说，"他要把'开门'，变成回游的奖励。"

画面：狗，紧张。

"这样，所有参赛者都会抢点数。"林述说，"包括我。"

他想了想。

"我也加一条。"

他加了一条终局规则：

【终局补充：点数最高者，需半数参赛者同意，方可'开门'。】

这条一加，羂索的规则就废了。

因为半数参赛者，不会同意"开门"——开门意味着世界可能崩。

"你这条，"羂索的声音传来，"是堵我的路。"

"对。"林述说，"你要开门，得先过半数人。"

"你赢不了点数。"羂索说。

"我不用赢。"林述说，"我只要'过半人支持我'。"

他记本子：

【终局规则战：羂索加"点数开门"，我加"过半同意"。】
【结论：我把"开门"，变成了"投票"。羂索要开门，得先说服半数人。】

"你这人，"旺财的画面传来——一条狗，竖大拇指（虽然爪子很短）。

"规则战，我玩得比他熟。"林述说，"他算的是'力量'。我算的是'人心'。"

*（第一百五十八章 完）*
