# 第四十八章 阴死一个人，其实不用很强

有个二级咒术师，盯上了林述的生意。

那人叫不出名字，一张横脸，见谁都想压一头。他找到林述的据点，砸了拉面馆的告示，放话："情报贩子，三天内滚出东京，不然我让你知道什么叫咒术师。"

林述没理他。他查了这人三天。

横脸，二级，术式是"硬化"——把自己变得跟铁一样硬，靠硬碰硬吃饭。为人鲁莽，看不起野路子。有个毛病：贪。接私活，收黑钱。

"这人，"林述跟旺财说，"不用打。"

"怎么弄。"

"他硬。硬的人，最怕软刀子。"

林述做的第一件事，是给横脸送了个"情报"——一条假的温床位置。位置是他自己布的一个坑：一间废弃仓库，里面放了三只他特意引来的三级咒灵，还洒了能激怒咒灵的药粉。

横脸果然去了。他硬化冲进去，三只三级围着打。三级伤不了硬化的他，但能耗。他硬着，能耗十分钟。

十分钟后，药粉起效，他咒力乱了。

林述这时才出现。他没打。他站在仓库门口，把仓库门一关，锁上。

"你慢慢耗。"他隔着门说，"这三只不弄死你，但它们能让你硬化的咒力，耗到见底。等你出来，你术式用不了，我再来收人。"

横脸在里面吼。

林述走了。他在门外等了四十分钟。

横脸出来时，咒力耗尽，硬化失效。林述一拳。

二级咒术师，倒了。

"你没用术式。"旺财说。

"用不着。"林述蹲下，看着躺地上的横脸，"阴人这件事，不用很强。只要比他多算一步。"

他把横脸的钱包和身份卡收了，留了张纸条："下次砸人招牌前，先查对方是干嘛的。"

【处理二级咒术师（横脸）：未正面交手。用假情报+陷阱+耗咒力。】
【结论：对付'只认硬碰硬'的对手，把他拖进他不擅长的局。】

林述把钱包里的钱记进账。这人欠他的招牌钱，连本带利，回来了。

*（第四十八章 完）*
