# 第二百四十二章 兔符咒·二档

林述攒够了兔符咒的灵。

那天晚上，他把灵喂下去。

兔符咒亮了。

他站起来，抬脚，跑。

一步，跨出十丈。

他愣住。

"这……"他说，"太快了。"

"不是快。"旺财说，"是你'没重量'。"

林述又试。这次不是跑，是"停"。十丈外，他说停就停，脚下一片符纹，纹丝不动。

"兔符咒二档，"他说，"不只快，是能'踏空'。"

他试着往上一蹬。

人离地三丈，停了一瞬，又落下来。

"能踩空气。"林述说。

"踩空气有什么用。"

"上辈子挤地铁，"林述说，"这辈子能踩着空气，从人头顶上飞过去。"

他笑了。

"而且，"他说，"清影的时候，快一倍。"

他算了一下。牛符咒清影快三倍，兔符咒快一倍。两个一起用。

"你现在的清影速度，"旺财说，"比符士还快。"

"但符力还是符徒。"林述说。

"对。"旺财说，"你还是个'薄皮大力士'。"

"没关系。"林述说，"薄皮，跑得快就行。"

*（第二百四十二章 完）*
