# 第二百三十六章 我坑了第一个符师

来找林述麻烦的，是个信众符师。

持三符，符士。背上有圣主的印记。

"你那块符石，归我。"它说。

"为什么。"

"因为我说了。"

林述看了看它。符士，符力比他厚。正面打，打不过。

"你借圣主的符力。"林述说。

"对。"

"规矩第二条，"林述说，"借圣主符力者，不许进中立区。"

符士笑了。

"我在区外。"

"那你进来抢我的东西，"林述说，"算不算'动武'。"

符士愣了一下。

它确实站在区线上。脚在外面，手想伸进来。

"你伸进来试试。"林述说，"一百灵。你付得起吗。"

符士的手停在半空。

"你以为我付不起。"

"你付得起。"林述说，"但你主人付不起。"

符士脸色变了。它借圣主符力，罚的灵，最后都得报上去。圣主不会为一个符士，赔一百灵。

它把手收了回去。

"你等着。"它说。

它走了。

林述站在原地，摸了摸自己的符石。

"你没打它。"旺财说。

"不用打。"林述说，"上辈子谈需求，我从来不硬刚。我给它讲条款。"

"你刚才那条，是你自己编的。"

"对。"林述说，"规矩没写'伸进来算动武'。但它不知道。"

*（第二百三十六章 完）*
