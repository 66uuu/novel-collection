# 第四十九章 家入硝子说我是个怪物

家入硝子有个习惯：记住每个病人的伤。

她的记性很好。三年里，林述来她这儿十七次。十七次的伤，她全记得。

第一次，胳膊被咒灵烧红一片。第五次，肋骨裂了两根。第十一次，后背划开一道口子，血把衣服浸透。这一次，是内伤，咒力紊乱。

"……你又来了。"硝子把烟按灭。

"这次轻。"林述趴治疗床上，"内伤，不流血。"

"内伤才麻烦。"硝子手掌贴他后背，咒力渗进去，"你体内那股'别的东西'，又活跃了。"

"老毛病。"

硝子没接话。她治着，心里在算。

这人没有术式。没有家族。没有背景。一个野路子，靠一身怪力和两条腿，在咒术界活了一年多，还活得挺滋润。

正常野路子，早就死了。咒术界这地方，对没背景的人不友好。

可林述不一样。

他每次来，第一句都是"这次多少钱"。第二句是"能不能少点"。被她说"烦"，他就笑，下次还来。

他把身体当工具。坏了修，修好接着用。从不心疼，从不喊疼。

"林述。"硝子忽然开口。

"嗯。"

"你知道你为什么还没死吗。"

"因为我跑得快。"

"不是。"硝子收了手，"因为你把自己当成一台机器。机器不会怕，只会算。这很可怕。"

林述回头看她："这是夸我？"

"是陈述。"硝子点烟，"我见过很多咒术师，怕死，怕疼，怕麻烦。你不怕。你只算划不划算。"

"因为怕没用。"林述坐起来，"我上辈子加班死了，怕不怕都得死。"

硝子看着他。这话她说不出。她天天面对死亡，靠的是把自己变冷。而这人，靠的是把死亡算成一道题。

"怪物。"她说。

"谢谢。"

"没夸你。"

林述笑了，把治疗费放桌上："这次多少。"

"看你烦不烦。"

"那我走了。"

他走后，硝子一个人在医务室坐着，烟烧到了手指。

她想起那些被咒灵吞掉的人，想起自己治不好的伤。想起这人十七次伤，十七次自己走回来。

"……怪物。"她又说了一遍。这次，声音轻了很多。

*（第四十九章 完）*
