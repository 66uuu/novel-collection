# 第一百零四章 五条悟被封印的那一刻

五条悟进了涩谷。

林述在中央通道，看见了那一幕。

最强的男人，站在涩谷的十字路口。周围是咒灵，是诅咒师，是陷阱。

然后，一个东西出现了。

一个方形的牢，叫"狱门疆"。它悬在半空，等着五条悟。

"别过去！"林述想喊。

但他离得太远。

五条悟走了过去。他大概知道那是陷阱，但他不在乎。他是最强的，他没什么好怕的。

然后，狱门疆合上了。

五条悟，被封印了。

那一瞬间，整个涩谷的咒力，都静了一下。

林述站在原地，看着那个合上的方盒。

他知道这一幕。原著里，五条悟就是在这里被封印的。他记得，他等了十二年。

可真的看见的时候，他还是愣了很久。

"五条悟……被封印了。"旺财说。

"嗯。"

"世界最强的那个，没了。"

"对。"

林述握着拳。他早就知道会这样。他改不了。

但他还是，很难受。

"你准备了十二年，"旺财说，"就为了看这一幕？"

"不是。"林述说，"我准备了十二年，是为了在这一幕之后，还能站住。"

他转身，往战场深处走。

五条悟被封印了。最强的靠山，没了。

接下来，是他的仗。

*（第一百零四章 完）*
