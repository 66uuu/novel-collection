# 第八十五章 我见到了他，什么也没做成

夏油杰站在街那头，林述站在这头。

"你该走了。"夏油杰说，"他们快搜到这边了。"

"夏油。"林述往前走了一步，"我问你一件事，你答我。"

"说。"

"你后山那壶酒，"林述说，"你会去喝吗。"

夏油杰沉默。

林述看着他："你走那天说'记住了'。可你没去。"

"我没时间。"

"是没时间，还是不想。"林述说，"夏油，你走，我不拦。但你别把自己活成'只剩恨'的人。"

夏油杰的眼神动了一下。

"你懂什么。"他说，"你没见过那些被非术师害死的术师。你没见过村子怎么对待那个女孩。"

"我见过。"林述说，"我救过一个。理子的侍从。一个非术师，我救的。"

夏油杰愣住。

"非术师里，有坏人，也有好人。"林述说，"你杀的那一百一十二个，里面有坏人。但你知道那女孩吗，她后来被我安置了。她是个非术师。她没害过谁。"

夏油杰没说话。

远处，传来追捕队的脚步声。

"你走吧。"林述说，"但记住我今天说的。"

夏油杰看了他很久。

"林述。"他说，"你救不了我。"

"我知道。"林述说，"但我得说。"

夏油杰转身，消失在街角。

林述站在原地，什么都没做成。

他没抓他，没劝住他，没能改变任何事。

但他说了。他把该说的，说了。

"旺财。"他说。

"嗯。"

"走吧。"

他转身，往回走。身后的脚步声越来越近。

他什么也没做成。但至少，他见了他一面。

*（第八十五章 完）*
