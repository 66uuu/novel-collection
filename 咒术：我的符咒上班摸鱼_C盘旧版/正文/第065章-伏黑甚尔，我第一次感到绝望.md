# 第六十五章 伏黑甚尔，我第一次感到绝望

那个男人，是从阴影里走出来的。

没穿黑衣，一身休闲装，肩上扛着个布袋。走路很懒，像刚睡醒。

但林述的旺财雷达，什么都没报。

"没咒力。"旺财声音发颤，"这人……身上一点咒力都没有。"

没咒力的人，怎么会在这种场合出现？

五条悟的表情，第一次认真了。

"伏黑甚尔。"他说。

林述听过这名字。天与暴君。用咒力换来了极致肉体的男人。咒术界最忌惮的"零咒力"怪物。

甚尔扫了一眼队伍，目光在理子身上停了一下。

"哦，星浆体。"他声音懒散，"接了个活，来杀她。"

五条悟挡在前面："想杀她，先过我。"

"过你？"甚尔笑了，"五条家的少爷。行啊。"

两个人动了。

林述没看清过程。他只看见五条悟冲上去，然后被甚尔一拳打飞。夏油杰补上，术式展开，被甚尔用一个布袋挡下，反手一肘。

两个最强的同期，被打得节节败退。

林述站在原地，手心全是汗。

他知道甚尔强。但他没想到这么强。

五条悟被打退，夏油杰被打退。甚尔朝理子走来。

林述挡在理子前面。牛符咒全开，一拳。

甚尔侧身，抬手，接住了。

接住了。

林述的全力一拳，被这人单手接住，像接一个皮球。

"牛符咒？"甚尔看着他，有点兴趣，"你这力气，不是咒力。有意思。"

他手腕一转。

林述听见自己手臂骨头的声音。

剧痛。他整个人被甩出去，砸在墙上。

他趴在地上，抬头。

甚尔已经越过他，走向理子。

那一刻，林述第一次感到绝望。

不是"打不过"。是"我所有的东西，在这人面前，都不算数"。

牛符咒给力，甚尔更力。兔符咒给速，甚尔更快。他引以为傲的"体系外力量"，在真正的"体系外怪物"面前，什么都不是。

"林述！"理子的声音。

他撑着墙，想站起来。手臂断了，站不稳。

"旺财。"他吐着血，"去……去叫人。"

*（第六十五章 完）*
