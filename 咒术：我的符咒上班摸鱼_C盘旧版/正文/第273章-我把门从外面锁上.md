# 第二百七十三章 我把门从外面锁上

林述站在门缝里。

圣主的半身，在门外，要挤进来。

"让开。"圣主说。

"不让。"

林述掏出那块虎符咒的一角。

碎片贴上门。

门上的符纹，亮了。那是"锁链"的图纸，跟他手里的十二符咒，是一个纹路。

"你拿我的身体，锁我的门。"圣主说。

"对。"林述说。

他把十二符咒，一个一个按在门上。

牛、兔、龙、蛇、马、羊、猴、鸡、狗、猪、鼠、虎。

十二个纹，十二道锁。

门，开始合。

"你会留在门外。"圣主说。

"我知道。"

"你回不去了。"

"我知道。"

门缝，越来越窄。圣主的半身，被挤回去。

最后一道缝，合上。

门，锁死了。

林述站在门外，手还按在门上。

"上辈子，"他说，"锁门，是下班。"

"这辈子锁门，也是。"

*（第二百七十三章 完）*
