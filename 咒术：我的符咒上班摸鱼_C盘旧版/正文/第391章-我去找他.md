# 第三百九十一章 我去找他

林述把队伍交给了石头。

"你管。"他说。

"我不会管。"石头说。

"你会的。"

"我连自己叫什么都不记得。"

"你叫石头。"林述说。

"我起的。"

"我记不住别的。"

"不用记别的。"林述说。

"你就记三条。"

"哪三条。"

"第一，"林述说，"饭一天两顿，别欠。"

"第二，讲不动的故事，别硬讲。"

"第三，我不在，谁也不许说'跟着我'。"

"为什么。"

"因为说这话的，"林述说，"就是想当老大的。"

"老大一多，"他说，"队伍就散了。"

石头点头。

"那你什么时候回来。"

"不知道。"林述说。

"走七天。"

"七天不回呢。"

"那就别等。"林述说。

"该吃饭吃饭。"

"该散散。"

"一个队伍，"他说，"靠一个人撑，迟早塌。"

"上辈子，"他说，"我们组就靠一个人撑着。"

"那人一走，整个组，一天散光。"

"我不当那种人。"
