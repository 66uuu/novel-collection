# 小说合集 · 创作与设定文档

个人创作/整理的中短篇小说、长篇连载、番茄版改稿、人物设定与漫剧改编脚本集合。
按作品系列分目录，包含 Markdown、DOCX、TXT 正文，以及插图与人物资产图片。

## 内容范围

- 多个小说系列的成品、分章文件、不同平台投稿版本与旧版备份
- 人物设定、世界观设定、漫剧改编脚本与构建工具
- 插图、封面与人物资产图片

## 公开范围说明（发布时追加）

- 本仓库是本地 `小说` 目录的公开镜像，**未纳入**一个用于 OCR 语料整理与
  文本分析的工作区目录。该目录含针对个人的分析档案与长文 OCR 稿，
  不属于小说作品本体，且涉及高度敏感的个人信息，故不公开。
- 源码/脚本文档中出现的本机绝对路径与 Windows 用户名已替换为占位符
  （`<DESKTOP>/`、`<USER_HOME>/`、`<WIN_USER>` 等），使用时请替换为自己的路径。
- 作品版权归各自作者所有；如需转载请先取得授权。

## 目录

顶层每个子目录对应一个作品系列或一组相关版本，目录名即作品名。
