# 《梦境失序》封面设计说明

作者：李焱

封面采用竖版心理恐怖海报构图，核心视觉围绕“梦境空间失去秩序”展开：

1. 画面主体是一间被切割成多个不可能空间的卧室，楼梯从不同方向穿过房间，门框彼此重叠，形成无法判断出口的迷宫。
2. 墙上的时钟指向三点，数字出现断裂和错位，作为顾南不断重复的梦境时间锚点。
3. 远景放置多个穿黑衣的模糊人影，人物在门后、窗边和楼梯尽头反复出现，制造“同一个人正在不同位置同时注视”的错觉。
4. 前景使用破裂镜面和多个错位的人脸，表现顾南的自我分裂、记忆重叠和现实边界崩塌。
5. 主色调为冷蓝灰、黑色与暗红色。冷色表现梦境的麻木和窒息，暗红色只作为局部警示色，避免血腥直白，突出心理恐怖。
6. 标题《梦境失序》采用破碎、断裂、略有位移的白色字体，作者名“李焱”置于底部，整体像一张被反复撕开又强行拼回去的梦境记录。

封面成品由生成式图像工具制作，画面重点突出：诡异、混乱、无序、梦境错乱、精神边界崩塌和多重自我重叠。
