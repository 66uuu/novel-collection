# 番茄小说自动发布 · 本机运行指南

> 本脚本在你**自己的 Windows 电脑**上运行，复用你已登录的 Chrome，不用给 AI 密码/cookie。
> AI 所在沙箱无浏览器、pip 被拦，无法代跑——所以这条"真自动化"只能在你本机落地。

## 一、准备环境（只需一次）

1. 装 Python（≥3.10）：https://www.python.org/downloads/ ，安装时勾选 **Add to PATH**
2. 打开命令行（Win+R → 输入 `cmd` → 回车），依次执行：
   ```
   pip install playwright
   playwright install chromium
   ```
   （chromium 约 150MB，需联网，几分钟）
3. 确认你的 Chrome 已登录番茄作家助手网页版：
   打开 https://writer.fanqienovel.com 并登录（能和桌面客户端数据互通）。

## 二、把文件放到本机

把这两个东西放在**同一个文件夹**里（直接复制 AI 给的 `发布自动化/` 和 `发布物料/` 目录即可）：
- `番茄自动发布_本机版.py`
- `发布物料/`（含 30 章 txt + 发布清单.md）

> 脚本默认去找 `../发布物料`，即脚本所在目录的上一级。
> 若你把脚本和 `发布物料` 放在同一目录，请打开脚本把 `MATDIR` 改成 `"./发布物料"`。

## 三、第一次必做：DRY RUN（不真发，只演示）

1. 用记事本打开 `番茄自动发布_本机版.py`
2. 确认顶部 `DRY_RUN = True`（默认就是）
3. 可改：
   - `START`：第一天发布日期
   - `PER_DAY`：每天章数（你要 2）
   - `BOOK["author"]`：你的笔名
4. 命令行进到脚本目录，运行：
   ```
   python 番茄自动发布_本机版.py
   ```
5. 它会打开一个 Chrome 窗口，复用你的登录态，然后**只打印**"将要发布第X章《标题》[字数] 发布于某天"——**不点任何发布按钮**。
6. 你核对：章节顺序、标题、日期是否正确。

## 四、校准选择器（关键一步，AI 替不了）

真实发布要"点击网页按钮"，但每个网站的按钮长什么样（选择器）只有你浏览器里能看到，AI 在沙箱里看不到。你需要：

1. 登录作家助手网页版，**按 F12** 打开开发者工具 → Elements
2. 在脚本里 `真实发布` 注释块（标有"需你本机填选择器"）中，把占位选择器改成你页面实际的：
   - 新建作品按钮的文字/CSS
   - 书名、简介、标签的输入框
   - 写新章、章节名、正文编辑器
   - 定时发布的时间输入框
3. 这步建议**先拿 1 章试发**：把 `chs` 只留第 1 章测试，确认能成功创建+定时，再放开全部 30 章。

## 五、正式发布

确认 DRY RUN 无误、选择器填好后：

1. 把脚本顶部 `DRY_RUN = False`
2. 运行 `python 番茄自动发布_本机版.py`
3. 脚本会逐章创建并设定时发布（每天 2 章，共 15 天放完）
4. 跑完进作家助手后台核对：30 章均在，发布时间排好。

## 六、安全须知

- ✅ 登录态在你的 Chrome 里，脚本只是"复用"，**不导出、不发送给任何人**
- ✅ 脚本默认 `DRY_RUN=True`，第一次绝不真发
- ✅ 发布到的是**你自己的账号**，内容是你原创，无版权问题
- ⚠ 定时发布功能以作家助手网页版实际支持为准；若不支持定时，脚本会改为"全部存草稿"，你再在网页端手动设时间（仍然比一篇篇手敲快）
- ⚠ 若运行报错，多半是选择器没填对——回到第四步用 F12 复核

## 七、如果环境装不上怎么办

- `pip install playwright` 报错 → 确认 Python 已加 PATH，或重装 Python 勾选 Add to PATH
- `playwright install chromium` 下载慢/失败 → 挂代理或换个网络再试
- Chrome 路径不对 → 脚本顶部 `CHROME_USER_DATA` 改成你机器实际的 User Data 路径（Chrome 地址栏输入 `chrome://version` 可查"个人资料路径"）
