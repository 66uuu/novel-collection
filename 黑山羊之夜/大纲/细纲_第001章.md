## 细纲（第 1 章）

### 第 1 章：七月十一
- 核心事件：陈默被送回坳子村，夜里听见玉米地里传来人的脚步声，在枕头下摸到奶奶塞的旧手电。
- 字数目标：8000 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-01 / 第 1 拍（建立期待）
- 目标情绪：闷热无聊 → 隐隐不安（从"熬过这个暑假"到"这村子有点不对"）
- 主角目标/关键选择：目标是熬过无聊的暑假；关键选择——起夜听见脚步时，他选择不开窗、只竖耳朵听，既立谨慎也立好奇。
- 章首钩子：预言式 — "后来陈默才知道，奶奶那句'天黑别往玉米地走'，是拿命换来的。"
- 爽点：无显性爽点，功能是立氛围、埋手电与艾草两个钩子，用"窗纸上的影子"给读者第一个寒颤。
- 本章禁止提前释放：不出现山羊实体；不解释规矩来历；不点明脚步声是谁。

#### 内容概括（五段式）
- 起因：父母忙，把陈默丢给乡下奶奶过暑假。
- 发展：村口热浪、门口艾草、屋里信号一格，陈默刷手机打发时间。
- 转折：夜里起夜，听见玉米地里"沙、沙、沙"的脚步声，节奏像人。
- 高潮：脚步声停在窗外，窗纸上映出一道影子。
- 结尾：他摸到枕头下的旧手电按下开关，光柱打在窗纸上——影子不见了，窗台上落着一小撮湿泥。

#### 情节安排（多线）
- 主线推进：L01 从"回村"起步。
- 辅线推进：L03 从"疏离"推到"奶奶的警告"。
- 事件线 / 任务线：到村—安顿—起夜。
- 感情线 / 关系线：无显性，但奶奶塞手电的动作埋下关心。
- 逻辑线：无聊 → 起夜 → 听见脚步 → 害怕 → 开灯 → 发现湿泥（原因 → 行动 → 结果 → 新问题）。

#### 人物关系和出场顺序
- 出场顺序：陈默、奶奶、玉米地（环境）、旧手电。
- 人物关系变化：陌生 → 被奶奶默默照顾。
- 视角/信息差：读者隐约知道奶奶在隐瞒，陈默不知道。
