# 题材定位

## 基本信息
- 书名：黑山羊之夜
- 题材类型：乡村怪谈 / 民俗恐怖 / 心理惊悚
- 目标平台：番茄小说（快节奏、强钩子、每章结尾留悬念，前三章必须抓人）
- 核心梗：一只直立行走的黑山羊，通过模仿人类来"取替"活人；被取替的人不会死，会在别处以另一头开始直立的羊回来。
- 微创新点：怪物不是"捕食者"而是"模仿者"——恐怖来自"它越来越像人"；叠加"三条乡野规矩"的规则怪谈结构与"人→羊"的转化循环。
- 预计字数：8–12 万字（中篇完结，共 12 章，单章约 7000–10000 字）
- 目标读者：18–35 岁，偏好《规则怪谈》《隐秘的角落》式慢热氛围恐怖

## 作者已定
- 素材来自用户提供的两张图：① 玉米地泥路上直立黑山羊（绿眼、雾、暗夜）；② 一段"回乡少年 11:30 夜探撞见黑山羊"的聊天怪谈。
- 书名定为《黑山羊之夜》。
- 必须保留原故事核心节点：11:30 夜探 → 林边背影 → 转身见羊脸 → 逃回村口它又出现 → 手电短路熄灭 → 少年失踪 → 角落另一头羊开始直立。
- 融合图片元素：玉米地、起雾的泥路、绿眼、拟人微笑。
- 基调：不靠血腥，靠"像人"的细节制造不适。

## 核心设定（草案）
- 一句话梗概：暑假回乡的少年陈默在 11:30 的夜里撞见一只直立行走的黑山羊，他拼命逃回村子，却发现那东西早已在村口等他——它要的不是吃掉他，而是学会成为他。
- 主角：陈默，17 岁，城市长大、叛逆好奇、不信邪；弱点是手机依赖与对乡野规矩的无知；核心动机是"证明自己不怕"。
- 世界观骨架：南方山村"坳子村"，村外连片玉米地与一片老林子，中间一条起雾的泥路；黑山羊是一种以活人为样本的"模仿者"。
- 核心冲突：主线矛盾＝陈默与黑山羊的"被取替"；终极阻碍＝它已经学会了"成为他"，而村里没人相信。

## 读者契约（待定稿）
- 核心读者承诺：慢热逼近的恐惧 + "规则被逐条触犯"的宿命感 + 结局的转化反转。
- 主角代理权承诺：陈默的每一次选择（出门、回头、逃跑）都推动恐怖升级，他不是被动受害者。
- 利益安全线：核心悬念（它到底是什么）不得提前揭底。
- 期待债：开篇承诺"三条规矩"，结局必须全部兑现。
- 题材边界：乡村怪谈，不引入科幻/外星解释，保持不可知。

## 终局底牌与升级台阶（待定稿）
- 终局底牌：转化循环的真相（失踪者＝下一头直立的羊）·最后一卷揭晓。
- 升级台阶：恐怖强度按"背影→转身→追逐→贴身→失踪"五档递进。

## 核心梗三分法
- 表层卖点：玉米地里直立行走的黑山羊。
- 深层爽点：规则怪谈的解谜感与"你会犯哪条"的代入恐惧。
- 长线钩子：它到底想干什么？下一个被取替的是谁？
