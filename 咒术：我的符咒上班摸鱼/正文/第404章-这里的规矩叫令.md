# 第四百零四章 这里的规矩叫"令"

林述走到一张桌子前。

桌上有一张纸。

纸上只有一行字。

"本层规则：令。"

"令。"林述念了一遍。

字就动了。

纸上的字，变成了另一行。

"令：不容违逆。"

林述愣了一下。

"它回话了。"旺财说。

"不是回话。"林述说。

"是它本来就这样。"

"什么意思。"

"你念一遍，就等于点开了一次。"林述说。

"点开，它就走流程。"

"走流程，它就给你下一步。"

"上辈子，"他说，"我们的系统也这样。"

"你输一个词。"

"它弹一堆提示。"

"提示里，有你要的，也有它想让你看的。"

"哪个多。"

"它想让你看的多。"林述说。

"它想让你看什么。"

"让你觉得，"林述说，"它很懂你。"

"其实它只是把你输的词，"他说，"原样吐回来，加两个字。"

旺财看了看那张纸。

"加的两个字是什么。"

"'遵令'。"林述说。
