# 第十六章 我想通了一件事，我打不过所有人

林述摊开本子，画战力表。

五条悟：碰不得。生来就满级。

夏油杰：一级咒术师，术式强，打不过。

夜蛾：等级未知，但稳，别惹。

伏黑甚尔：未来的，碰必死。

自己：牛符咒，无咒力，肉体爆，脑子有。

"结论，"他写，"我打不过任何人。"

旺财："那你活着干啥。"

"活着才能搞钱。"

"搞钱为了啥。"

"为了不用再搞钱。"

狗沉默。这逻辑它绕不进去。

林述想：穿越前他是社畜，以为努力就能升职。穿越后他懂了，有些人天生在终点，有些人连起跑线都没有。

他不是主角命。他是拿着外挂还卡关的玩家。

"但卡关也能玩。"他跟狗说，"就是慢。"

他定年度 KPI：

一、不死后。

二、开兔符咒。

三、攒够钱，退休。

旺财："三最实在。"

"那是终极目标。"

林述把表翻面，写第二张：

【我能打的：四级、三级、二级（费点劲）。】

【我打不过的：一级以上、会术式的、有领域的。】

【策略：不正面刚。用先知、用嘴、用算计。把"打不过"变成"不用打"。】

他想起五条悟说的"别单挑术师"。对。他这号角色，单挑是送。

"伏黑甚尔那关，"他写，"等十二年后的窗口。现在别想。"

十二年。够他慢慢磨。

林述合本子。第二槽十九，没动。今天光想事，没杀怪。

"想也是练。"他自我安慰，"脑子也算加班。"

旺财："加班费。"

"记账。"

窗外东京霓虹。林述躺下。他打不过所有人，但他想通了——这游戏不比谁猛，比谁活得久。

活得久，才有机会开挂。

*（第十六章 完）*
