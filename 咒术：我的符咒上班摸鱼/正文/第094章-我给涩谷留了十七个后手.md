# 第九十四章 我给涩谷留了十七个后手

林述把后手表，重新数了一遍。

【涩谷后手（当前进度）】

【1. 咒具'断'（已得）。】
【2. 咒具'缄'（御三家拍卖所得）。】
【3. 咒具'隙'（黑市淘的）。】
【4. 理子侍从（人情债）。】
【5. 灰原雄（忠诚）。】
【6. 七海建人（未来一级）。】
【7. 家入硝子（唯一治疗师）。】
【8. 五条悟（损友，知情）。】
【9. 情报网（重建中）。】
【10. 西装（御三家内线）。】
【11. 图书馆铁盒（给未来的信）。】
【12. 三条撤离路线（已规划）。】
【13. 存款（六十五万，增长中）。】
【14. 学生三人（已毕业，可托付）。】
【15. 第三槽（龙）——待解锁。】
【16. 咒力修为（二级，持续练）。】
【17. 旺财（雷达+情报+战斗力）。】

十七个。

"数完了。"旺财说，"十七个。"

"对。"林述说，"十二年后，我要把这十七个，一把甩出去。"

"现在有几个能用。"

"能用的，七八个。"林述说，"剩下十个，得慢慢攒。"

他把表贴墙上。这次贴得比上次高，因为表更长了。

"你从什么时候开始，想这个的。"旺财问。

"穿越第三天。"林述说，"我知道涩谷会发生什么。从那天起，我就在准备。"

"准备了这么久。"

"对。"林述说，"别人穿越，是来开挂的。我穿越，是来排期的。"

他看着墙上的十七个后手。

十二年后，涩谷。

那一天，会检验他这两年，还有后面十年的所有准备。

"旺财。"

"嗯。"

"涩谷那天，你还在吗。"

"我一条狗，能活十二年吗。"

"能。"林述说，"你跟我绑定，我活着，你就活着。"

"那就行。"旺财说，"我陪你去。"

*（第九十四章 完）*
