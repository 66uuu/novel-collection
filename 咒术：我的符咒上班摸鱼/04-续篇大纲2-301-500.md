# 《咒术：我的符咒上班摸鱼》续篇二（301-500 章）大纲

> 承接 300 章结局：主角锁死门、留在门外、办符塾当老师。
> 方向：**门外之外**。门外世界不是终点，它只是个"夹层"。

---

## 一句话概括

门外不是世界的最外层。第二扇门后面，还有一层。主角在门外教了几年书，一个从"门外之外"掉下来的人，把更大的世界带到了他门口。

---

## 核心新设定

| 项目 | 设定 |
|---|---|
| 门外之外 | 门外世界是"夹层"。再往外，是"外域" |
| 第二扇门 | 不在中立区，在门外世界的边缘。更难开，也更难关 |
| 外域 | 没有符力，也没有咒力，只有"**念**"。念=意志的直接具现 |
| 念师 | 外域的强者。用念造物、造人、造世界 |
| 空 | 外域的怪物。是"被放弃的念"凝结的 |
| 十二符咒的源头 | 圣主之上，还有"造圣主的人" |
| 主角定位 | 从"门外的老师"，变成"两界的中间人" |

## 铁律（续篇二同样遵守）

1. **主角永远不是最强的**，靠脑子、规则、布局。
2. **十二符咒仍是全部底牌**，不开新符咒。
3. **沙雕+社畜内核不变**，到哪儿都是"打工的"。
4. **旺财全程在线**。
5. **结局是"下班"**，不是登顶。
